Visual attention（視覺注意力） and context

Visual attention selects relevant（相關性；是否切合問題） regions. Bottom-up attention（注意力） follows striking image features（特徵；描述樣本的屬性）; top-down attention follows the task and context.

Recognise（辨識；從資料找出物件或模式） this in a question: Image label（標籤；作比較的正確答案）, object（客體；三元組終點） location, bounding boxes（邊界框；框出物件位置）, pixel area, segmentation（分割）

What this tells us: The right answer explains why the selected region contributes to the question. “The model uses attention” alone does not establish that it checks the necessary relationship.

What makes a region relevant to the current visual task?

  • Bottom-up attention is attracted by image properties such as brightness, contrast and orientation（朝向；物件旋轉的方向）. The most visually striking region need not be relevant to the task.
  • Top-down attention uses the current target, scene layout and expected relationships to direct processing toward useful evidence.
  • Context can help disambiguate an object, but it must not manufacture an object that is not actually visible.
  • Self-attention（自注意力） learns relationships among image patches. It is not a guarantee that the model’s focus matches a human explanation or the desired safety criterion.

Common wrong answers and the exact correction
  • Self-attention is learned relationships between patches; it is not identical to visual saliency.
  • Expected does not mean（均值；平均數） observed.

Apply the distinction

Data, components and application

  • Bright distractor selected → use task/context guidance → saliency alone may miss the relevant object.
  • Expected object imagined → verify visible evidence → context is guidance, not proof.
  • Relevant region hidden → request another view → attention cannot recover absent pixels.

How to evaluate it

Check whether relevant objects/relations are found under distraction, unusual context and changed camera angles.

Build the answer in this order

  1. Task and target.
  2. Bottom-up cues versus top-down guidance.
  3. Context-supported interpretation.
  4. Test distractors and uncertainty.

An answer you could write

  • Bottom-up attention follows contrast or brightness, while top-down attention follows the PPE inspection task.
  • Context can guide the search toward the face or hands, but does not prove that a required item is present.
  • Validate the selected regions and report missing evidence when the relevant area is outside the frame（框架；附欄位的知識記錄）.

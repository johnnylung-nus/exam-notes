Self-attention（自注意力） and multi-head attention（多頭注意力）

Self-attention lets each token（詞元） combine information from other tokens in the same sequence. Multiple heads learn separate comparisons, allowing several relationship patterns to be represented together.

Turn attention scores into contextual evidence（證據；已觀察到的資訊）

Worked study example: Illustrative query scores for two allowed tokens are 0 and ln(3), after any scaling. Their scalar values are 2 and 10. Natural exponentiation is used in softmax（機率正規化函數）.

How do queries, keys and values produce a contextual representation?

  • Queries represent what a token seeks; keys represent how other tokens can be matched; values contain the information to combine. These are learned projections of token representations, not independent raw measurements.
  • Comparing a query with available keys creates scores. Scaling controls score magnitude, masking removes forbidden positions, and softmax turns scores into nonnegative weights that sum to one. The resulting output is a weighted sum of values.
  • Several heads use different learned projections, enabling different relationships to be represented at once. A head is not assigned a guaranteed human meaning; useful context relationships emerge only if training（訓練） supports them.
Implementation steps and their purpose
  1. Create query, key and value representations from token vectors
  2. Compare each query with available keys
  3. Scale scores and turn them into normalized weights
  4. Form a weighted combination of value vectors
  5. Repeat with different learned projections in several heads
  6. Combine head outputs

Common wrong answers and the exact correction
  • Attention weights are learned input-dependent combinations
  • Multiple heads are not simply repeated identical attention copies.

Implement it and test the outcome

Data, components and application

  • Unwanted future information → apply a mask before normalization → respect prediction（預測） order
  • One relation insufficient → multiple heads → learn different comparisons
  • Expensive long sequences → constrain length → manage memory

How to evaluate it

Judge downstream prediction quality, cost and generalization（泛化能力）; attention pictures alone do not prove causal explanations.

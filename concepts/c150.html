Filter / wrapper / embedded feature selection（特徵選擇）

Feature selection keeps some original variables（變數）. Filters use statistics, wrappers test feature（特徵；描述樣本的屬性） subsets with a model, and embedded methods obtain selection or importance from the model fitting process.

Recognise（辨識；從資料找出物件或模式） this in a question: Too many variables, irrelevant inputs, select features, dimensionality（維度；描述資料所需的座標數） harms distance

Does feature selection use a filter, a fitted model or subset testing?

  • Filter selection uses a statistical property such as variance（變異數）, correlation（相關；數值一同變化的程度） or target association without fitting every candidate model subset. It is fast but can miss a feature useful only through interaction.
  • Wrappers repeatedly train and validate the chosen model on candidate subsets. They account for that model’s behavior but can be expensive and can overfit the validation search if unchecked.
  • Embedded/model-based approaches obtain coefficients or importance during fitting.
  • A low-importance feature is a candidate for removal, not proof it is useless; correlated substitutes and changing model regions can alter rankings.
  • Keep the selection process inside training folds.

Data, components and application

  • Univariate filter misses feature combinations → validate model-based subsets → interactions may matter
  • Wrapper search expensive → restrict candidates → control runtime
  • Importance biased or unstable → check held-out（留出資料；未參與該階段訓練） removal impact → avoid treating rankings as truth

How to evaluate it

Accept reduction when the relevant（相關性；是否切合問題） metric is preserved or improved and operational complexity falls.

Build the answer in this order

  1. Identify redundant or costly features
  2. Name a selection family
  3. Explain its criterion
  4. Retrain and compare fairly
An answer you could write

An answer you could write

  • “I retain the reduction only if purchaser recall and business value are maintained or improved.”

ISY5002 Q1(c) — AdaBoost feature importance（變數重要性；模型使用該特徵的相對程度） versus a single tree

What the question requires

  1. Compare the actual displayed rankings.
  2. Explain how sequential weak learners（弱學習器；略優於基準的模型） can use different features.
  3. Propose a feature-selection experiment.
  4. Evaluate fairly on held-out data.

Proposed answer points

  • The single tree emphasizes PageValue（頁面價值；題目定義的頁面平均經濟價值）/BounceRate（跳出率；進站後未觸發其他請求便離開的比例）; the AdaBoost plot emphasizes ProductRelated and Informational_Duration more.
  • Later learners can address earlier mistakes, changing aggregate（彙總；把多筆資料合併成統計值） importance. Retrain using a justified subset and compare on the same validation cases.

Avoid: Importance is model-dependent, not a causal（因果；一者造成另一者變化） effect. Correlated features and the importance measure can alter rankings.

ISY5002 Q2(c) — Critique anomaly classification（分類；預測類別） with only two anomalies

What the question requires

  1. Read the imbalance and representation（表徵；資料的表示方式） constraints（約束條件）.
  2. Identify two distinct challenges in the proposed classifier.
  3. Propose a remedy for each and tie it to the supplied features/data.
  4. Explain how anomaly detection（異常偵測） would be assessed.

Proposed answer points

  • Challenge 1:3,000 normal sequences（序列；有先後順序的資料） versus two anomalies cannot support（支持度；同時出現的交易比例） reliable supervised anomaly generalization; an all-normal model already scores 3000/3002≈99.93% accuracy（準確率）.
  • Consider learning normal behaviour with a one-class or reconstruction-based detector and collect more diverse verified anomalies.
  • Challenge 2:30 concatenated features can be redundant/on different scales; the plotted histogram（直方圖；統計各數值區間的出現次數） may be less discriminative（判別式；著重區分輸入所屬類別） than frequency（頻率） features.
  • Inspect the supplied figure, compare representations on held-out data, scale training-derived features and reduce redundant dimensions if justified.
  • Each sequence has 4×50=200 samples; this is separate from the engineered 10+20=30 feature dimensions. Evaluate false alarms and anomaly recall; two anomalies make estimates highly uncertain.

Avoid: Do not manufacture many reliable abnormal examples by copying two rows. A temporal（時間的） histogram also discards order. The missing QA（Question Answering；問答） answer is newly analysed study guidance, not a past reviewed answer.

Wav2Vec self-supervised learning（自監督學習）

Wav2Vec2.0 is presented as self-supervised speech representation learning（表徵學習）: learn useful audio features（特徵；描述樣本的屬性） from speech before using task labels（標籤；作比較的正確答案）.

What this tells us: A code is not a recognized word. The pretext task（前置任務；用自造目標學表徵） first learns useful audio structure; downstream labels connect that representation to the real output.

What can speech pretraining learn without transcripts?

  • The lecture divides Wav2Vec2.0 use into self-supervised pretraining and supervised downstream adaptation. These phases use different sources of training targets.
  • A CNN creates latent（潛在） speech features; selected feature time steps are masked so the contextual model must use surrounding information.
  • Quantization（量化；把連續幅度映成有限數值） creates discrete（離散；取分開的數值或時點） target representations from the audio itself. Training aligns contextual representations with the corresponding targets rather than requiring a transcript for every pretraining clip.
  • For the target task, keep the pretrained encoder（編碼器） frozen or fine-tune it using labelled examples. The learned representation can support（支持度；同時出現的交易比例） speech recognition（語音辨識） or speaker identification.
Implementation steps and their purpose
  1. Collect representative unlabelled speech.
  2. Encode audio with a CNN; mask selected time-step features.
  3. Learn contextual representations matching quantized audio targets: discrete targets created from the audio itself.
  4. Freeze or fine-tune the pretrained model with labelled target data.
  5. Evaluate on separate speakers/recordings.

Prepare the data and validate the representation

Data, components and application

  • Little labelled data → reuse pretrained features → reduces learning from scratch.
  • Pretraining audio differs from deployment → adapt and test locally → representations may not transfer perfectly.
  • Train/test speakers overlap → separate them → avoids optimistic generalization（泛化能力） claims.

How to evaluate it

Assess the downstream speech task and complete interaction, not just the pretraining objective.

Build the answer in this order

  1. Unlabelled versus labelled data available.
  2. Self-supervised pretraining.
  3. Target-task adaptation.
  4. Unseen-speaker/task evaluation（評估）.

Common wrong answers and the exact correction
  • Self-supervised does not mean（均值；平均數） no learning target.
  • Do not describe it as ordinary supervised training on transcripts.

An answer you could write

  • Wav2Vec2.0 pretrains on unlabelled audio using masked feature positions and audio-derived quantized targets.
  • The contextual model learns speech structure from surrounding features, then a downstream head（頭實體；關係起點） uses labelled task data.
  • Compare frozen and fine-tuned representations on separate speakers/recordings rather than relying only on pretraining loss.

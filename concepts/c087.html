C087

Time and frequency（頻率） representation（表徵；資料的表示方式）

Time representation shows how readings change; frequency representation shows which rates of variation contribute. Choose according to the question.

Recognise（辨識；從資料找出物件或模式） this in a question: Frequency peaks, periodic（週期性） components, filter noise（雜訊；干擾有效訊息的成分）, convolution（卷積）

What this tells us: A model cannot use event-order evidence（證據；已觀察到的資訊） if preprocessing（前處理） removes that evidence. Adding a larger classifier after the loss（損失函數；衡量預測錯誤） does not restore it.

Which structure is easier to see in time or frequency?

  • Time-domain samples preserve order and change locations. Frequency coefficients expose repeated rates of variation that may be hard to see directly.
  • The transformation is a representation change, not automatically information reduction; loss occurs when coefficients or timing detail are discarded/aggregated（彙總；把多筆資料合併成統計值）.
  • A global frequency description is unsuitable when the order of components defines the event. Localized transforms retain more temporal structure.
  • Feature choice should follow the recognition question: steady vibration（振動；來回震動的訊號） frequency and brief transient detection（偵測） need different evidence.
Implementation steps and their purpose
  1. Identify whether the task needs event timing, frequency content or both.
  2. Inspect the time signal.
  3. Use Fourier analysis for overall frequency components.
  4. If timing matters, use a localized representation such as the lecture’s wavelet approach.
  5. Extract relevant（相關性；是否切合問題） coefficients/statistics and evaluate the task.

Choose the method from the problem

Common wrong answers and the exact correction
  • Frequency is not amplitude（振幅；訊號大小）.
  • A whole-recording Fourier view is not a time-frequency map.

Implement it and test the outcome

Data, components and application

  • Time information lost → use localized analysis → preserves event timing.
  • Raw waveform too complex → transform to relevant frequency features → exposes repeated structure.
  • Transform chosen for appearance → test target task → a clear plot is not proof of useful evidence.

How to evaluate it

Check retained frequency/time information and downstream（後續階段；使用前一步結果的模型或流程） recognition on unseen sequences.

Build the answer in this order

  1. Question needs what information?
  2. Choose representation.
  3. Explain information gained/lost.
  4. Evaluate downstream usefulness.

An answer you could write

  • I need both the frequency and its occurrence time, so a global spectrum（頻譜；各頻率成分的分布） alone is insufficient.
  • I extract localized coefficients and compare them across windows.
  • The final test checks whether reversed or shifted events remain distinguishable.

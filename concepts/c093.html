Supervised representation learning（監督式表徵學習）

Supervised representation learning uses labelled task examples to learn features（特徵；描述樣本的屬性） useful for prediction（預測）. Transfer can freeze an encoder（編碼器） or fine-tune it.

Choose from the scenario

Use when sensor labels（標籤；作比較的正確答案） exist or a pretrained model can help with a smaller target dataset.

Scenario cueSuitable choiceWhy it fits
Few labels, useful pretrained featuresTry frozen adaptation（調適；修改以配合新情境）Fewer adjustable parameters（參數） can reduce fitting risk.
Enough target data and clear feature mismatchCompare fine-tuning（微調）Representation can adapt to new signal characteristics.

What this tells us: A new classification（分類；預測類別） head can learn a target mapping without changing the encoder. Calling this “fine-tuning the entire model” would misdescribe the actual training.

How do task labels shape a learned representation?

  • In supervised representation learning, prediction error from labelled examples updates the feature extractor so its representations support（支持度；同時出現的交易比例） the target classes（類別；分類目標）.
  • Frozen adaptation updates only a new output mapping; fine-tuning also changes some or all pretrained feature weights. These have different data and overfitting（過度擬合） demands.
  • The target dataset must contain relevant（相關性；是否切合問題） class variation. An unchanged pretrained model may be fast to reuse but can preserve unsuitable domain features.
  • A validation comparison determines whether extra trainable capacity helps; fine-tuning is not inherently better when target labels are scarce.

Common wrong answers and the exact correction
  • Pretraining and target-task training are different stages.
  • Fine-tuning is not just attaching a new output layer（輸出層；產生預測）.

Apply the distinction

Data, components and application

  • Few target examples → start with frozen features → fewer trainable parameters（可訓練參數；會在訓練中更新的數值） can reduce fitting risk.
  • Domain mismatch → consider fine-tuning → adapts features to new signals.
  • Validation degradation → reduce capacity/training or retain frozen features → target labels may not support extensive updates.

How to evaluate it

Check target-task errors, class coverage（涵蓋率；能服務的使用者或項目範圍）, resource cost and training/validation gap.

Build the answer in this order

  1. Labels and deployment task.
  2. Frozen versus adapted representation.
  3. Explain data/capacity trade-off.
  4. Compare on unseen target cases.

An answer you could write

  • I first train a new output mapping while freezing the pretrained encoder.
  • If target-domain validation shows a representation mismatch, I compare fine-tuning under the same held-out（留出資料；未參與該階段訓練） split（切分；按條件分開資料）.
  • I choose the configuration balancing target quality, capacity and deployment cost.

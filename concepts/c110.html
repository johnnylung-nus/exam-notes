General regression neural networks（廣義迴歸神經網路）

GRNN（General Regression Neural Network） predicts a numeric（數值型；以數量表示） value by combining stored training（訓練） targets, giving greater influence to examples closer to the new input. Its output divides a similarity-weighted target sum by the similarity（相似度） sum.

Recognise（辨識；從資料找出物件或模式） this in a question: Nonlinear（非線性；不能只用線性關係表示） prediction（預測）, hidden layer（隱藏層；中間處理層）, weights（權重）, bias（偏置／偏差；須看語境）, backpropagation（反向傳播；計算各參數梯度）

Similarity-weighted regression（迴歸；預測連續數值）

ŷ = Σ(sᵢtᵢ) / Σsᵢ
ŷ
predicted numeric target
sᵢ
similarity of stored example i
tᵢ
stored target of example i
Σ
sum across stored examples
  1. Targets10 and20 have similarities0.8 and0.2.
  2. Numerator=0.8×10+0.2×20=12.
  3. Denominator=0.8+0.2=1.
  4. Prediction=12/1=12.

Interpret the result: Normalize similarity weights; do not confuse this with an unrestricted RBF（Radial Basis Function；徑向基底函數） output.

A local average changes when support（支持度；同時出現的交易比例） changes

Worked study example: Illustrative targets are 10,20,40. Similarities are already computed from distances using a selected Gaussian（高斯分布；常見鐘形分布） width; the two queries have different proximity patterns.

QuerySimilarity-weighted numerator / denominatorPrediction
Near first example(0.8×10 + 0.2×20 + 0.0×40)/(0.8+0.2+0)12
Between second and third(0.1×10 + 0.4×20 + 0.5×40)/(0.1+0.4+0.5)29

What this tells us: The prediction follows nearby target evidence（證據；已觀察到的資訊） rather than a single fitted global straight line. A distant query still needs a low-support warning even if a numeric result is produced.

How does GRNN average nearby targets to predict an output?

  • GRNN forms a normalized similarity-weighted estimate of stored targets. Nearby training patterns contribute strongly; remote patterns contribute weakly. The denominator makes the effective target weights sum to one.
  • Its smoothing width controls a bias–variance（變異數） trade-off（取捨；改善一項可能犧牲另一項）: narrow kernels approach a near-neighbor estimate and can follow noise（雜訊；干擾有效訊息的成分）; broad kernels average over dissimilar cases and can erase local structure.
  • The pattern layer represents training examples, so model size and prediction work can grow with the stored dataset. Fast fitting does not automatically mean（均值；平均數） cheap inference（推論；由依據得出結論）. Explain memory and support as well as error when recommending it.
Implementation steps and their purpose
  1. Scale and clean numeric inputs
  2. Store representative training inputs and targets in pattern units
  3. Calculate Gaussian similarity to the new input
  4. Sum similarity-weighted targets
  5. Divide by the sum of similarities

Use the result and check it

Data, components and application

  • Small smoothing width → increase after validation → reduce sensitivity（敏感度；找出正類的比例） to noise
  • Large training memory → reduce representative patterns → improve inference cost
  • Distant query → flag weak support → local averaging may be unreliable

How to evaluate it

Tune smoothing width using held-out（留出資料；未參與該階段訓練） MAE（Mean Absolute Error；平均絕對誤差） or RMSE（Root Mean Squared Error；均方根誤差）; inspect errors in sparsely sampled regions.

Build the answer in this order

  1. Identify numeric target
  2. Explain similarity weighting
  3. Show numerator and denominator
  4. Justify（給出理由；用情境與證據支持選擇） smoothing and validation

Diagnose: Noisy predictions around individual training records

Common wrong answers and the exact correction
  • The denominator normalizes weights
  • GRNN is not the same architecture as a generic backpropagation MLP（Multilayer Perceptron；多層感知器；多層前饋神經網路）.

When would this calculation be useful?

Use for nonlinear regression where local similarity predicts the target and storing representative examples is feasible（可行；符合所有硬性條件）.

Scenario cueSuitable choiceWhy it fits
Small nonlinear regression problem with meaningful distancesCompare GRNN with a simple regression baseline（基準；供比較的簡單方法）It can model a smooth local relationship with a directly interpretable weighted-average mechanism.

An answer you could write

  • “The numerator accumulates similarity-weighted targets; the denominator normalizes the similarities.”
  • “I choose smoothing width on validation data and separately assess prediction cost and sparse-region reliability.”

C115

Multi-input（多輸入） / multi-output（多輸出） architectures

Multiple inputs let a network combine different information sources. Multiple outputs let it learn several related targets, with a suitable output head（頭實體；關係起點） and loss（損失函數；衡量預測錯誤） for each target.

Recognise（辨識；從資料找出物件或模式） this in a question: Multiple sensors（感測器）, camera + sound, conflicting measurements, alignment（對齊） · History matters, sequential purchases, time steps, long dependencies

What must the system deliver?

Use when the scenario includes images plus text or metadata, or requires several predictions about the same object（客體；三元組終點）.

Scenario cueSuitable choiceWhy it fits
Several labels（標籤；作比較的正確答案） can independently apply to an objectUse separately labeled sigmoid（S形函數） headsA softmax（機率正規化；轉成總和為1的權重） would force competition even when two attributes（屬性；對象的描述欄位） should both be present.

How are several inputs or outputs connected in one model?

  • Process each modality（模態；資料形式如語音或影像） according to its structure: tokens as sequences（序列；有先後順序的資料）, images as spatial（空間的） arrays and numeric metadata as prepared measurements. Combining raw values blindly can erase the relationships the branch should exploit.
  • A merge joins representations（表徵；資料的表示方式） belonging to the same case. Every source must exist at prediction（預測） time; metadata recorded after an outcome is leakage even if it enters through a separate branch.
  • Separate outputs need separate labels, activations and losses. Loss weights（權重） control their influence on shared layers（共用層）, so the numerically larger loss must not automatically determine what all shared features（特徵；描述樣本的屬性） learn.
Implementation steps and their purpose
  1. List each input modality and its shape
  2. Give each modality a suitable processing branch
  3. Combine branch representations
  4. Attach task-specific output heads
  5. Define each target and corresponding loss
  6. Balance losses and validate every output

Design two inputs and two outputs

Worked study example: Illustrative task predicts exclusive product type among three classes（類別；分類目標） and continuous（連續；可在範圍內連續變化） estimated weight from one product image plus four metadata features.

What this tells us: Report type errors and weight error separately. A favorable combined loss can conceal deterioration in the business-critical output.

Data, implementation and validation

Data, components and application

  • One modality has a different scale or missing values（缺失值） → prepare it separately → avoid corrupting fusion（融合）
  • One task dominates training（訓練） → adjust loss weighting → preserve the other task

How to evaluate it

Measure each output separately and check whether using multiple inputs improves over single-input baselines.

Build the answer in this order

  1. Identify information sources
  2. Draw branches and merge point
  3. Label each output
  4. Explain activation（激活函數；轉換神經元輸出）, loss and evaluation（評估） per head

Diagnose: Deployment lacks a metadata input

What you observeWhy it happensWhat to changeWhy that helps
Deployment lacks a metadata inputTraining used a source recorded after the decisionRemove that source and retrainA model cannot operationally depend on information unavailable when it must act.
Common wrong answers and the exact correction
  • Concatenating unrelated raw inputs is not automatically a good design
  • Multiple exclusive classes differ from multiple separate outputs.

An answer you could write

  • “I use modality-specific branches, then merge representations for the same observation.”
  • “Each output has its own target, activation, loss and evaluation; I justify（給出理由；用情境與證據支持選擇） how the losses are balanced.”

Where this is tested in the sample papers

ISY5002 Q1(d) — Sequence model, input construction and combination

What the question requires

  1. Choose LSTM（Long Short-Term Memory；長短期記憶網路） for ordered session（工作階段；一次連續造訪的記錄） events.
  2. Represent each session as an ordered sequence with a purchase label.
  3. Encode page/source, scale duration, pad（補齊；把不同長度輸入補至所需長度）/mask（遮罩；標示哪些位置應使用或忽略） and split（切分；按條件分開資料） without future leakage.
  4. Combine outputs with earlier models without training-score leakage.

Proposed answer points

  • Clickstream（點擊軌跡；依次瀏覽與操作的記錄） sequence → LSTM → Dense sigmoid → purchase score; use binary cross-entropy（二元交叉熵；二分類損失） for the binary label.
  • For stacking（堆疊集成；用另一模型整合各模型預測）, generate LSTM training scores out of sample, add them to the earlier model’s inputs, and compare against that model on validation data.

Avoid: Do not use post-purchase/future events when predicting an earlier intervention. In-sample base-model scores can leak into a stacked learner.

C080

Validity（推論有效性）, soundness（推論健全性）, and reasoning（推理） failure

Validity asks whether a conclusion（結論） follows from the premises（前提；推理的依據）. Soundness also requires true premises; a valid-looking argument based on a wrong case assumption（假設；答案依賴但題目未明說的條件） is insufficient.

Unsigned fractional-size discrepancy

|L−R|>0.30
L, R
Average relative pupil sizes in the left and right eye.
|L − R|
Absolute value of the WHOLE difference; swapping eyes does not change it.
0.30
Threshold when sizes are represented as fractions; use 30 on a 0–100 percentage scale.

This is an absolute difference between normalized sizes, not an unspecified percentage change relative to one eye. Follow the supplied case’s measurement definition.

  1. State assumption:30 percentage points between normalized means.
  2. L=.20,R=.60 gives difference−.40.
  3. abs(−.40)=.40; .40>.30 is true.
  4. At exactly.30 the strict greater-than test is false.

Interpret the result: The illustrative.40 difference passes; the boundary.30 does not.

Are the reasoning steps valid and the premises true?

  • Validity concerns whether the conclusion follows from the premises; soundness additionally needs true premises. Unsupported case assumptions undermine the answer even if the arithmetic is consistent（一致性）.
  • A counterexample（反例；推翻一般說法的例子） is often faster than a long critique: reverse input order, test zero difference or test the boundary at the threshold（門檻值）.
  • Units and scales are part of the reasoning. Fractions and percentages can describe the same quantity but require consistent thresholds.
  • The sample’s percentage wording is ambiguous; an exam answer should state the adopted interpretation rather than claim a universally correct clinical equation.
Implementation steps and their purpose
  1. List the premises actually supplied by the case.
  2. Separate assumptions from evidence（證據；已觀察到的資訊）.
  3. Check the inference（推論；由依據得出結論） or calculation.
  4. Test edge cases and reversed inputs.
  5. Check whether the conclusion answers the requested question.

Data, components and application

  • Unstated assumption → label（標籤；作比較的正確答案） it explicitly（明確；直接提供的資訊） → readers can assess its effect.
  • Wrong scale → keep fractions and percentages consistent → avoids a 100-fold threshold error.
  • Wrong problem solved → reread the exact requested quantity → a correct calculation can be irrelevant.

How to evaluate it

Verify premises, logical steps, units, signs, boundary conditions and final requirements.

Build the answer in this order

  1. Case facts（事實；推理中已知的資訊） versus assumptions.
  2. Reasoning rule.
  3. Counterexample or boundary test.
  4. Supported conclusion.

An answer you could write

  • Assuming the threshold means 30 percentage points between normalized means, compare abs(left−right) with .30.
  • Taking absolute values separately does not fix a negative difference; reversing left/right should not change an unsigned discrepancy.
  • Use strict greater-than when required and state that a relative-percentage interpretation needs a defined denominator.

Where this is tested in the sample papers

ISY5001 Q2(i) — Patient self-service: benefits, risks and role boundaries

What the question requires

  1. State a position on removing the primary doctor.
  2. Acknowledge the convenience benefit.
  3. Explain a case-specific risk and a safer scope.

Proposed answer points

  • A patient-facing information/capture function could improve convenience, but removing the doctor is not justified by the presented diagnostic/triage（分流；判斷處理或轉介的急切程度） support（支持度；同時出現的交易比例） case.
  • Capture errors, incomplete context and delayed escalation are possible risks; retain clinician assessment for the clinical decision.

Avoid: Do not claim all cognitive systems always require a doctor; argue from this system’s intended users and risks.

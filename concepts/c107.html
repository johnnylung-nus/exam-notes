C107

MLP（Multilayer Perceptron；多層感知器；多層前饋神經網路） and backpropagation（反向傳播；計算各參數梯度）

An MLP passes inputs through hidden layers（隱藏層；中間處理層） to predict a target. Backpropagation calculates how each weight contributed to the loss（損失函數；衡量預測錯誤）, allowing a gradient-based optimizer（最佳化器；按梯度更新參數） to update it.

Recognise（辨識；從資料找出物件或模式） this in a question: Nonlinear（非線性；不能只用線性關係表示） prediction（預測）, hidden layer, weights（權重）, bias（偏置／偏差；須看語境）, backpropagation

What must the system deliver?

Use for supervised nonlinear relationships, especially prepared tabular features（特徵；描述樣本的屬性）; choose architecture（架構） complexity to fit available data.

Scenario cueSuitable choiceWhy it fits
Unordered prepared customer features predict purchaseStart with a small MLP and binary head（頭實體；關係起點）The hidden layers model interactions while one sigmoid（S形函數） output matches a binary target.

How does backpropagation assign error to hidden-layer weights?

  • An MLP learns intermediate features whose targets are not directly labeled. Backpropagation assigns credit or blame to each hidden unit by following how that unit influences the final loss through later weights.
  • Forward propagation（前向傳播；由輸入算至輸出） computes the prediction and loss. Backward propagation computes derivatives（導數；輸入微變時輸出改變多少）; the optimizer then changes parameters（參數）. Calling all three backpropagation hides the actual sequence（序列；有先後順序的資料） required in an architecture answer.
  • For a hidden unit, the downstream（後續階段；使用前一步結果的模型或流程） error is multiplied by its outgoing weight and its activation（激活函數；轉換神經元輸出） derivative. If either is tiny, little learning reaches that unit; this explains why activation and initialization（初始化） choices affect early layers.
Implementation steps and their purpose
  1. Prepare inputs and training（訓練） labels（標籤；作比較的正確答案）
  2. Run a forward pass through hidden and output layers
  3. Calculate task-appropriate loss
  4. Propagate loss gradients backward using the chain rule（連鎖法則；逐層計算導數）
  5. Update weights and monitor validation performance

Trace a tiny network forward and backward

Worked study example: Illustrative scalar network: input 2 → weight 0.5 → ReLU（Rectified Linear Unit；修正線性；負數歸零） hidden unit → output weight 0.4 → linear（線性；此處加權組合加偏置） prediction. Biases start zero, target is 1, loss is half-squared error.

What this tells us: Both weights increase because the prediction is too low. Use the original forward-pass weights to calculate that step’s gradients, then update together.

Data, implementation and validation

Data, components and application

  • Training improves while validation worsens → simplify, regularize or stop early → reduce fitting of training-specific noise（雜訊；干擾有效訊息的成分）
  • Poor gradients → inspect activation and initialization → restore useful learning signals（訊號）

How to evaluate it

Assess held-out（留出資料；未參與該階段訓練） precision（精確率）, recall（召回率） and loss for classification（分類；預測類別）, or regression（迴歸；預測連續數值） error for numeric（數值型；以數量表示） targets.

Build the answer in this order

  1. Specify input and output
  2. Draw hidden structure
  3. Justify（給出理由；用情境與證據支持選擇） output activation and loss
  4. Explain training and validation checks

Interpret the result: Compute both gradients using the original forward-pass weights.

Diagnose: Training loss falls but held-out loss rises

What you observeWhy it happensWhat to changeWhy that helps
Training loss falls but held-out loss risesThe model memorizes training-specific patternsReduce hidden width, regularize or stop earlyThe aim is lower error on new cases, not the smallest possible training loss.
Common wrong answers and the exact correction
  • Backpropagation computes gradients
  • the optimizer performs updates
  • More layers are not automatically better.

An answer you could write

  • “The hidden layers learn nonlinear combinations of the inputs; the final head matches the target.”
  • “Forward pass gives the loss, backpropagation calculates each gradient, and the optimizer updates the weights.”

Where this is tested in the sample papers

ISY5002 Q1(b) — Confusion matrices, model choice and error costs

What the question requires

  1. Define the positive class（類別；分類目標） from the table.
  2. Calculate the metrics needed for the stated decision.
  3. Compare missed purchasers and unnecessary offers.
  4. Choose a model conditionally on business costs.

Proposed answer points

  • Using the supplied table: SVM（Support Vector Machine；支援向量機） recall=3078/(3078+72)≈0.9771; NN（Artificial Neural Network；神經網路） recall=3029/(3029+121)≈0.9616. SVM misses fewer labelled purchasers.
  • SVM has more false positives (312 versus 261); NN precision is higher. Prefer SVM if missed purchasers dominate cost and unused offers are cheap; otherwise justify another choice.

Avoid: The table’s actual-positive totals contradict the earlier dataset class proportions. Use the table as given for these calculations and flag the inconsistency（不一致；存在互相衝突的資訊）; do not silently reverse its labels.

C152

PCA（Principal Component Analysis；主成分分析）, variance（變異數）, and principal directions（主方向）

PCA replaces correlated（相關；數值一同變化的程度） numeric（數值型；以數量表示） features（特徵；描述樣本的屬性） with new uncorrelated directions, ordered by how much data variation they capture. It solves representation（表徵；資料的表示方式） and dimensionality reduction（降維）, not collaborative recommendation（推薦）.

Recognise（辨識；從資料找出物件或模式） this in a question: Correlated variables（變數）, fewer dimensions, retain variance, eigenvalues（特徵值）/loadings（負荷量；原特徵對主成分的係數）

Interpret the result: Uncorrelated PCs are not generally independent;ordinary scores need not have unit variance.

Which directions retain the most variance after centring?

  • PCA rotates prepared numeric data to directions with maximum variance, then retains only some directions. It does not use the prediction target to seek the most discriminative（判別式；著重區分輸入所屬類別） directions, so high retained variance need not imply high purchase accuracy（準確率）.
  • A component direction is a set of coefficients; a component score is one observation’s coordinate along that direction. Large absolute loadings help name the pattern, but a component sign can be reversed without changing the represented axis（軸；運算指定的維度）.
  • Fit centering, scaling and directions on training（訓練） predictors only. Revenue（營收；本題欄位指是否完成購買） must not be included when predicting Revenue. PCs are uncorrelated in the fitted covariance sense, not generally independent; ordinary scores need not have unit variance unless standardized/whitened.
Implementation steps and their purpose
  1. Exclude the prediction target and future information
  2. Split（切分；按條件分開資料） before fitting PCA
  3. Center training features and standardize when units require it
  4. Fit principal directions using training inputs
  5. Choose component count using variance and validation
  6. Transform validation/test inputs using the fitted preparation and directions

Choose the method from the problem

Useful for compressing related features or reducing multicollinearity（多重共線性；多個輸入高度線性相關）, while accepting some loss（損失函數；衡量預測錯誤） of original-feature interpretability.

Common wrong answers and the exact correction
  • Uncorrelated does not generally mean（均值；平均數） independent
  • Default PC scores（主成分分數；樣本投影後的新座標） need not have unit variance.

Implement it and test the outcome

Data, components and application

  • Revenue included in PCA for Revenue prediction → remove and refit → prevent leakage
  • High variance is irrelevant to target → compare prediction quality → variance retention is not accuracy

How to evaluate it

Inspect cumulative explained variance（累積解釋變異；保留成分合計涵蓋的變化）, loadings, retained information and held-out downstream metrics.

Build the answer in this order

  1. Explain why reduction helps
  2. State a retention rule
  3. Interpret large absolute loadings
  4. Use valid component scores as predictors

Where this is tested in the sample papers

ISY5002 Q1(e)(i) — Select a PCA component count with a stated criterion

What the question requires

  1. Read the explained-variance percentages.
  2. State a criterion rather than inventing a required cutoff.
  3. Accumulate the percentages.
  4. Choose the smallest count meeting the criterion.

Proposed answer points

  • With a stated 90% cumulative-variance criterion, retain ten components: the first nine sum to 86.8%, the first ten to 92.2%.
  • Other justified criteria can produce different counts; the question does not mandate 90%.

Avoid: Ten is not a universal PCA rule. Do not confuse number of original features with number of retained components.

ISY5002 Q1(e)(ii) — Interpret loadings and use scores without target leakage（目標洩漏；輸入混入預測時不應知道的答案資訊）

What the question requires

  1. Identify large absolute loadings for each retained PC.
  2. Describe contrasts without treating PC labels（標籤；作比較的正確答案） as known physical causes.
  3. Compute visitor PC scores from fitted coefficients.
  4. Use scores as predictors and validate the downstream task.

Proposed answer points

  • PC1 represents product/information engagement contrasted with bounce/exit behaviour; PC2 emphasizes bounce/exit. Remaining loading-based interpretations are listed below.
  • Scores are transformed coordinates, not the eigenvectors（特徵向量） themselves. For predicting Revenue, remove Revenue from the PCA input and refit preprocessing（前處理）/PCA on training data only.

Avoid: The supplied PCA table includes Revenue. PCs built using the target must not be fed back as predictors of that same target.

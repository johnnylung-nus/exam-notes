PCA, variance, and principal directions

PCA replaces correlated numeric features with new uncorrelated directions, ordered by how much data variation they capture. It solves representation and dimensionality reduction, not collaborative recommendation.

Interpret the result: Uncorrelated PCs are not generally independent;ordinary scores need not have unit variance.

Which directions retain the most variance after centring?

  • PCA rotates prepared numeric data to directions with maximum variance, then retains only some directions. It does not use the prediction target to seek the most discriminative directions, so high retained variance need not imply high purchase accuracy.
  • A component direction is a set of coefficients; a component score is one observation’s coordinate along that direction. Large absolute loadings help name the pattern, but a component sign can be reversed without changing the represented axis.
  • Fit centering, scaling and directions on training predictors only. Revenue must not be included when predicting Revenue. PCs are uncorrelated in the fitted covariance sense, not generally independent; ordinary scores need not have unit variance unless standardized/whitened.
Implementation steps and their purpose
  1. Exclude the prediction target and future information
  2. Split before fitting PCA
  3. Center training features and standardize when units require it
  4. Fit principal directions using training inputs
  5. Choose component count using variance and validation
  6. Transform validation/test inputs using the fitted preparation and directions

Choose the method from the problem

Useful for compressing related features or reducing multicollinearity, while accepting some loss of original-feature interpretability.

ISY5002 Q1(e)(i) — Select a PCA component count with a stated criterion

What the question requires

  1. Read the explained-variance percentages.
  2. State a criterion rather than inventing a required cutoff.
  3. Accumulate the percentages.
  4. Choose the smallest count meeting the criterion.

Proposed answer points

  • With a stated 90% cumulative-variance criterion, retain ten components: the first nine sum to 86.8%, the first ten to 92.2%.
  • Other justified criteria can produce different counts; the question does not mandate 90%.

Avoid: Ten is not a universal PCA rule. Do not confuse number of original features with number of retained components.

ISY5002 Q1(e)(ii) — Interpret loadings and use scores without target leakage

What the question requires

  1. Identify large absolute loadings for each retained PC.
  2. Describe contrasts without treating PC labels as known physical causes.
  3. Compute visitor PC scores from fitted coefficients.
  4. Use scores as predictors and validate the downstream task.

Proposed answer points

  • PC1 represents product/information engagement contrasted with bounce/exit behaviour; PC2 emphasizes bounce/exit. Remaining loading-based interpretations are listed below.
  • Scores are transformed coordinates, not the eigenvectors themselves. For predicting Revenue, remove Revenue from the PCA input and refit preprocessing/PCA on training data only.

Avoid: The supplied PCA table includes Revenue. PCs built using the target must not be fed back as predictors of that same target.

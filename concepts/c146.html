C146

Decision-tree（決策樹；逐條條件作判斷） splitting（切分；按條件分開資料） and information gain（資訊增益）

A decision tree repeatedly chooses a feature（特徵；描述樣本的屬性） test that makes child groups more class-pure. Information gain is parent uncertainty（不確定性） minus the size-weighted uncertainty remaining after a split.

Recognise（辨識；從資料找出物件或模式） this in a question: Explain purchase rules, feature split, entropy（熵）, information gain, many tiny leaves（葉節點；決策樹的最終輸出）

Information gain from a binary split

Proportion of class c in that node; use 0 log 0 = 0.

Child records after a candidate split, indexed by branch v.
|S_v|/|S|
Fraction of parent records in that child.
IG
Parent entropy minus weighted child entropy.
  1. Balanced parent entropy=1 bit.
  2. Pure child A entropy=0.
  3. Child B entropy=−(1/6)log₂(1/6)−(5/6)log₂(5/6)≈0.650.
  4. Weighted remaining entropy=(4/10)×0+(6/10)×0.650=0.390.
  5. Gain=1−0.390=0.610.

Interpret the result: Compare candidate splits on the same parent;purity alone is not generalization（泛化能力）.

What this tells us: The split is useful because it isolates a supported pure group and reduces uncertainty in the remainder. A different candidate must be calculated on the same parent for comparison.

How much uncertainty does a proposed tree split remove?

  • Entropy measures class uncertainty in a node. A balanced binary node has one bit; a pure node has zero. A useful split reduces the remaining weighted uncertainty, not simply the largest single child’s uncertainty.
  • Information gain compares parent entropy with the size-weighted sum of child entropies. Weighting matters because a tiny pure leaf should not outweigh a large mixed group merely by being perfectly pure.
  • A tree repeats local split choices to form rules. A root feature is important for that fitted tree’s partition, but other useful features can appear lower down or in an ensemble（集成學習）; tree position is not a causal（因果；一者造成另一者變化） claim.
Implementation steps and their purpose
  1. Start with all training（訓練） cases at the root
  2. Calculate parent entropy from class proportions
  3. Consider categorical（類別型；值代表類別） tests or numeric（數值型；以數量表示） thresholds
  4. Calculate the size-weighted child entropies
  5. Select the largest information gain
  6. Repeat with stopping or pruning（剪枝） rules

Use the result and check it

Data, components and application

  • Many-value identifiers create pure tiny leaves → reject identifiers or use gain ratio（增益比率）/pruning → avoid memorization
  • Continuous（連續；可在範圍內連續變化） features need thresholds → test candidate midpoints → choose a defensible split
  • Small leaves unstable → require minimum samples → improve generalization

How to evaluate it

Evaluate held-out（留出資料；未參與該階段訓練） class metrics and the usefulness of extracted rules, not only training purity.

Build the answer in this order

  1. Interpret the given tree path
  2. Explain the selected split
  3. Identify a model weakness
  4. Propose a change and fair evaluation（評估）

Common wrong answers and the exact correction
  • Root position indicates importance within that tree, not causation
  • Weight child uncertainty by group size.

When would this calculation be useful?

Use for interpretable classification（分類；預測類別） rules and for explaining why a particular feature is tested near the root.

Where this is tested in the sample papers

ISY5002 Q1(a) — Interpret a tree and connect it to business value

What the question requires

  1. Read the supplied branches for likely purchasers.
  2. Explain the action supported by that prediction（預測）.
  3. Identify a specific model/data weakness and proposed improvement.
  4. Test whether the change improves business outcome, not just training fit.

Proposed answer points

  • High PageValue（頁面價值；題目定義的頁面平均經濟價值） and low BounceRate（跳出率；進站後未觸發其他請求便離開的比例） characterize purchase-likely branches in the displayed model. This can guide targeted offers.
  • Test whether adding product-page engagement improves held-out prediction. Check feature availability at the intervention time, then assess incremental sales/profit with an appropriate controlled comparison.

Avoid: Do not assume every browser with high page activity will buy, or infer（推論；由依據得出結論） causal sales gains from offline accuracy（準確率） alone.

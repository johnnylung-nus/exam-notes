C071

Audio sampling（取樣） and coding

Sampling records audio amplitude（振幅；訊號大小） at time intervals; quantization（量化；把連續幅度映成有限數值） maps amplitude to discrete（離散；取分開的數值或時點） levels. They control different parts of the digital representation（表徵；資料的表示方式）.

Recognise（辨識；從資料找出物件或模式） this in a question: Speech to text, spoken bot, multilingual recording, few transcripts

Uncompressed audio size

B=fs×b×C×T
B
Total number of bits; divide by 8 for bytes.
f_s
Samples per second per channel (Hz).
b
Bits per sample (bit depth).
C
Number of channels.
T
Recording duration in seconds.

This is raw PCM size; file headers and compression are separate.

  1. 16,000 samples/s ×16 bits/sample ×1 channel =256,000 bits/s.
  2. For60 seconds:15,360,000 bits.
  3. Divide by8:1,920,000 bytes before headers.

Interpret the result: One minute is1.92 MB in decimal units, before file overhead.

What changes when the audio settings change?

Worked study example: Illustrative uncompressed mono PCM（Pulse-Code Modulation；脈衝編碼調變） calculations, excluding file headers.

All steps shown
SettingCalculation for one secondConsequence
16 kHz,16-bit,mono16,000×16=256,000 bitsBaseline（基準；供比較的簡單方法） data rate
8 kHz,16-bit,mono8,000×16=128,000 bitsHalf as many time samples
16 kHz,8-bit,mono16,000×8=128,000 bitsSame time samples, coarser amplitudes
16 kHz,16-bit,stereo16,000×16×2=512,000 bitsTwo channels double storage

What this tells us: Two files can have the same size but preserve different information. Choose settings according to the signal（訊號） and model, not merely whichever file is smaller.

What is preserved or lost when audio is sampled and coded?

  • Sampling rate controls how often amplitude is measured; bit depth（位元深度；每個取樣的量化精度） controls how finely each measured amplitude is represented. Increasing one does not directly increase the other.
  • A speech model expects particular input properties. A recording labelled with the wrong rate can alter its apparent time/frequency（頻率） scale.
  • Uncompressed PCM size depends on samples per second, bits per sample, channel count and duration. Compression changes storage representation, not the original captured evidence（證據；已觀察到的資訊）.
  • Upsampling can create intermediate values but cannot uniquely recover high-frequency information already lost through undersampling（欠抽樣；減少多數類樣本）.
Implementation steps and their purpose
  1. Check the signal frequencies that need preservation.
  2. Choose an adequate sampling rate.
  3. Choose sample precision and encoding.
  4. Use the sample rate/format expected by the recognition model.
  5. Check the captured file before recognition.

Use the result and check it

Data, components and application

  • Undersampling → choose sufficient rate before capture → lost frequency detail cannot be restored merely by changing a file header.
  • Wrong input rate → correctly resample → matches model assumptions（假設；答案依賴但題目未明說的條件）.
  • Low-amplitude distortion → consider suitable quantization/encoding → lecture contrasts PCM with logarithmic coding.

How to evaluate it

Listen/check for clipping and format errors, then compare speech-recognition quality on representative recordings.

Build the answer in this order

  1. Signal needs.
  2. Sampling rate versus amplitude precision.
  3. Model-compatible conversion.
  4. Test input and recognition.

  • Upsampling does not invent lost original detail.

An answer you could write

  • Sampling rate determines the number of time samples per second; bit depth determines amplitude precision.
  • A 16 kHz,16-bit,mono PCM recording needs 256,000 bits per second before overhead.
  • Match audio rate/format to the model and verify capture quality; resampling（重新取樣；改變取樣率） cannot restore information lost during original undersampling.

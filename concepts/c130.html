C130

Random forests（隨機森林） and feature importance（變數重要性；模型使用該特徵的相對程度）

A random forest combines bootstrapped decision trees and randomly limits candidate features（特徵；描述樣本的屬性） at each split（切分；按條件分開資料）. This creates tree diversity（多樣性） beyond ordinary bagging（裝袋法）.

Recognise（辨識；從資料找出物件或模式） this in a question: Unstable single tree, feature importance, bootstrap（自助抽樣；從原資料有放回抽樣）, vote

How does a random forest reduce tree correlation（相關；數值一同變化的程度）?

  • Random forest adds feature randomization to bootstrap sampling（自助抽樣）. At each split, a tree considers only a random candidate subset, reducing the chance that one strong feature makes every tree follow the same early decisions.
  • A final prediction（預測） aggregates trees, not their importance scores. Impurity importance totals a feature’s contribution to training-node purification; permutation importance instead measures validation deterioration when its information is disrupted.
  • Importance is model-dependent and can be redistributed across correlated inputs. A feature unused by one tree may still help other trees correct errors in different data regions, so removing it requires a retrained comparison.
Implementation steps and their purpose
  1. Prepare training（訓練） features and labels（標籤；作比較的正確答案）
  2. Draw a bootstrap sample for each tree
  3. At each split consider a random subset of features
  4. Grow the tree
  5. Vote across trees or average regression（迴歸；預測連續數值） outputs
  6. Estimate quality and examine feature importance

Prepare the data and validate the representation（表徵；資料的表示方式）

Data, components and application

  • Highly correlated trees → reduce candidate features per split → encourage diversity
  • Importance suggests a removable feature → retrain and validate removal → ranking（排序） alone does not prove redundancy（冗餘；資訊重複）
  • Too much complexity → tune leaf（葉節點；決策樹的最終輸出） size/depth → control generalization（泛化能力）

How to evaluate it

Compare held-out（留出資料；未參與該階段訓練） recall（召回率）, precision（精確率） and business cost; inspect importance stability and out-of-bag（袋外；該模型抽樣未用到的資料） estimates during development.

Build the answer in this order

  1. State both randomness sources
  2. Explain prediction aggregation
  3. Interpret importance cautiously
  4. Validate any feature-removal proposal

Choose the representation from the task

Useful for nonlinear（非線性；不能只用線性關係表示） tabular classification（分類；預測類別） or regression with interactions; a strong baseline（基準；供比較的簡單方法） when interpretability of one small tree is not essential.

Diagnose: Importance ranking changes when a similar feature is added

What you observeWhy it happensWhat to changeWhy that helps
Importance ranking changes when a similar feature is addedCorrelated inputs share predictive informationTest removal by retraining on the same validation designRanking differences alone do not prove one variable（變數） is useless or causal（因果；一者造成另一者變化）.
Common wrong answers and the exact correction
  • Importance is not causation
  • Random forests can overfit and do not guarantee unbiased importance rankings.

An answer you could write

  • “Random forests vary both training cases and candidate features at each split.”
  • “I test the reduced feature set on held-out cases rather than removing variables solely from one importance ranking.”

ISY5001 Q3(a)(i) — Model choice against a ranked-output requirement

What the question requires

  1. Underline “least suitable”.
  2. Identify the required ranked list of diagnoses（診斷；判斷可能的疾病或故障原因）.
  3. Compare the proposed methods under stated assumptions（假設；答案依賴但題目未明說的條件）.

Proposed answer points

  • Under a basic hard-label single-tree interpretation, a single tree is the intended weak choice because the required output is a ranked differential list.
  • A single tree can in fact（事實；推理中已知的資訊） rank（秩；矩陣獨立資訊的維度數） classes（類別；分類目標） by leaf class proportions; explain the assumed implementation rather than asserting an inherent impossibility.

Avoid: Choosing a suitable model does not answer which is least suitable. There is no official key confirming a unique implementation assumption.

ISY5001 Q3(a)(ii) — Inputs, derived variables（衍生變數；由現有欄位計算） and ranked diagnoses

What the question requires

  1. Use only listed or explicitly（明確；直接提供的資訊） derived fields.
  2. Derive age at consultation; encode/scale appropriately.
  3. Separate doctor diagnosis as the label.
  4. Explain how each remaining method generates a ranking.

Proposed answer points

  • Inputs: listed symptoms（症狀；患者感受到的不適）, signs, medication-use flags, gender, occupation, and age derived from consultation date minus birth date.
  • Trees: aggregate（彙總；把多筆資料合併成統計值） class counts/probabilities across trees and rank. KNN（K-Nearest Neighbours；K近鄰；參考最接近的K個樣本）: find nearby historical feature vectors（特徵向量；一個樣本的數值描述）, count their attached diagnosis labels, then rank up to ten.

Avoid: Medication-use flags are not measured blood-pressure/glucose. A label is not an input coordinate; neighbour support（支持度；同時出現的交易比例） is not automatically a calibrated（校準；令量測或機率對應實際意義） probability（機率）.

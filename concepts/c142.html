Linear（線性；此處加權組合加偏置） / logistic regression（邏輯斯迴歸）

Linear regression（線性迴歸） predicts a numeric（數值型；以數量表示） value from a weighted combination of features（特徵；描述樣本的屬性）. Logistic regression predicts class（類別；分類目標） probability（機率） by applying a logistic transformation（變換；把資料轉成另一表示） to a weighted combination.

Recognise（辨識；從資料找出物件或模式） this in a question: Continuous（連續；可在範圍內連續變化） target, probability, straight-line boundary, local neighbours

When does a linear score predict a value or a class probability?

  • Linear regression predicts a numeric quantity as a weighted combination of inputs and fits squared-error loss（損失函數；衡量預測錯誤） in the basic lecture form.
  • Logistic regression instead maps a weighted total to a class probability; its name does not make a purchase label a numeric regression target.
  • For logistic prediction, the learned score and decision threshold are separate. A probability of0.7 means an estimated class probability, not a guaranteed purchase, and it may need calibration（校準；令量測或機率對應實際意義） checking.
  • Coefficients are interpreted conditional on other included inputs and preprocessing（前處理）.
  • Correlation（相關；數值一同變化的程度）, omitted information and target leakage（目標洩漏；輸入混入預測時不應知道的答案資訊） can all undermine a simple story about why a coefficient is large; regression coefficients do not automatically establish causation（因果；一者造成另一者變化）.

Apply the distinction

Apply the distinction

Data, components and application

  • Linear relationship inadequate → add justified features or compare nonlinear（非線性；不能只用線性關係表示） models → capture missing structure
  • Correlated predictors → consider regularization（正則化） or PCA → stabilize the fitted model
  • Target leakage → remove outcome-derived features → preserve deployment validity（推論有效性）

How to evaluate it

Use MAE（Mean Absolute Error；平均絕對誤差）/RMSE（Root Mean Squared Error；均方根誤差） and residual（殘差） analysis for numeric targets; use loss, precision（精確率）, recall（召回率） and confusion matrix（混淆矩陣） for purchase classification.

Build the answer in this order

  1. Identify target type
  2. Choose model and loss
  3. Explain output interpretation
  4. Evaluate against a baseline

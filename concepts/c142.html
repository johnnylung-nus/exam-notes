C142

Linear / logistic regression

Linear regression predicts a numeric value from a weighted combination of features. Logistic regression predicts class probability by applying a logistic transformation to a weighted combination.

Recognise this in a question: Continuous target, probability, straight-line boundary, local neighbours

When does a linear score predict a value or a class probability?

  • Linear regression predicts a numeric quantity as a weighted combination of inputs and fits squared-error loss in the basic lecture form. Logistic regression instead maps a weighted total to a class probability; its name does not make a purchase label a numeric regression target.
  • For logistic prediction, the learned score and decision threshold are separate. A probability of0.7 means an estimated class probability, not a guaranteed purchase, and it may need calibration checking.
  • Coefficients are interpreted conditional on other included inputs and preprocessing. Correlation, omitted information and target leakage can all undermine a simple story about why a coefficient is large; regression coefficients do not automatically establish causation.

Common wrong answers and the exact correction
  • Despite its name logistic regression is used for classification
  • A probability is not a guaranteed outcome.

Apply the distinction

Data, components and application

  • Linear relationship inadequate → add justified features or compare nonlinear models → capture missing structure
  • Correlated predictors → consider regularization or PCA → stabilize the fitted model
  • Target leakage → remove outcome-derived features → preserve deployment validity

How to evaluate it

Use MAE/RMSE and residual analysis for numeric targets; use loss, precision, recall and confusion matrix for purchase classification.

Build the answer in this order

  1. Identify target type
  2. Choose model and loss
  3. Explain output interpretation
  4. Evaluate against a baseline

An answer you could write

  • “For purchase yes/no I use logistic regression with a binary classification loss, not ordinary numeric least squares.”
  • “If I use PCA scores, I construct them from predictor inputs only and evaluate on unseen visitors.”

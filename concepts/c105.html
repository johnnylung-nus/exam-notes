Perceptron（感知器） and linear separability（線性可分性）

A single perceptron makes a binary decision using one straight separating boundary. It can learn a solution only when the training（訓練） classes（類別；分類目標） are linearly separable.

What this tells us: Fixing one case can change other decisions, so repeat across the training set（訓練集）. If no separating line exists, repeated updates cannot create one.

Which patterns can a single linear boundary separate?

  • A perceptron’s threshold（門檻值） cuts feature space（特徵空間；以特徵作座標的空間） into two sides. With two inputs the boundary is a line; adding input dimensions changes it to a hyperplane（超平面；多維空間的線性分界）, but does not make it nonlinear（非線性；不能只用線性關係表示）.
  • Its learning signal（訊號） comes from a wrong class decision. A correctly classified training case makes no update even if it is very close to the boundary; a wrong case moves the boundary toward classifying it correctly.
  • An update is proportional to the input: a feature（特徵；描述樣本的屬性） equal to zero gets no weight update from that case. The bias can still change because its fixed input is one. This is why tracing the bias matters.
Implementation steps and their purpose
  1. Initialize weights and bias
  2. Calculate weighted input and hard-threshold output
  3. Find target minus predicted output
  4. Adjust each weight by learning rate × error × its input
  5. Repeat over examples

Choose the method from the problem

Useful as a simple binary baseline（基準；供比較的簡單方法）; unsuitable when the classes require curved or disconnected decision regions.

Common wrong answers and the exact correction
  • Training longer cannot make one perceptron solve XOR
  • A threshold output is not a calibrated（校準；令量測或機率對應實際意義） probability.

Implement it and test the outcome

Data, components and application

  • Nonseparable classes → use nonlinear hidden layers（隱藏層；中間處理層） → combine several boundaries
  • Large learning steps oscillate → reduce learning rate → updates become controlled

How to evaluate it

Check errors on unseen cases and whether a linear decision boundary（決策邊界；不同預測類別的分界） is plausible; failure to converge（收斂；結果逐步趨於穩定） may reflect the model limitation.

Build the answer in this order

  1. Inspect the class arrangement
  2. Decide whether a straight boundary suffices
  3. Show one update if asked
  4. Justify（給出理由；用情境與證據支持選擇） an MLP when it does not

An answer you could write

  • “A single perceptron is unsuitable because one linear boundary cannot separate the classes shown.”
  • “I would add nonlinear hidden units so several learned boundaries can be combined, then compare unseen-case errors.”

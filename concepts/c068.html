C068

Detection（偵測） vs segmentation（分割）

Classification（分類；預測類別） labels（標籤；作比較的正確答案） the whole image; detection returns object（客體；三元組終點） boxes and labels; segmentation assigns labels to pixels.

Recognise（辨識；從資料找出物件或模式） this in a question: Image label, object location, bounding boxes（邊界框；框出物件位置）, pixel area, segmentation

Relative pupil（瞳孔；眼睛中央讓光進入的開口） size

r=NpupilNiris
N_pupil
Pixel count in the identified pupil region.
N_iris
Pixel count in the reference iris region; must be nonzero.
r
Relative pupil size for that image; a ratio, not a raw pixel difference.
  1. Illustrative counts: pupil200; iris1,000.
  2. Divide200 by1,000 =0.20.
  3. If segmentation misses50 pupil pixels,150/1,000=.15.
  4. Correct division cannot repair incorrect region counts.

Interpret the result: Relative size is0.20 for the stated illustrative counts.

What this tells us: The ratio is information derived from recognized regions, not raw camera pixels. If segmentation misses 50 pupil pixels, the ratio changes even though the final division is correct.

Does the task need a label, a box or a pixel mask?

  • The desired measurement determines the visual task. An image-level label cannot supply a pupil area or an object boundary.
  • Detection localizes a candidate region with a box; segmentation separates object pixels from background. A box normally includes non-object pixels.
  • The sample’s normalized size is pupil-pixel count divided by iris-pixel count. Both regions must be consistently defined before the ratio is meaningful.
  • A later formula can be perfectly computed from incorrect masks; evaluation（評估） must inspect measurement quality as well as arithmetic.
Implementation steps and their purpose
  1. Identify the requested output: class（類別；分類目標）, location or boundary.
  2. Choose classification, detection or segmentation accordingly.
  3. Prepare matching labels for training（訓練）/evaluation.
  4. Convert model outputs into the required measurements or decisions.
  5. Inspect difficult capture conditions.

Use the result and check it

Data, components and application

  • Boxes include background → segment the region → improves area measurements.
  • Tiny/occluded objects → improve capture and representative examples → reduces missed regions.
  • Good object score but wrong decision → evaluate the derived measurement too → downstream（後續階段；使用前一步結果的模型或流程） errors matter.

How to evaluate it

Check the relevant labels/boxes/masks, boundary errors and final measurement or task correctness.

Build the answer in this order

  1. Required information.
  2. Choose output granularity.
  3. Model output → measurement.
  4. Evaluate downstream consequence.

An answer you could write

  • Use segmentation when the question requires pupil/iris pixel counts; a whole-image label or bounding box alone is insufficient.
  • For 200 pupil pixels and 1,000 iris pixels, the defined relative size is 0.20.
  • Check recognized regions and counts as well as the final ratio because correct arithmetic can still use incorrect measurements.

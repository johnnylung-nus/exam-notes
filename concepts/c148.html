Tree pruning（決策樹剪枝）

Pruning（剪枝） reduces a tree’s complexity so it captures repeatable structure rather than tiny training-specific exceptions. Pre-pruning stops growth; postpruning removes branches after a larger tree is grown.

Recognise（辨識；從資料找出物件或模式） this in a question: Explain purchase rules, feature（特徵；描述樣本的屬性） split（切分；按條件分開資料）, entropy（熵）, information gain（資訊增益）, many tiny leaves（葉節點；決策樹的最終輸出）

What this tells us: Moderate pruning removes unstable distinctions without losing too much purchase signal（訊號）. Heavy pruning reduces false alarms but misses too many valuable purchasers.

Which branches have too little evidence（證據；已觀察到的資訊） to keep?

  • Growing a tree repeatedly partitions training data until leaves can represent tiny exceptions. These exceptions may be real noise（雜訊；干擾有效訊息的成分） rather than stable structure; training purity therefore keeps improving after validation quality has peaked.
  • Pre-pruning prevents weak or poorly supported splits using depth, leaf-size or improvement constraints（約束條件）. Postpruning starts with a larger fitted tree and removes branches, selecting among candidates on validation evidence.
  • Pruning can alter both missed positives and false alarms. A smaller tree is preferable only when its error trade-off（取捨；改善一項可能犧牲另一項） and simplicity suit the task; aggressive pruning can erase a real minority pattern.
Implementation steps and their purpose
  1. Inspect training and validation errors
  2. Limit depth, require minimum leaf samples or demand useful split improvement
  3. Alternatively grow a tree then form simpler pruned candidates
  4. Compare candidates using validation data
  5. Keep the simplest tree with adequate task performance

Prepare the data and validate the representation（表徵；資料的表示方式）

Data, components and application

  • Tree too complex → increase leaf size or prune → reduce variance（變異數）
  • Tree too shallow misses clear patterns → relax limits cautiously → reduce underfitting（擬合不足）
  • Choose pruning from test data → use validation instead → keep the final estimate independent（獨立；知道一者不改變另一者機率）

How to evaluate it

Compare recall（召回率）, precision（精確率） and business value before and after pruning; report the trade-off rather than assuming every smaller tree is better.

Build the answer in this order

  1. Identify overfitting（過度擬合） evidence
  2. Distinguish pre- and postpruning
  3. State the selection data
  4. Explain the resulting business consequences

Common wrong answers and the exact correction
  • Pruning may change both missed positives and false alarms
  • Perfect training classification（分類；預測類別） is not the objective.

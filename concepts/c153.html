Eigenvalues（特徵值） / eigenvectors（特徵向量） and SVD（Singular Value Decomposition；奇異值分解）

For PCA（Principal Component Analysis；主成分分析）, eigenvectors specify principal directions（主方向） and eigenvalues tell how much variance（變異數） each direction captures. SVD is another way to obtain those directions from the centered data matrix.

Recognise（辨識；從資料找出物件或模式） this in a question: Correlated（相關；數值一同變化的程度） variables（變數）, fewer dimensions, retain variance, eigenvalues/loadings（負荷量；原特徵對主成分的係數）

How do singular values, eigenvalues and principal directions connect?

  • A covariance eigenvector tells a direction that the covariance transformation（變換；把資料轉成另一表示） scales without rotating; its eigenvalue is the variance along that principal direction. The words direction and amount prevent treating eigenvalues as feature（特徵；描述樣本的屬性） coefficients.
  • SVD decomposes the centered data matrix directly. Its right singular vectors give the same PCA directions, and squared singular values divided by sample count minus one give covariance eigenvalues under the sample-covariance convention.
  • For explained-variance ratios the common sample-size denominator cancels, but squaring does not. Summing singular values instead of their squares answers the wrong question. Components, loadings and observation scores are related quantities with different roles, not interchangeable tables.
Implementation steps and their purpose
  1. Prepare and center the feature matrix
  2. Obtain directions from covariance eigenvectors or from SVD of centered inputs
  3. Sort directions by eigenvalue or singular value
  4. Select component count using cumulative explained variance（累積解釋變異；保留成分合計涵蓋的變化）
  5. Project prepared observations onto the retained directions

Prepare the data and validate the representation（表徵；資料的表示方式）

Data, components and application

  • Sum raw singular values for variance → square them first → variance depends on squared singular values
  • Forget centering → center using training（訓練） means → obtain PCA directions around the mean（均值；平均數）
  • Interpret loadings as observations → distinguish directions from scores → avoid category mistakes

How to evaluate it

Check retained variance, reconstruction（重建） usefulness and downstream（後續階段；使用前一步結果的模型或流程） held-out（留出資料；未參與該階段訓練） performance; retain more components only when justified.

Build the answer in this order

  1. Explain direction versus amount
  2. Show retention arithmetic
  3. Distinguish eigenvectors/loadings from scores
  4. Apply the same fitted transform to new cases

Common wrong answers and the exact correction
  • Singular values are not themselves covariance eigenvalues
  • PCA dimensionality reduction（降維） is distinct from recommendation MF.

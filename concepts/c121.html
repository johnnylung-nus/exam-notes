C121

L1（L1懲罰；以權重絕對值作限制） / L2（L2懲罰；以權重平方作限制） regularization（正則化）

L1 and L2 add weight penalties to prediction（預測） loss（損失函數；衡量預測錯誤）. L1 encourages some weights（權重） to become exactly zero; L2 discourages large weights and usually spreads influence across smaller nonzero weights.

Recognise（辨識；從資料找出物件或模式） this in a question: Training（訓練） improves, validation worsens, memorisation, limited labelled data

Choose from the scenario

Use when training fits too closely to limited or noisy data; L1 can also support（支持度；同時出現的交易比例） feature selection（特徵選擇） in suitable models.

Scenario cueSuitable choiceWhy it fits
Want a sparse（稀疏性） original-feature linear（線性；此處加權組合加偏置） modelConsider L1 and validate the retained subsetIts optimization can produce exact zeros, unlike ordinary L2 shrinkage.

What this tells us: L2 discourages a single very large coefficient. Real fitting still balances this preference against the predictive contribution of each input.

How do L1 and L2 change the cost of large weights?

  • Regularization adds a complexity penalty to prediction loss. It can deliberately accept a larger training prediction error to improve new-case performance; comparing only the penalized objective across different strengths can be misleading.
  • L1 penalizes absolute weight sizes and may set some weights exactly to zero. L2 penalizes squared sizes, making a very large coefficient disproportionately expensive; it generally shrinks coefficients without automatically eliminating features（特徵；描述樣本的屬性）.
  • The penalty strength is tuned rather than learned as an ordinary weight. Its practical meaning depends on feature scaling（特徵縮放；令數值尺度可比較）, loss normalization（正規化；此處縮放至固定範圍） and implementation conventions, so copying a coefficient from another task is not a complete justification（給出理由；用情境與證據支持選擇）.

Common wrong answers and the exact correction
  • L2 is not guaranteed feature elimination
  • Dropout（隨機停用神經元） and batch normalization（批次正規化） work differently from explicit（明確；直接提供的資訊） weight penalties.

Apply the distinction

Data, components and application

  • Penalty too weak → increase gradually → reduce excessive flexibility
  • Penalty too strong → reduce it → avoid underfitting（擬合不足）
  • Features have incomparable scales → standardize → make penalties comparable

How to evaluate it

Look for lower validation error and a narrower generalization（泛化能力） gap, not the smallest raw training loss.

Build the answer in this order

  1. Diagnose overfitting（過度擬合）
  2. Choose penalty and explain its effect
  3. Tune strength without test reuse
  4. Compare the resulting validation performance

An answer you could write

  • “The gap suggests excessive flexibility, so I add a weight penalty and tune its strength on validation data.”
  • “A slightly worse training fit is acceptable when unseen-case performance improves.”

Where this is tested in the sample papers

ISY5002 Q2(a) — Lean CNN（Convolutional Neural Network；卷積神經網路） redesign, parameter arithmetic, activations and loss

What the question requires

  1. Locate the parameter bottleneck.
  2. Propose a smaller classifier tail（尾實體；關係終點） while preserving required outputs.
  3. Recalculate weights plus biases and total reduction.
  4. Choose activations/loss consistent（一致性） with the classification（分類；預測類別） task.
  5. Validate accuracy（準確率）, imbalance and lean deployment constraints.

Proposed answer points

  • The original tail is Flatten9408 → Dense256 → Dense128 → Dense918. Its Dense parameter counts（參數數量） are 2,408,704, 32,896 and 118,422; with 18,960 convolution（卷積） parameters（參數） the total is 2,578,982. The first Dense alone accounts for about 93.4%, so the actual bottleneck is the flattened-to-dense connection.
  • A defensible replacement is Flatten9408→Dense64→Dense918. Unchanged convolutions:18,960; Dense64:602,176; output:59,670; total:680,806. Reduction:1,898,176≈73.6%.
  • Use ReLU（Rectified Linear Unit；修正線性；負數歸零） in the hidden layers（隱藏層；中間處理層）, softmax（機率正規化；轉成總和為1的權重） over the 918 mutually exclusive combined classes（類別；分類目標）, and categorical cross-entropy（類別交叉熵；多類分類損失）. Smaller is not automatically better: check held-out（留出資料；未參與該階段訓練） quality.

Avoid: 5,000 unevenly spread images raise overfitting and class-imbalance concerns; those are related but different problems. The combined 918-way output is one design, not the only possible factorized output architecture（架構）.

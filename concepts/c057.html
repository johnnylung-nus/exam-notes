C057

GA（Genetic Algorithm；遺傳演算法） crossover（交配重組） and mutation（突變）

Crossover recombines existing parent material; mutation randomly changes components to introduce/restore diversity（多樣性）. Both depend on the chromosome（染色體） representation（表徵；資料的表示方式）.

What this tells us: Crossover can create new combinations without creating a new allele; mutation directly changes a gene. Neither guarantees higher fitness, and an invalid child cannot be judged merely by its apparent score.

What do crossover and mutation change in a chromosome?

  • Crossover rearranges material already present in parents; mutation can introduce a value absent from the current population. Their roles differ even when both change the chromosome. Selection exploits existing fitness, crossover recombines useful patterns, and mutation counters loss（損失函數；衡量預測錯誤） of diversity.
  • Operators must match encoding. Splicing binary strings is straightforward, but splicing two route permutations can repeat a city and omit another. A permutation-aware operator or repair rule is therefore a necessary part of the design, not an optional cosmetic cleanup. The repaired result must be evaluated again.
  • Rates specify expected tendencies, not exact counts in a random generation（生成式；學習資料生成或分布）. A per-bit mutation rate multiplies population size and chromosome length for expected bit changes; a per-chromosome rate means something else. Increasing mutation can restore diversity but eventually turns structured search toward randomness; high crossover can also disrupt useful combinations.
Implementation steps and their purpose
  1. Select parents first.
  2. Apply crossover if its probability test passes.
  3. Use single-point, multi-point or uniform crossover as specified.
  4. Apply mutation at the stated gene/chromosome level.
  5. Check validity, repair if required, evaluate and replace.

Prepare the data and validate the representation

Data, components and application

  • Permutation duplicates → permutation-safe crossover/repair → ordinary string splicing can invalidate routes.
  • Mutation too high → reduce rate → useful structure is lost; too low can lose diversity.

How to evaluate it

Check offspring validity, diversity and best feasible（可行；符合所有硬性條件） fitness over multiple runs. Improvement in one generation is not guaranteed.

Build the answer in this order

  1. Show parent encoding.
  2. Apply exact crossover/mutation.
  3. Check constraints（約束條件）.
  4. Explain parameter trade-off（取捨；改善一項可能犧牲另一項）.

Common wrong answers and the exact correction
  • Per-bit mutation expectation = population×length×rate, not a guaranteed count.
  • Crossover and mutation perform different roles.

An answer you could write

  • “Splitting1100 and0011 after two bits yields1111 and0000; flipping the third bit of1111 yields1101.”
  • “At per-bit rate.1, ten length-four chromosomes have four expected mutations, not a guaranteed count; route chromosomes need validity-preserving operators.”

C055

Genetic algorithm（遺傳演算法） representation（表徵；資料的表示方式） and fitness（適應度）

A genetic algorithm searches a population（族群） of encoded candidate solutions. Fitness expresses how good each decoded solution is for the actual objective and constraints（約束條件）.

Recognise（辨識；從資料找出物件或模式） this in a question: Optimise combinations, chromosome（染色體）, fitness, selection, crossover（交配重組）, mutation（突變）

How does a chromosome encode a valid candidate solution?

  • A chromosome must encode one complete candidate solution.
  • For a route, a city permutation represents visit order; for a binary selection, bits represent chosen items.
  • This choice determines which crossover/mutation operations preserve valid candidates.
  • A convenient string format is not enough if decoding creates impossible plans.
  • Fitness should reward（獎勵） the desired objective while handling constraints.
  • If the problem minimises cost but roulette favours larger fitness, the raw distance cannot be used unchanged.
  • Feasibility can be enforced by representation, repair or an explicit（明確；直接提供的資訊） justified penalty; an invalid short route must not beat a valid complete tour.
  • Population search explores several candidates and recombines useful parts, but it does not guarantee improvement every generation（生成式；學習資料生成或分布） or a global optimum（全域最優解）.
  • Track the best feasible solution separately, use a budget/stopping rule and compare repeated runs.
  • Diversity（多樣性） is a resource: too little can trap the population, while too much random variation slows refinement.
Implementation steps and their purpose
  1. Define what one full solution contains.
  2. Choose chromosome encoding: bits, real values, integers or a permutation.
  3. Define objective, constraints and fitness direction.
  4. Initialise a diverse population and evaluate it.
  5. Select, recombine, mutate and replace repeatedly until a stopping rule.

Data, components and application

  • Fitness ignores constraint → enforce validity/penalty/repair → a high score may otherwise be unusable.
  • Poor encoding → choose meaningful representation → search operates on encoded solutions, not business intent（意圖）.

How to evaluate it

Track best feasible objective, runtime and variability across runs; compare a simple baseline（基準；供比較的簡單方法）. No automatic global-optimum guarantee.

Build the answer in this order

  1. Define solution and encoding.
  2. Specify fitness/constraints.
  3. Explain generation loop.
  4. Set stop and evaluate.

Common wrong answers and the exact correction
  • Fitness may require transforming a cost-minimisation objective.
  • A population member is one candidate solution, not one feature（特徵；描述樣本的屬性）.

When would this calculation be useful?

Useful for large optimisation spaces where exhaustive search is impractical and a good approximate feasible solution is acceptable.

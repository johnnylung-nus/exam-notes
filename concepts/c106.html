ADALINE（Adaptive Linear Neuron；自適應線性神經元） and delta rule（差值學習規則）

ADALINE learns from the continuous（連續；可在範圍內連續變化） weighted sum before thresholding. The delta rule changes weights（權重） to reduce squared prediction（預測） error, rather than using only the final class（類別；分類目標） decision.

Recognise（辨識；從資料找出物件或模式） this in a question: Continuous target, probability（機率）, straight-line boundary, local neighbours

For the perceptron use its thresholded prediction; for ADALINE’s delta rule use the linear output before thresholding. Do not interchange these y definitions.

  1. Start w=0.2,b=0; y=0.2×2=0.4.
  2. Error=1−0.4=0.6; Δw=0.12; Δb=0.06.
  3. New w=0.32,b=0.06; y=0.70.
  4. Half-squared error falls from0.18 to0.045.

What this tells us: This step reduces the continuous prediction error. Applying the final bipolar threshold（門檻值） is a separate output decision, not the number inserted into the delta rule.

Why does ADALINE update from the linear output error?

  • ADALINE trains against the continuous weighted sum, so the size of a mistake matters even before the threshold is applied. A small error produces a small update rather than the same correction as any other wrong binary output.
  • Squared-error loss is smooth in the weights of a linear unit. Moving against its gradient（梯度） gives the delta rule: learning rate × target-minus-linear-output × input. State whether the half-squared-error convention is used if doing derivative（導數；輸入微變時輸出改變多少） arithmetic.
  • The final threshold may provide a class label（標籤；作比較的正確答案）, but it is outside the differentiable training signal（訊號）. Confusing the linear output with the thresholded output erases the core distinction from a perceptron（感知器）.
Implementation steps and their purpose
  1. Calculate the continuous weighted sum
  2. Subtract it from the target
  3. Multiply error by input and learning rate to obtain the weight adjustment
  4. Update weights and repeat
  5. Apply a threshold if a final binary class is required

Use the result and check it

Data, components and application

  • Unscaled inputs cause unstable updates → standardize → gradients are better balanced
  • Nonlinear（非線性；不能只用線性關係表示） target → add nonlinear hidden structure → a single linear unit cannot express it

How to evaluate it

Track mean squared error（均方誤差；誤差平方後平均） on training and validation data, and classification（分類；預測類別） performance if a threshold is applied.

Build the answer in this order

  2. Calculate the error
  3. Show the update

Common wrong answers and the exact correction
  • Do not compute ADALINE learning error from the thresholded class
  • ADALINE is not automatically a multilayer nonlinear model.

When would this calculation be useful?

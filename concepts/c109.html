RBF（Radial Basis Function；徑向基底函數） networks

An RBF network describes an input by its closeness to hidden-unit centers. Nearby inputs activate a Gaussian（高斯分布；常見鐘形分布） basis function strongly; the output combines these responses.

Recognise（辨識；從資料找出物件或模式） this in a question: Nonlinear（非線性；不能只用線性關係表示） prediction（預測）, hidden layer（隱藏層；中間處理層）, weights（權重）, bias（偏置／偏差；須看語境）, backpropagation（反向傳播；計算各參數梯度）

What this tells us: This RBF output is a learned linear combination; it need not divide by the sum of responses. That distinguishes it from the normalized local average in GRNN（General Regression Neural Network；廣義迴歸神經網路）.

How does distance from a centre determine an RBF response?

  • An RBF unit asks how close the input is to a center, not on which side of a global straight boundary it lies.
  • Its Gaussian response is strongest at the center and declines as distance grows.
  • The width determines a unit’s area of influence. Small widths create many narrow local bumps; large widths combine evidence（證據；已觀察到的資訊） over broad regions. The right choice depends on the data density and target smoothness.
  • Two-stage training（訓練） separates representation（表徵；資料的表示方式） from target fitting: cluster the prepared inputs to obtain centers and widths, then use labeled examples to learn the output combination.
  • Center selection can therefore use unlabeled training inputs, but evaluation（評估） still needs held-out（留出資料；未參與該階段訓練） targets.
Implementation steps and their purpose
  1. Scale inputs before calculating distances
  2. Choose hidden centers, often using clustering（分群）
  3. Set a width for each center
  4. Calculate radial responses for each training input
  5. Learn supervised output weights

Choose the method from the problem

Useful for nonlinear mapping when local regions in feature space（特徵空間；以特徵作座標的空間） provide a meaningful representation.

Common wrong answers and the exact correction
  • An RBF hidden unit measures distance, not a perceptron-style global boundary
  • Scaling changes those distances.

Data, components and application

  • Widths too narrow → validate wider widths → avoid memorizing isolated training cases
  • Widths too broad → reduce widths or add centers → distinguish meaningful regions
  • Many centers → reduce them with clustering → control model size

How to evaluate it

Tune center count and widths using validation classification（分類；預測類別） or regression（迴歸；預測連續數值） error; compare against a simple baseline（基準；供比較的簡單方法）.

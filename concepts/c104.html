C104

Artificial neuron（人工神經元）, weights（權重）, bias（偏置／偏差；須看語境）, activation（激活函數；轉換神經元輸出）

A neuron combines inputs using learned weights, adds a bias, then applies an activation. Weights control input influence; bias shifts the point at which the neuron responds.

Recognise（辨識；從資料找出物件或模式） this in a question: Continuous（連續；可在範圍內連續變化） target, probability（機率）, straight-line boundary, local neighbours

Follow one neuron from evidence to output

Worked study example: Illustrative binary neuron: page engagement input 2, exit-rate input 0.5; their weights are 0.8 and −1.2; bias is −0.4. The numbers illustrate arithmetic, not a fitted bookstore model.

All steps shown
OperationCalculationMeaning
Engagement contribution2 × 0.8 = 1.6Supports the positive output
Exit contribution0.5 × (−1.2) = −0.6Opposes the positive output
Add bias1.6 − 0.6 − 0.4 = 0.6Pre-activation total
Apply sigmoid（S形函數）1 / (1 + exp(−0.6)) ≈ 0.646One bounded prediction（預測） score

What this tells us: At decision threshold（門檻值） 0.5 this predicts the positive class（類別；分類目標）. Raising the decision threshold to 0.7 changes the decision without changing the learned weights.

How do weights, bias and activation produce one neuron's output?

  • Think of each weight as a learned sensitivity（敏感度；找出正類的比例）: increasing an input by one changes the pre-activation total by that input’s weight, while the other inputs stay fixed.
  • A negative weight contributes evidence in the opposite direction.
  • The bias moves the boundary without requiring any measured input to change. Treat it as an adjustable constant, not as a new property measured from the visitor or image.
  • The activation acts after the weighted sum.
  • A hard threshold turns the total into a class; sigmoid turns it into a bounded score; a hidden nonlinear（非線性；不能只用線性關係表示） activation allows combinations that a single linear（線性；此處加權組合加偏置） equation cannot express.
Implementation steps and their purpose
  1. Encode each input numerically
  2. Multiply inputs by their weights and add the bias
  3. Apply the chosen activation
  4. Compare output with the training（訓練） target and update weights

Data, components and application

  • Different input scales distort learning → scale using training statistics → inputs become comparable
  • Only linear layers → add nonlinear hidden activations → stacked layers can represent nonlinear patterns

How to evaluate it

Choose classification metrics（分類評估指標） or regression（迴歸；預測連續數值） error to match the target; training output alone does not establish generalization（泛化能力）.

Build the answer in this order

  1. Identify the input values
  2. Explain weight and bias roles
  3. Calculate total then activation
  4. Match final activation to the required output

Diagnose: The model ignores a numerically small input

What you observeWhy it happensWhat to changeWhy that helps
The model ignores a numerically small inputInputs use incompatible unitsScale with training-only statisticsA unit change then has a comparable numerical（數值型；以數量表示） meaning, so optimization is less dominated by the largest scale.
Common wrong answers and the exact correction
  • A bias is learned, not an additional measured customer attribute（屬性；對象的描述欄位）
  • Activation is not the loss function（損失函數；衡量預測錯誤）.

When would this calculation be useful?

Use neurons as building blocks when the relationship between inputs and target must be learned from examples.

Scenario cueSuitable choiceWhy it fits
A binary decision is requiredUse one probability output and a chosen thresholdSeparates the model’s score from the business decision; a costly false negative（假負例；正類誤判為負） can justify（給出理由；用情境與證據支持選擇） a lower threshold.

An answer you could write

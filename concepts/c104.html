Artificial neuron, weights, bias, activation

A neuron combines inputs using learned weights, adds a bias, then applies an activation. Weights control input influence; bias shifts the point at which the neuron responds.

Recognise this in a question: Continuous target, probability, straight-line boundary, local neighbours

Follow one neuron from evidence to output

Worked study example: Illustrative binary neuron: page engagement input 2, exit-rate input 0.5; their weights are 0.8 and −1.2; bias is −0.4. The numbers illustrate arithmetic, not a fitted bookstore model.

All steps shown
OperationCalculationMeaning
Engagement contribution2 × 0.8 = 1.6Supports the positive output
Exit contribution0.5 × (−1.2) = −0.6Opposes the positive output
Add bias1.6 − 0.6 − 0.4 = 0.6Pre-activation total
Apply sigmoid1 / (1 + exp(−0.6)) ≈ 0.646One bounded prediction score

What this tells us: At decision threshold 0.5 this predicts the positive class. Raising the decision threshold to 0.7 changes the decision without changing the learned weights.

How do weights, bias and activation produce one neuron's output?

  • Think of each weight as a learned sensitivity: increasing an input by one changes the pre-activation total by that input’s weight, while the other inputs stay fixed. A negative weight contributes evidence in the opposite direction.
  • The bias moves the boundary without requiring any measured input to change. Treat it as an adjustable constant, not as a new property measured from the visitor or image.
  • The activation acts after the weighted sum. A hard threshold turns the total into a class; sigmoid turns it into a bounded score; a hidden nonlinear activation allows combinations that a single linear equation cannot express.
Implementation steps and their purpose
  1. Encode each input numerically
  2. Multiply inputs by their weights and add the bias
  3. Apply the chosen activation
  4. Compare output with the training target and update weights

Data, components and application

  • Different input scales distort learning → scale using training statistics → inputs become comparable
  • Only linear layers → add nonlinear hidden activations → stacked layers can represent nonlinear patterns

How to evaluate it

Choose classification metrics or regression error to match the target; training output alone does not establish generalization.

Diagnose: The model ignores a numerically small input

What you observeWhy it happensWhat to changeWhy that helps
The model ignores a numerically small inputInputs use incompatible unitsScale with training-only statisticsA unit change then has a comparable numerical meaning, so optimization is less dominated by the largest scale.
Common wrong answers and the exact correction
  • A bias is learned, not an additional measured customer attribute
  • Activation is not the loss function.

When would this calculation be useful?

Use neurons as building blocks when the relationship between inputs and target must be learned from examples.

Scenario cueSuitable choiceWhy it fits
A binary decision is requiredUse one probability output and a chosen thresholdSeparates the model’s score from the business decision; a costly false negative can justify a lower threshold.

An answer you could write

  • “Each input contributes its value multiplied by a learned weight; the bias shifts the response.”
  • “The activation converts the combined evidence into the required output; the decision threshold is selected using the error costs.”

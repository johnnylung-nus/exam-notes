Hierarchical clustering（階層式分群） and linkage（連結準則；計算群與群的距離）

Hierarchical clustering creates nested groups displayed in a dendrogram（樹狀圖；顯示群合併層次）. Agglomerative（凝聚式） clustering（分群） starts with one cluster per observation and repeatedly merges the closest pair. Linkage defines distance between clusters.

What does the linkage rule mean when merging clusters?

  • Agglomerative clustering starts with individual observations（觀測值） and merges the nearest pair of current clusters. Because a merge is generally not undone, early distance and linkage choices shape the whole hierarchy.
  • Linkage answers what close clusters means: single uses nearest cross-pair, complete uses farthest cross-pair, average uses average cross-pairs, and Ward uses the increase in within-group squared error. These are different grouping preferences.
  • A dendrogram records merge order and height. Cutting it produces a chosen group count or distance level; large merge gaps can suggest a useful cut but need substantive profile and stability checks.
Implementation steps and their purpose
  1. Prepare features（特徵；描述樣本的屬性） and choose observation distance
  2. Start with individual clusters
  3. Calculate inter-cluster（群間；不同群之間的關係） distances under the chosen linkage
  4. Merge the closest pair
  5. Repeat and record merge heights
  6. Cut the dendrogram at a justified level and profile groups

Prepare the data and validate the representation（表徵；資料的表示方式）

Data, components and application

  • Single-link chains connect distinct groups → compare complete/average linkage → alter the grouping criterion
  • Outliers（離群值） dominate merges → investigate → avoid interpreting noise（雜訊；干擾有效訊息的成分） as a segment
  • Many observations → consider cost → pairwise calculations can be expensive

How to evaluate it

Inspect dendrogram stability, separation and substantive group profiles; compare plausible linkage choices.

Build the answer in this order

  1. Explain merge sequence（序列；有先後順序的資料）
  2. State linkage meaning
  3. Choose a defensible cut
  4. Interpret groups and limitations

Common wrong answers and the exact correction

  • Hierarchical merging usually cannot undo a bad earlier merge.

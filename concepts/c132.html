Gradient boosting（梯度提升）

Gradient boosting builds an additive model sequentially. Each new learner addresses the current loss（損失函數；衡量預測錯誤） errors; with squared-error regression（迴歸；預測連續數值） this corresponds to learning the remaining residuals.

Fit and apply a residual correction

Worked study example: Illustrative regression targets are [10,20,30]. Start with their mean（均值；平均數） 20 for every case. A small new tree approximates residuals as [−8,1,7]. Learning rate（學習率） is 0.1.

What this tells us: The learner need not reproduce every residual exactly to reduce the loss. Further rounds fit what remains, under validation control.

What error does the next gradient-boosting learner fit?

  • Gradient boosting changes the ensemble（集成學習） prediction in the direction that reduces a chosen loss. With squared error, the needed correction is the residual: actual target minus current prediction.
  • A new learner fits correction targets derived from the current ensemble, then contributes a scaled update. The learning rate controls each learner’s influence; more small steps can generalize differently from a few large corrections.
  • For other losses the correction is based on the loss gradient（梯度）, not always the raw residual. This is why saying every boosting（提升法） method reweights mistakes exactly like AdaBoost is incorrect.
Implementation steps and their purpose
  1. Choose a task-appropriate differentiable loss
  2. Start with a simple constant prediction
  3. Calculate what changes would reduce current loss
  4. Fit a small learner to those correction targets
  5. Add a scaled correction using a learning rate
  6. Monitor validation performance across rounds

Use the result and check it

Data, components and application

  • Training improves while validation declines → fewer rounds or early stopping（提前停止） → avoid fitting noise（雜訊；干擾有效訊息的成分）
  • Large updates → lower learning rate → make gradual corrections
  • Deep trees → reduce depth → restrict interactions and capacity

How to evaluate it

Use held-out（留出資料；未參與該階段訓練） RMSE（Root Mean Squared Error；均方根誤差）/MAE（Mean Absolute Error；平均絕對誤差） for regression or suitable classification metrics（分類評估指標） and loss; compare model size and latency.

Build the answer in this order

  1. Identify target and loss
  2. Explain sequential corrections
  3. Justify learning rate and depth
  4. Check validation optimum

Common wrong answers and the exact correction
  • Residual fitting is the squared-loss special case
  • Gradient boosting is not simply reweighting observations（觀測值） exactly as AdaBoost does.

When would this calculation be useful?

Useful for strong nonlinear（非線性；不能只用線性關係表示） tabular prediction where shallow trees can gradually correct systematic errors.

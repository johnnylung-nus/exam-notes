C073

Speech recognition（語音辨識）

Automatic speech recognition（自動語音辨識） converts recorded speech to text. NLU（Natural Language Understanding；自然語言理解） then determines what that text means for the task.

What this tells us: A transcript can sound plausible and still be wrong. The final action should depend on verified critical fields rather than an assumption（假設；答案依賴但題目未明說的條件） that every recognized word is correct.

How does the speech signal（訊號） become a word sequence（序列；有先後順序的資料）?

  • ASR predicts words from audio; NLU predicts intent（意圖） and details from those words. A transcription error can therefore become an incorrect action downstream（後續階段；使用前一步結果的模型或流程）.
  • Errors affecting an important slot（資訊欄位） may matter more than errors in ordinary wording. “Fifteen” versus “fifty” changes a timer even if the rest is correct.
  • Real input includes noise（雜訊；干擾有效訊息的成分）, accents, spontaneous phrasing, reverberation and overlapping speakers. Testing only read speech omits these failure conditions.
  • A correction/retry path can improve task completion even when model-level word error is unchanged. The interface design matters alongside the recognizer.
Implementation steps and their purpose
  1. Capture speech using the expected audio format.
  2. Preprocess the recording where necessary.
  3. Run the speech-recognition model.
  4. Pass the transcript to NLU/dialogue processing.
  5. Allow correction or retry when the task-critical words are uncertain.

Prepare the data and validate the representation（表徵；資料的表示方式）

Data, components and application

  • Noise/reverberation → improve recording and representative tests → reduces recognition errors.
  • Overlapping speakers → manage input conditions → one transcript may mix sources.
  • Spontaneous speech or accents → test realistic user speech → read-speech performance is insufficient.

How to evaluate it

Use word error rate for transcript quality, then task completion, corrections and retries for the complete interface.

Build the answer in this order

  1. Voice task.
  2. Audio → transcript → intent/action.
  3. Likely recognition failures.
  4. Measure transcript and task success.

Common wrong answers and the exact correction
  • Speech recognition identifies words; speaker recognition identifies who spoke.
  • Low overall word error can still hide an important slot error.

An answer you could write

  • ASR converts speech into a transcript; NLU then extracts the intent and action-critical fields.
  • A fifteen/fifty recognition error changes the reminder interval, so uncertain critical values need correction or confirmation.
  • Evaluate word error rate and complete-task success, retries and response time separately.

C078

Multimodal cognition（多模態認知）

Multimodal cognition combines different input types and knowledge to interpret a situation more completely than one modality（模態；資料形式如語音或影像） alone.

Recognise（辨識；從資料找出物件或模式） this in a question: Multiple sensors（感測器）, camera + sound, conflicting measurements, alignment（對齊）

When do different modalities provide complementary evidence?

  • Different modalities can provide complementary evidence, but combination must preserve who/what/time each observation refers to.
  • A visual sign and a patient detail are not interchangeable raw inputs: each needs its own acquisition, validation and representation.
  • Combining evidence can happen through intermediate features or through interpreted outputs. The architecture should say which rather than simply draw many arrows into AI（Artificial Intelligence；人工智慧）.
  • A missing modality should create a defined incomplete-evidence condition, not a fabricated substitute measurement.
Implementation steps and their purpose
  1. State what each input contributes.
  2. Process each modality into useful information.
  3. Align observations（觀測值） belonging to the same event.
  4. Combine representations or decisions.
  5. Apply knowledge to the combined evidence.
  6. Return a decision with uncertainty（不確定性） and a defined action.

Data, implementation and validation

Data, components and application

  • Inputs refer to different times/people → align records → prevents invalid combinations.
  • One input unreliable → represent quality or seek another reading → extra modalities are not automatically helpful.
  • Black-box fusion（融合） → label what passes between components → makes the design explainable.

How to evaluate it

Compare with single-input baselines, test missing/noisy inputs and check full task correctness.

Build the answer in this order

  1. Need for multiple evidence types.
  2. Per-input processing.
  3. Alignment and combination.
  4. Decision and evaluation（評估）.

Common wrong answers and the exact correction
  • Multiple sensors of one type are not necessarily different modalities.
  • Fusion does not guarantee improvement.

An answer you could write

  • The App’s visual sign becomes one Web input alongside doctor-entered patient details and other signs.
  • Associate all observations with the same case/session before applying reusable knowledge.
  • Keep diagnostic possibilities, urgency and recommended action as distinct output fields, and represent missing or uncertain evidence explicitly.

Superposition（疊加） and signal decomposition（訊號分解）

Superposition builds a signal（訊號） by scaling and adding simpler components. Decomposition works in the other direction to make complex behaviour easier to analyze.

Recognise（辨識；從資料找出物件或模式） this in a question: Frequency（頻率） peaks, periodic（週期性） components, filter noise（雜訊；干擾有效訊息的成分）, convolution（卷積）

What this tells us: The components and their weights（權重） jointly specify the representation（表徵；資料的表示方式）. The weight 3 is not itself the changing component; it scales that component.

How do component signals combine into an observed signal?

  • A linear combination scales components and adds them. The weights say how much of each basis component contributes to the signal.
  • Decomposition chooses a representation where useful structure is easier to inspect; reconstruction（重建） returns to the original representation by adding weighted components.
  • Keeping every component can reproduce the signal, while dropping components produces an approximation whose errors must be assessed.
  • Superposition is conditional on linear behaviour. Products of two input signals are not the same operation as adding scaled signals.
Implementation steps and their purpose
  1. State the observed signal and relevant（相關性；是否切合問題） component types.
  2. Choose a suitable basis or component representation.
  3. Find component weights.
  4. Study useful components separately.
  5. Add weighted components to reconstruct or approximate the signal.
  6. Check what information the approximation loses.

Use the result and check it

Data, components and application

  • Wrong basis → choose components matched to the signal/task → improves interpretability.
  • Too few components → retain additional useful ones → reduces reconstruction loss（損失函數；衡量預測錯誤）.
  • Assuming linearity without checking → state the linear-system condition → superposition is not universal.

How to evaluate it

Compare reconstructed with original signal and check whether retained components preserve the task-relevant event.

Build the answer in this order

  1. Complex signal problem.
  2. Decomposition choice.
  3. Component interpretation or reconstruction.
  4. Information retained versus lost.

Common wrong answers and the exact correction
  • Linear superposition uses scaling and addition, not multiplication of signals.
  • Small reconstruction error（重建誤差；還原值與原資料的差距） alone does not prove useful classification（分類；預測類別）.

When would this calculation be useful?

Use when a sensor（感測器） signal combines multiple patterns and a simpler component representation is useful.

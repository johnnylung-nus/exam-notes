C149

Curse of dimensionality（維度災難）

As feature（特徵；描述樣本的屬性） count grows, data becomes sparse（稀疏性） in the expanded space. More observations（觀測值） are needed to cover it, and distances can become less discriminative（判別式；著重區分輸入所屬類別）, hurting generalization（泛化能力） and neighbor-based methods.

Recognise（辨識；從資料找出物件或模式） this in a question: Very few faults, only two anomalies, rare abnormal event · Too many variables（變數）, irrelevant inputs, select features, dimensionality（維度；描述資料所需的座標數） harms distance

Show why coverage falls as dimension grows

Why do distances become less useful with many features?

  • Adding dimensions expands the space the observations must cover. With a fixed sample, neighborhoods contain less local evidence, and irrelevant features can make distances reflect noise（雜訊；干擾有效訊息的成分） rather than target-relevant similarity（相似度）.
  • A feature count that is manageable for thousands of normal cases can still be unsupported for two abnormal cases. The rare class’s independent coverage matters; aggregate（彙總；把多筆資料合併成統計值） sample size conceals this asymmetry（非對稱；交換方向不一定相同）.
  • Feature selection（特徵選擇） retains original variables; PCA（Principal Component Analysis；主成分分析） combines correlated（相關；數值一同變化的程度） variables; a smaller model restricts fitting capacity. Each targets a different source of difficulty, and none creates examples of fault mechanisms not observed in training（訓練）.
Implementation steps and their purpose
  1. Compare useful sample count with feature count and model capacity
  2. Inspect irrelevant, repeated or noisy features
  3. Select a smaller meaningful feature subset
  4. Consider PCA when correlated numeric features can be compressed
  5. Validate the complete reduction-plus-model pipeline（處理流程）

Prepare the data and validate the representation（表徵；資料的表示方式）

Data, components and application

  • Many weak dimensions → remove or combine features → improve sample efficiency
  • Two anomalies reused repeatedly → collect varied anomalies → do not mistake duplication for coverage
  • Distance dominated by noise → scale and select relevant（相關性；是否切合問題） features → restore useful similarity

How to evaluate it

Compare held-out（留出資料；未參與該階段訓練） rare-case recall（召回率）, false-alarm rate and model stability across splits; acknowledge large uncertainty（不確定性） with few faults.

Build the answer in this order

  1. Explain why available cases do not cover the space
  2. Identify an appropriate reduction
  3. Preserve prediction-relevant information
  4. Evaluate without leakage

Common wrong answers and the exact correction
  • High dimension is not automatically fatal with abundant relevant data
  • Dimensionality reduction（降維） cannot manufacture missing anomaly diversity（多樣性）.

An answer you could write

  • “Thirty features do not guarantee thirty useful diagnostic signals（訊號）; only two abnormal cases cannot establish their abnormal relationships.”
  • “I reduce unsupported complexity and collect independent faults rather than treating oversampling（過度抽樣；增加少數類樣本） as new coverage.”

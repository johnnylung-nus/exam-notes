Supervised / unsupervised / reinforcement learning（強化學習）

Supervised learning（監督式學習） uses input–target examples; unsupervised learning（非監督式學習） discovers structure without target labels（標籤；作比較的正確答案）; reinforcement learning learns actions（動作） from rewards received through interaction.

Recognise（辨識；從資料找出物件或模式） this in a question: Predict a labelled outcome, discover groups, choose an action by reward（獎勵） · Robot sorting, actions change environment, reward, safe learning

What this tells us: The last choice addresses missing anomaly coverage（涵蓋率；能服務的使用者或項目範圍）; it does not turn two known faults into reliable evidence（證據；已觀察到的資訊） about all abnormal situations.

Do we learn from labels, structure or rewards?

  • The type of feedback determines the learning setup. Supervised cases have target labels; unsupervised cases supply inputs but no correct category; reinforcement learning supplies consequences of actions taken through time.
  • Sequence inputs do not automatically imply reinforcement learning. Purchase prediction（預測） from a labeled browsing sequence is supervised; robot actions that change subsequent observations（觀測值） and reward create a control problem.
  • Scarce fault labels can make a two-class model poorly supported even with abundant normal data. A normal-pattern anomaly model asks whether an observation differs from learned normal behavior; it does not automatically identify every fault cause.

Common wrong answers and the exact correction
  • Reward is not the same as a correct class label
  • Unsupervised learning does not provide known class meanings automatically.

Apply the distinction

Data, components and application

  • Only two abnormal examples → supervised fault coverage is unreliable → consider normal-pattern anomaly modeling while collecting more anomalies
  • A sequence exists but actions do not change outcomes → supervised sequence prediction may suffice → sequence data alone does not imply reinforcement learning

How to evaluate it

Use held-out（留出資料；未參與該階段訓練） prediction error for supervised learning, meaningful stable groups for clustering, and cumulative reward plus safety/task success for control.

Build the answer in this order

  1. State what feedback exists
  2. Classify the learning type
  3. Match model to output
  4. Explain how success is measured

An answer you could write

  • “Purchase prediction is supervised because every session has an outcome label, even though its inputs form a sequence.”
  • “Robot control is reinforcement learning because actions change future states and are judged by cumulative task, safety and time consequences.”

Where this is tested in the sample papers

ISY5002 Q2(b) — Deep-RL sorting architecture（架構）, reward and safe learning

What the question requires

  1. Define observations/state, actions and task success.
  2. Choose reward terms for correct sorting, safety and time.
  3. Draw hardware, perception（感知；由輸入理解環境）, decision and control loops.
  4. Explain simulation-first training（訓練） and controlled transfer.

Proposed answer points

  • RGB-D（Red, Green, Blue–Depth；彩色加深度影像） + robot sensors → identification/tracking → state → deep-RL policy（策略） → safety/motion checks → arm/gripper（夾爪；機器人抓取物件的部件） action → new observations and reward. Include target objects, obstacles, other robots and people in the environment.
  • Reward correct placement; penalize collisions and unnecessary time. Enforce joint/gripper constraints（約束條件） in control rather than hoping a learned reward guarantees safety.
  • Train in a physics-based（基於物理；模擬運動、接觸等物理規律） simulator（模擬；先在虛擬環境測試或學習）, then validate in controlled low-risk real tests with safety constraints active.

Avoid: A reward penalty is not a hard safety guarantee. Classification of the object（客體；三元組終點） and control of the robot are separate responsibilities.

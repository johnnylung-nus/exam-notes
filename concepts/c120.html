Xavier / He initialization（初始化）

Initialization sets starting weights（權重） before learning. Random weights break symmetry（對稱；交換方向仍相同）; their scale should avoid making activations or gradients disappear or grow excessively through the network.

Recognise（辨識；從資料找出物件或模式） this in a question: Loss（損失函數；衡量預測錯誤） spikes, gradients vanish/explode, deep model not learning

Interpret the result: Random weights break symmetry; suitable variance preserves signal（訊號） scale.

How does initial weight scale affect signal and gradient flow?

  • Identical zero connecting weights leave hidden units symmetric: identical inputs generate identical responses and matching gradients.
  • Random connecting weights allow units to develop different useful features; zero biases do not create the same problem when weights differ.
  • Weight scale controls activation（激活函數；轉換神經元輸出） and gradient propagation. Excessively large sigmoid（S形函數） totals saturate; excessively small values attenuate signals across depth. The appropriate distribution depends on the number of incoming connections and chosen activation.
  • He initialization accounts for ReLU（Rectified Linear Unit；修正線性；負數歸零） suppressing negative responses.
  • Xavier-style methods balance signal propagation for sigmoid/tanh-type networks.
  • Several Xavier conventions exist, so use the lecture’s or implementation’s stated formula instead of mixing fan-in and fan-out definitions.
Implementation steps and their purpose
  1. Identify hidden activation type
  2. Choose Xavier-style initialization for sigmoid/tanh（雙曲正切函數） networks
  3. Choose He initialization for ReLU networks
  4. Start biases at zero when appropriate
  5. Train and inspect activation, gradient and loss behavior

Data, components and application

  • All weights identical → randomize → neurons can learn different features
  • Huge initial weights saturate sigmoid → reduce scale → maintain useful derivatives
  • Tiny initial weights → choose suitable variance → preserve signals across depth

How to evaluate it

Check stable convergence（收斂；結果逐步趨於穩定） and validation performance across reasonable random seeds; initialization is one part of the training setup.

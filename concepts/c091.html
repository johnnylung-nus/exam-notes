Gaussian mixtures（高斯混合模型） / expectation maximization（期望最大化）

A Gaussian mixture models several overlapping groups. Expectation maximization (EM) alternates estimating hidden group membership（隸屬度） and updating model parameters（參數）.

How do soft assignments and parameter updates alternate in EM?

  • EM solves a circular estimation problem: component distributions（分布） require memberships, while memberships require distributions. Initialization breaks the circle and iteration refines both.
  • The E-step assigns probabilities, not necessarily hard labels（標籤；作比較的正確答案）. Each observation can contribute fractionally to several components.
  • The M-step treats those probabilities as weights（權重） when updating distributions and mixture proportions. Counts are therefore weighted totals rather than ordinary integers.
  • A mixture model describes multiple subpopulations; its fitted components are not automatically meaningful real-world classes（類別；分類目標） without interpretation and validation.
Implementation steps and their purpose
  1. Choose component count and initialize parameters/mixture proportions.
  2. E-step: estimate each observation’s probability of belonging to each component.
  3. M-step: update component parameters using those weighted memberships.
  4. Update mixture proportions.
  5. Repeat until the stopping condition.
  6. Check sensitivity to initialization and fit.

Use the result and check it

Data, components and application

  • Unknown labels → soft memberships → each observation can contribute to both components.
  • Poor initialization → compare plausible starts → one run may give a poor solution.
  • Too simple model → assess component count → multiple peaks may need multiple components.

How to evaluate it

Inspect fit, convergence and stability; evaluate downstream classification（分類；預測類別） if that is the goal.

Build the answer in this order

  1. Mixed data without labels.
  2. Initialize.
  3. Estimate memberships ↔ update distributions.
  4. Check fit and limitations.

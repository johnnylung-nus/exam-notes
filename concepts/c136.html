C136

Normalization（正規化；此處縮放至固定範圍） and preprocessing（前處理）

Preprocessing makes data usable without changing what the prediction（預測） means. Cleaning handles missing, noisy or inconsistent values; encoding represents categories; scaling makes numeric（數值型；以數量表示） magnitudes comparable.

Recognise（辨識；從資料找出物件或模式） this in a question: Sensor（感測器） waveform, sample rate（取樣率；每秒取樣次數）, aliasing（混疊）, units, sign, thresholds · Preprocessing, leakage, small dataset, validation, tune hyperparameters（超參數）

Prepare a concatenated sensor representation（表徵；資料的表示方式）

Worked study example: Illustrative training（訓練） duration values have mean（均值；平均數） 20 and standard deviation（標準差；資料分散程度） 5. A wavelet energy feature has mean 100 and standard deviation 20. Use those fitted statistics for a new sequence（序列；有先後順序的資料）.

What this tells us: Before scaling, energy’s raw magnitude is much larger; afterward these values reflect deviations relative to each feature’s training variation.

Reuse training statistics for validation/test. Handle zero standard deviation or zero range explicitly; unseen values can lie outside [0,1].

  1. Duration30s,training mean20s,SD5s givesz=2.
  2. Energy120,training mean100,SD20 givesz=1.
  3. Missing duration is not the same as a true zero;fit an explicit（明確；直接提供的資訊） missing-value rule.

Interpret the result: Comparable numeric scale does not guarantee useful diagnostic content.

Which preprocessing changes the meaning or scale of the inputs?

  • Preparation must preserve meaning: missing duration is not a real zero-duration visit, and an extreme vibration（振動；來回震動的訊號） value may be the fault to detect rather than removable noise（雜訊；干擾有效訊息的成分）. Cleaning requires the task context.
  • Fit transformation（變換；把資料轉成另一表示） parameters（參數） only on training records. Imputation values, category vocabularies, scaling means and PCA（Principal Component Analysis；主成分分析） directions all carry information from the data used to fit them, even without using labels（標籤；作比較的正確答案） explicitly.
  • For concatenated features, different scales can dominate distances or gradient（梯度） updates. Histogram（直方圖；統計各數值區間的出現次數） counts and wavelet statistics may need different preparation before concatenation（串接；沿指定方向接起來）; scaling does not make unsuitable features informative.
Implementation steps and their purpose
  1. Split（切分；按條件分開資料） data before fitting preparation steps
  2. Inspect missing values（缺失值）, outliers（離群值） and invalid records
  3. Fit imputation and category encoding on training data
  4. Fit min–max scaling or standardization（標準化；減均值再除標準差） where useful
  5. Apply the same fitted transformations to validation, test and future data

Data, components and application

  • Missing value is coded zero → distinguish missingness from a real zero → avoid false evidence（證據；已觀察到的資訊）
  • Huge scale differences → standardize → prevent domination of distances
  • Outliers may be real faults → investigate before removal → do not delete the target phenomenon

How to evaluate it

Check prepared ranges, missingness by class（類別；分類目標） and held-out（留出資料；未參與該階段訓練） model quality; preprocessing should improve validity（推論有效性）, not merely make training easier.

Build the answer in this order

  1. Identify the data defect
  2. Specify the transformation
  3. Explain the training-only fitting rule
  4. Show why it helps the chosen model

Choose the representation from the task

Especially important for distance models, neural networks（神經網路） and PCA, or when multiple sources have incompatible units.

Common wrong answers and the exact correction
  • Never fit a scaler or PCA on the test set（測試集）
  • Raw neighboring image pixels are often correlated（相關；數值一同變化的程度）, not automatically independent（獨立；知道一者不改變另一者機率） features.

An answer you could write

  • “I retain genuine abnormal sensor values and distinguish missing measurements from zero readings.”

ISY5001 Q2(g) — Check formula scale, sign and threshold（門檻值）

What the question requires

  1. Keep relative size as pupil（瞳孔；眼睛中央讓光進入的開口） pixels / iris（虹膜；圍繞瞳孔的有色部分） pixels.
  2. Check the fractional scale against the threshold.
  3. Apply absolute value to the whole left–right difference.
  4. State the percentage interpretation and strictness.

Proposed answer points

  • Under a 30-percentage-point interpretation: abs(left_mean − right_mean) > 0.30. This is equivalent to abs(left_mean − right_mean)/0.30 > 1.
  • For 0.20 versus 0.60, absolute difference = 0.40; dividing by 0.30 gives about 1.33.

Avoid: The case’s “30%” is ambiguous: a relative-percent definition requires a reference denominator. Do not present the percentage-point interpretation as a universal clinical formula. abs(L)−abs(R) does not fix sign.

ISY5001 Q3(a)(ii) — Inputs, derived variables（衍生變數；由現有欄位計算） and ranked diagnoses（診斷；判斷可能的疾病或故障原因）

What the question requires

  1. Use only listed or explicitly derived fields.
  2. Derive age at consultation; encode/scale appropriately.
  3. Separate doctor diagnosis as the label.
  4. Explain how each remaining method generates a ranking（排序）.

Proposed answer points

  • Inputs: listed symptoms（症狀；患者感受到的不適）, signs, medication-use flags, gender, occupation, and age derived from consultation date minus birth date.
  • Trees: aggregate（彙總；把多筆資料合併成統計值） class counts/probabilities across trees and rank（秩；矩陣獨立資訊的維度數）. KNN（K-Nearest Neighbours；K近鄰；參考最接近的K個樣本）: find nearby historical feature vectors（特徵向量；一個樣本的數值描述）, count their attached diagnosis labels, then rank up to ten.

Avoid: Medication-use flags are not measured blood-pressure/glucose. A label is not an input coordinate; neighbour support（支持度；同時出現的交易比例） is not automatically a calibrated（校準；令量測或機率對應實際意義） probability（機率）.

ISY5002 Q1(e)(ii) — Interpret loadings（負荷量；原特徵對主成分的係數） and use scores without target leakage（目標洩漏；輸入混入預測時不應知道的答案資訊）

What the question requires

  1. Identify large absolute loadings for each retained PC.
  2. Describe contrasts without treating PC labels as known physical causes.
  3. Compute visitor PC scores（主成分分數；樣本投影後的新座標） from fitted coefficients.
  4. Use scores as predictors（預測輸入變數） and validate the downstream（後續階段；使用前一步結果的模型或流程） task.

Proposed answer points

  • PC1 represents product/information engagement contrasted with bounce/exit behaviour; PC2 emphasizes bounce/exit. Remaining loading-based interpretations are listed below.
  • Scores are transformed coordinates, not the eigenvectors（特徵向量） themselves. For predicting Revenue（營收；本題欄位指是否完成購買）, remove Revenue from the PCA input and refit preprocessing/PCA on training data only.

Avoid: The supplied PCA table includes Revenue. PCs built using the target must not be fed back as predictors of that same target.

ISY5002 Q2(c) — Critique anomaly classification（分類；預測類別） with only two anomalies

What the question requires

  1. Read the imbalance and representation constraints（約束條件）.
  2. Identify two distinct challenges in the proposed classifier.
  3. Propose a remedy for each and tie it to the supplied features/data.
  4. Explain how anomaly detection（異常偵測） would be assessed.

Proposed answer points

  • Challenge 1:3,000 normal sequences versus two anomalies cannot support reliable supervised anomaly generalization（泛化能力）; an all-normal model already scores 3000/3002≈99.93% accuracy.
  • Consider learning normal behaviour with a one-class or reconstruction-based detector and collect more diverse verified anomalies.
  • Challenge 2:30 concatenated features can be redundant（冗餘；資訊重複）/on different scales; the plotted histogram may be less discriminative（判別式；著重區分輸入所屬類別） than frequency（頻率） features.
  • Inspect the supplied figure, compare representations on held-out data, scale training-derived features and reduce redundant dimensions if justified.
  • Each sequence has 4×50=200 samples; this is separate from the engineered 10+20=30 feature dimensions. Evaluate false alarms and anomaly recall（召回率）; two anomalies make estimates highly uncertain.

Avoid: Do not manufacture many reliable abnormal examples by copying two rows. A temporal（時間的） histogram also discards order. The missing QA（Question Answering；問答） answer is newly analysed study guidance, not a past reviewed answer.

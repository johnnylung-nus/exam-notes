Boosting（提升法） and AdaBoost

Boosting adds learners sequentially to improve the current ensemble（集成學習）. AdaBoost increases emphasis on training（訓練） observations（觀測值） that previous learners classified incorrectly, then combines learners using performance-based weights（權重）.

How do misclassified cases gain influence in AdaBoost?

  • AdaBoost focuses later learners on cases the current learner found difficult. Example weights are updated after each fit; the sequence（序列；有先後順序的資料） is dependent, unlike independent（獨立；知道一者不改變另一者機率） bagging（裝袋法）.
  • A learner with lower weighted error receives a stronger vote. Misclassified cases increase in relative weight, so the next weak learner has more incentive to distinguish them using different splits or features.
  • Repeatedly emphasizing difficult cases is valuable when they contain real missed structure, but harmful when the difficulty comes from incorrect labels or irreducible noise（雜訊；干擾有效訊息的成分）. Validation and data inspection are therefore important even with shallow weak learners.
Implementation steps and their purpose
  1. Start with equal observation weights
  2. Fit a weak classifier
  3. Calculate its weighted error
  4. Increase relative weight of misclassified observations
  5. Fit the next learner on the revised weighting
  6. Combine learner votes with learned weights

Use the result and check it

Data, components and application

  • Noisy or mislabeled hard cases dominate → clean labels and limit model complexity → avoid repeatedly fitting errors
  • Too many rounds → validate early stopping（提前停止）/learning rate（學習率） → control overfitting（過度擬合）
  • Unstable importance interpretation → compare held-out（留出資料；未參與該階段訓練） changes → do not infer（推論；由依據得出結論） a universal feature truth

How to evaluate it

Compare business-relevant recall（召回率）/precision（精確率）, not only training accuracy（準確率）; use the same held-out cases for fair model comparison.

Common wrong answers and the exact correction

When would this calculation be useful?

Useful when several weak but informative learners can form a stronger classifier.

Where this is tested in the sample papers

ISY5002 Q1(c) — AdaBoost feature importance（變數重要性；模型使用該特徵的相對程度） versus a single tree

What the question requires

  1. Compare the actual displayed rankings.
  2. Explain how sequential weak learners can use different features.
  3. Propose a feature-selection experiment.
  4. Evaluate fairly on held-out data.

Proposed answer points

  • The single tree emphasizes PageValue/BounceRate（跳出率；進站後未觸發其他請求便離開的比例）; the AdaBoost plot emphasizes ProductRelated and Informational_Duration more.
  • Later learners can address earlier mistakes, changing aggregate（彙總；把多筆資料合併成統計值） importance. Retrain using a justified subset and compare on the same validation cases.

Avoid: Importance is model-dependent, not a causal（因果；一者造成另一者變化） effect. Correlated（相關；數值一同變化的程度） features and the importance measure can alter rankings.

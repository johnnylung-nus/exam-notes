MR-32 Probabilistic Representation

Represent uncertain knowledge using variables, dependencies and probabilities. This describes how the knowledge is stored; Bayesian inference describes how to update or derive probabilities from it.

What to draw / write: Probabilistic representation

Rain ─→ WetRoad
Rain ─→ Traffic
P(WetRoad | Rain)
Node
A variable with possible states, such as Rain=true/false.
Arrow
A directed dependency in the model; it is not an is-a link.
P(A | B)
Probability of A given B.
Network parameters
State priors and conditional probabilities needed for the chosen model.
  • Exam answer: If asked to design a Bayesian network, draw variables and directed dependencies, then give the supplied priors/conditional tables or state which must be learned.
  • Do not invent numerical probabilities.
  • If asked only to apply Bayes’ theorem, use the formula and substitution instead.

Used Cases:

The use-case names come from the lecture. The short scenarios below explain how to recognize them in an exam; they are teaching examples, not quoted exam questions.

Lecture use caseWhat it meansExample / clue in a question
Medicine（醫療）The same symptoms can support more than one explanation.Update candidate-condition probabilities using the supplied prior and evidence likelihoods; do not claim the highest probability alone determines urgency.
Robotics（機器人）Sensor measurements can be noisy.A robot has uncertain position readings; represent uncertainty rather than treating every reading as an exact fact.
Autonomous driving（自動駕駛）Object detection may be imperfect.A detected object might be a pedestrian; reason under uncertainty and retain separate safety constraints.
Finance（金融）Future conditions are uncertain.A model estimates risk from available evidence rather than presenting a future event as certain.
Cybersecurity（網絡安全）Suspicious behavior is not automatically an attack.Combine an alert with prior attack frequency and other evidence before reporting an assessed probability.
LLM agents（大型語言模型代理）Available evidence can be incomplete.An assistant has partial evidence for a conclusion; express the supported uncertainty instead of inventing missing facts.

Choose by the required job: explain what knowledge is stored and how this representation helps with the scenario. A use-case name alone is not a sufficient reason.

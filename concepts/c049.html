C049

Confidence-weighted implicit（隱式；由行為間接推知） MF（Matrix Factorization；矩陣分解）

Confidence-weighted implicit MF separates preference from confidence（信賴度；前件出現時後件也出現的比例）. Any observed activity gives preference 1; no activity gives preference 0 with low confidence, rather than confirmed dislike.

Recognise（辨識；從資料找出物件或模式） this in a question: Clicks, views, purchases, implicit feedback（隱式回饋）, unobserved items

How are implicit preference and confidence kept separate?

  • Implicit MF separates the target preference from confidence in that target. The lecture maps any positive count to preference1 and no interaction to preference0. Confidence then weights（權重） how strongly the loss（損失函數；衡量預測錯誤） tries to match each preference, with repeated activity receiving more weight.
  • This does not convert every missing pair into an equally certain dislike. The unobserved preference0 carries low weight, while a repeated positive carries high weight. The factor model balances these weighted errors and regularisation, sharing patterns without claiming the binary preference matrix is an explicit rating survey.
  • Because unobserved entries still participate at low confidence, the objective differs from fitting only observed explicit ratings. An appropriate implicit ALS（Alternating Least Squares；交替最小平方法） implementation exploits this structure; naively materialising every pair can be expensive. Confidence scale must be tuned: high activity does not imply proportionally increasing certainty forever.
Implementation steps and their purpose
  1. Convert interactions to binary preferences.
  2. Assign higher confidence to stronger/more repeated observations（觀測值）.
  3. Retain low confidence for unobserved entries.
  4. Fit user/item factors with confidence-weighted preference error plus regularisation.
  5. Tune confidence scale/factors and rank（秩；矩陣獨立資訊的維度數） candidates.

Use the result and check it

Data, components and application

  • Heavy users dominate → tune/transform counts → raw count need not track liking linearly.
  • Dense objective cost → use suitable implicit ALS implementation → even unobserved pairs enter with low weight.

How to evaluate it

Evaluate held-out（留出資料；未參與該階段訓練） ranking（排序） and coverage（涵蓋率；能服務的使用者或項目範圍）; compare confidence settings on validation data.

Build the answer in this order

  1. Separate binary target from evidence strength.
  2. Explain weighted loss in words.
  3. Describe training（訓練）.
  4. Discuss unknowns and evaluation（評估）.

Common wrong answers and the exact correction
  • Preference zero is not certainty of dislike.
  • Confidence weight is not a calibrated probability.

When would this calculation be useful?

Use when counts or durations provide stronger evidence of interest but are not explicit rating values.

Residual connections（殘差連接）

A residual（殘差） connection adds a block’s input to its learned transformation. The block can learn a correction to the input rather than having to rebuild the entire desired mapping.

Recognise this in a question: Loss（損失） spikes, gradients vanish/explode, deep model not learning

What must the system deliver?

Use to train deeper networks more effectively when adding layers makes optimization difficult.

Scenario cueSuitable choiceWhy it fits
Adding depth worsens training（訓練） even with sufficient capacityUse a shape-compatible residual blockThe network can learn small refinements and retain a direct path instead of relearning the entire representation at every block.

How does an identity shortcut help a deep network learn?

  • A residual block adds its input to a learned transformation. Instead of reconstructing the whole desired output, the learned path can concentrate on the correction that needs to be made.
  • If no correction helps, a near-zero learned path approximately preserves the input. This makes additional depth easier to optimize than forcing every extra layer to learn an identity transformation indirectly.
  • Addition requires equal shapes. If spatial（空間的） dimensions or channel counts change, the shortcut needs a compatible projection or downsampling. A residual route improves information and gradient（梯度） flow, but does not automatically solve overfitting（過度擬合） caused by limited labels（標籤）.
Implementation steps and their purpose
  1. Group layers into a residual block
  2. Compute the block transformation
  3. Pass the original input through a shortcut
  4. Add shortcut and block output
  5. Match shapes with a projection when necessary
  6. Train and compare against a plain network

Compare learning the output with learning a correction

Worked study example: Illustrative desired scalar output is 5.2 for input 5. A residual block computes output = input + correction. For the vector case both paths must return the same shape.

What this tells us: The shortcut preserves a direct route while the trained block learns deviations. It is not a concatenation, which would increase channel count.

Data, implementation and validation

Data, components and application

  • Input/output dimensions differ → use a projection shortcut → addition requires compatible shapes
  • Deep plain network degrades → residual paths → improve information and gradient flow
  • Overfitting persists → use appropriate regularization（正則化） → easier optimization is not enough

How to evaluate it

Assess both successful optimization and validation performance at comparable model sizes.

Build the answer in this order

  1. Explain the depth-related problem
  2. Draw the shortcut and addition
  3. State the shape constraint（約束條件）
  4. Distinguish optimization benefit from generalization（泛化能力）

Diagnose: The residual addition fails or dimensions are silently misinterpreted

What you observeWhy it happensWhat to changeWhy that helps
The residual addition fails or dimensions are silently misinterpretedThe two paths have different shapesAdd a justified projection matching size/channelsEvery element on one path must have a corresponding element on the other.
Common wrong answers and the exact correction
  • Residual addition is not concatenation
  • A shortcut does not mean the block has no learned parameters（參數）.

An answer you could write

  • “For these same-sized features I add the input to the learned correction, allowing an unnecessary block to learn near zero.”
  • “I still monitor validation loss; an easier-to-train deep network can overfit.”

Similarity（相似度） and rating prediction（評分預測）

Similarity defines what counts as a useful neighbour. Prediction（預測） then combines neighbours’ known ratings（已知評分；實際有記錄的評分）, often with similarity weights（權重） and rating-scale adjustment.

What this tells us: The best measure depends on whether absolute levels or relative preferences matter. Do not conclude that one metric is universally superior; evaluate the resulting predictions under the real task.

Which ratings should enter the similarity calculation?

  • A similarity measure is meaningful only after specifying the coordinates and missing-value policy（策略）. Cosine compares direction, Euclidean measures absolute separation, and Pearson centres rating patterns to reduce differences in users’ rating baselines. These answer different notions of resemblance.
  • The prediction equation must match the chosen normalisation. If ratings were centred around user means, combining centred deviations gives a deviation that must be converted back to the target scale. Mixing raw scores with a centred-model interpretation produces values with the wrong meaning.
  • A numeric（數值型；以數量表示） similarity can hide weak support or undefined arithmetic. Zero variance（變異數） makes Pearson problematic; no overlap means no pairwise-complete comparison; a zero usable-weight sum prevents the weighted average. These cases require an explicit（明確；直接提供的資訊） fallback（備援處理） or abstention rather than quietly fabricating a confident score.
Implementation steps and their purpose
  1. Choose comparison coordinates and missing-value policy.
  2. Use cosine for direction, Euclidean for distance, or Pearson for centred rating patterns.
  3. Require sufficient relevant（相關性；是否切合問題） overlap.
  4. Select neighbours with known candidate ratings.
  5. Compute the stated weighted prediction, restoring a mean（均值；平均數） if centred.

Use the result and check it

Data, components and application

  • Zero-filled unknowns → use a justified missing-data policy → absence is not a measured zero.
  • Tiny overlap/zero denominator → fallback or abstain → a numeric score may be unreliable.

How to evaluate it

Compare held-out（留出資料；未參與該階段訓練） predictions and coverage（涵蓋率；能服務的使用者或項目範圍） under alternative similarity/normalisation policies.

Build the answer in this order

  1. State representation（表徵；資料的表示方式）.
  2. Justify（給出理由；用情境與證據支持選擇） similarity.
  3. Identify usable neighbours.
  4. Show arithmetic and limitations.

Common wrong answers and the exact correction
  • Cosine similarity（餘弦相似度） and Euclidean distance have opposite ranking（排序） directions.
  • Binary all-one co-rated（共同評分；兩者都評過的項目） values can make standard similarities uninformative.

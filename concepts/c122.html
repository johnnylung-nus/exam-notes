C122

Dropout（隨機停用神經元）

Dropout randomly sets a fraction of activations to zero during training（訓練）. The network cannot rely on the same particular hidden units always being available, reducing co-adaptation.

Recognise（辨識；從資料找出物件或模式） this in a question: Training improves, validation worsens, memorisation, limited labelled data

Trace a dropout mask and expected scale

Worked study example: Illustrative activations [2,4,6,8], dropout rate 0.5. Keep probability（機率） is 0.5; this sampled mask retains the first and third activations.

What this tells us: The expectation is preserved, not every individual pass or total. This controlled disruption changes the training experience while leaving parameter storage intact.

For inverted dropout use the unmasked activation at evaluation; do not apply the same random mask or divide by q again.

  1. Activations[2,4,6,8],mask[1,0,1,0].
  2. After masking:[2,0,6,0].
  3. Divide by0.5:[4,0,12,0].
  4. Expected first response=0.5×4+0.5×0=2.
  5. Normal inference uses all activations without this random mask.

Interpret the result: Dropout temporarily omits activations; it does not prune saved weights（權重）.

Why does disabling units during training reduce co-adaptation?

  • Dropout randomly suppresses eligible activations during training. Changing the omitted subset means downstream（後續階段；使用前一步結果的模型或流程） units cannot depend on the same precise feature（特徵；描述樣本的屬性） combination always being present, discouraging fragile co-adaptation.
  • In inverted dropout, surviving activations are divided by the probability of being kept. This preserves their expected scale over random masks; ordinary inference then uses the full representation（表徵；資料的表示方式） without additional random masking.
  • Dropout does not remove stored weight matrices or automatically reduce model size. Its default training/inference distinction must be respected; deliberately stochastic test-time dropout is a special uncertainty（不確定性） procedure, not the normal evaluation（評估） described here.
Implementation steps and their purpose
  1. Identify a training/validation overfitting（過度擬合） gap
  2. Add dropout to suitable hidden representations
  3. Choose a dropout fraction
  4. Train with fresh random masks
  5. Evaluate in inference mode with dropout disabled and the framework scaling convention applied

Prepare the data and validate the representation

Data, components and application

  • Excessive dropout harms learning → lower rate → retain enough signal（訊號）
  • Dropout enabled at normal evaluation → switch to inference mode → obtain the intended deterministic prediction（預測）
  • Small data remains unrepresentative → improve coverage（涵蓋率；能服務的使用者或項目範圍） → regularization（正則化） cannot invent missing cases

How to evaluate it

Compare validation loss（損失函數；衡量預測錯誤） and task metrics; accept dropout only if it improves generalization（泛化能力） under the same split（切分；按條件分開資料）.

Build the answer in this order

  1. Identify overfitting evidence（證據；已觀察到的資訊）
  2. Explain temporary random omission
  3. Specify training versus inference behavior
  4. Justify（給出理由；用情境與證據支持選擇） rate using validation

Choose the representation from the task

Use as a regularization option when a network overfits; choose placement and strength based on validation rather than habit.

Common wrong answers and the exact correction
  • Dropout does not directly add an L1（L1懲罰；以權重絕對值作限制）/L2（L2懲罰；以權重平方作限制） penalty
  • It does not automatically reduce stored parameter count.

An answer you could write

  • “Dropout temporarily masks activations during training; it is different from pruning（剪枝） or an L2 weight penalty.”
  • “I validate its rate and use inference mode for ordinary testing.”

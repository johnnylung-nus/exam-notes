IS-14 Denoising（去雜訊） autoencoders（自編碼器）

A denoising autoencoder receives a corrupted（擾動；輸入被加雜訊或遮蔽） input but is trained to reconstruct the original clean input.

What this tells us: The clean and noisy vectors must stay paired. Reconstructing the noisy input itself is an ordinary noisy-data autoencoder, not the intended denoising objective.

How can a model reconstruct a clean signal from a corrupted input?

  • Denoising training changes the input but keeps the target clean. This forces the model to learn stable structure instead of rewarding reproduction of the added corruption.
  • The corruption should resemble plausible deployment noise without destroying the underlying target event; unrealistic noise can teach the wrong invariance（不變性；指定變化下結果不變）.
  • At runtime the encoder/decoder（解碼器） sees noisy data without the clean target. Clean references are a training/evaluation（評估） resource, not a required live input.
  • A lower reconstruction error（重建誤差；還原值與原資料的差距） can coexist with lost event details, so inspect transients and the actual sensing decision after denoising.
Implementation steps and their purpose
  1. Start with representative clean training signals.
  2. Add realistic corruption to create model inputs.
  3. Keep the clean originals as targets.
  4. Train encoder and decoder to reduce clean-target reconstruction error.
  5. Test on unseen noisy signals.
  6. Check whether important event details survive.

Data, components and application

  • Training noise unrealistic → use corruption resembling deployment → improves relevance（相關性；是否切合問題）.
  • Over-smoothing → inspect important transients → a smoother signal may erase faults.
  • Noisy target used by mistake → preserve clean target → the learning objective must reward denoising.

How to evaluate it

Compare reconstruction against available clean references and evaluate the final sensing task under realistic noise.

Build the answer in this order

  1. Noise problem.
  2. Corrupted input and clean target.
  3. Reconstruction objective.
  4. Check detail preservation and task benefit.

Common wrong answers and the exact correction
  • Ordinary reconstruction and denoising use different input-target pairs.
  • Denoising does not guarantee correct anomaly classification（分類；預測類別）.

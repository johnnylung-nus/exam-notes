IS-18 Data augmentation（資料增強） for sensors（感測器）

Sensor augmentation（增強；產生保留所需意義的資料變體） creates plausible variations of training（訓練） windows while preserving the target meaning. The lecture covers scaling, magnitude filtering（濾波）, jittering and time-warping.

Recognise（辨識；從資料找出物件或模式） this in a question: Compact representation（表徵；資料的表示方式）, reconstruct signal（訊號）, denoise, unlabelled sensor data · Rare class（類別；分類目標）, imbalance, augmentation, synthetic samples

What this tells us: An activity may tolerate small speed differences while a fault detector using exact periodic（週期性） timing may not. “More augmented data” is therefore not a sufficient justification（給出理由；用情境與證據支持選擇）.

Which sensor transformations preserve the target meaning?

  • Augmentation changes training examples to mimic nuisance variation while preserving their target labels. It does not create new independent（獨立；知道一者不改變另一者機率） people or machines.
  • Scaling changes overall magnitude; jitter adds noise; time-warping changes local timing. Each can destroy label meaning in the wrong task.
  • Split by independent originals/subjects before augmentation. If related copies enter both training and test sets, evaluation（評估） can reward（獎勵） recognition of near-duplicates.
  • Transformation strength should be validated: the benefit is robustness on real unseen recordings, not success at recognizing synthetic copies.

Common wrong answers and the exact correction
  • Augmentation does not create independent real participants/machines.
  • A technique useful for one sensor task may destroy another task’s label.
Apply the distinction

Apply the distinction

Data, components and application

  • Transformation changes event meaning → restrict range/type → prevents wrong training labels.
  • Augmented copies across splits → split originals first → prevents leakage.
  • Only augmented test performance improves → use realistic independent recordings → synthetic robustness is not enough.

How to evaluate it

Compare unseen real-data errors and resistance to relevant（相關性；是否切合問題） noise, while checking that important magnitude/timing cues remain usable.

Build the answer in this order

  1. Missing variation.
  2. Label-preserving transform.
  3. Training-only use.
  4. Real-data comparison.
An answer you could write

An answer you could write

  • I augment only training windows using transformations that preserve the target event.
  • I retain independent real validation/test recordings and inspect each class.
  • I reject scaling or time-warping when magnitude or timing defines the required label.

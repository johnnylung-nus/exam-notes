K-nearest neighbours（K近鄰；參考最接近的K個樣本）

K-nearest neighbors predicts using the labels（標籤；作比較的正確答案） of nearby training（訓練） examples. Here K means the number of neighbors consulted, not the number of clusters or principal components（主成分）.

Recognise（辨識；從資料找出物件或模式） this in a question: Continuous（連續；可在範圍內連續變化） target, probability（機率）, straight-line boundary, local neighbours

Interpret the result: Scaling,distance and K jointly define what local evidence（證據；已觀察到的資訊） means.

Which neighbours should influence the prediction?

  • K-nearest neighbors stores labeled training examples and predicts from the local neighborhood of a query. Here K is the number of consulted neighbors, unlike K-means（K平均分群） cluster count or PCA（Principal Component Analysis；主成分分析） retained dimension.
  • Feature（特徵；描述樣本的屬性） scale and distance define what local means. A large-unit attribute（屬性；對象的描述欄位） can dominate raw Euclidean（歐氏） distance; irrelevant dimensions can dilute useful similarity（相似度）. Fit scaling using training data and select meaningful inputs.
  • Small K follows very local detail and noise（雜訊；干擾有效訊息的成分）; larger K smooths decisions but may blend distinct populations or favor a majority class. Tune that trade-off（取捨；改善一項可能犧牲另一項） using held-out（留出資料；未參與該階段訓練） task metrics, not a fixed rule that more neighbors is always safer.
Implementation steps and their purpose
  1. Fit preprocessing（前處理） on training data
  2. Scale numeric（數值型；以數量表示） features and choose a distance
  3. Calculate the new case’s distances to training observations（觀測值）
  4. Select the K nearest
  5. Vote for classification（分類；預測類別） or average numeric targets
  6. Tune K using validation

Prepare the data and validate the representation（表徵；資料的表示方式）

Data, components and application

  • Small K follows noise → increase K → smooth the boundary
  • Very large K ignores local groups → decrease K → retain local distinctions
  • Different feature units → standardize → make distance meaningful
  • High dimension → select useful features → avoid weak distance discrimination

How to evaluate it

Use held-out target metrics and prediction latency; compare neighbor behavior for sparse（稀疏性） regions and minority classes.

Build the answer in this order

Common wrong answers and the exact correction
  • Do not include the query’s own label as a neighbor in evaluation（評估）
  • Neighbor count is selected using validation, not a fixed universal rule.

An answer you could write

  • “With K3 the nearest labels are Y,Y,N, so the query is classified as a purchaser.”
  • “I tune K and the preparation pipeline（處理流程） using purchaser recall（召回率） and false-positive costs on held-out cases.”

ISY5001 Q3(a)(i) — Model choice against a ranked-output requirement

What the question requires

  1. Underline “least suitable”.
  2. Identify the required ranked list of diagnoses（診斷；判斷可能的疾病或故障原因）.
  3. Compare the proposed methods under stated assumptions（假設；答案依賴但題目未明說的條件）.

Proposed answer points

  • Under a basic hard-label single-tree interpretation, a single tree is the intended weak choice because the required output is a ranked differential list.
  • A single tree can in fact（事實；推理中已知的資訊） rank（秩；矩陣獨立資訊的維度數） classes by leaf（葉節點；決策樹的最終輸出） class proportions; explain the assumed implementation rather than asserting an inherent impossibility.

Avoid: Choosing a suitable model does not answer which is least suitable. There is no official key confirming a unique implementation assumption.

ISY5001 Q3(a)(ii) — Inputs, derived variables（衍生變數；由現有欄位計算） and ranked diagnoses

What the question requires

  1. Use only listed or explicitly（明確；直接提供的資訊） derived fields.
  2. Derive age at consultation; encode/scale appropriately.
  3. Separate doctor diagnosis as the label.
  4. Explain how each remaining method generates a ranking（排序）.

Proposed answer points

  • Inputs: listed symptoms（症狀；患者感受到的不適）, signs, medication-use flags, gender, occupation, and age derived from consultation date minus birth date.
  • Trees: aggregate（彙總；把多筆資料合併成統計值） class counts/probabilities across trees and rank. KNN: find nearby historical feature vectors（特徵向量；一個樣本的數值描述）, count their attached diagnosis labels, then rank up to ten.

Avoid: Medication-use flags are not measured blood-pressure/glucose. A label is not an input coordinate; neighbour support（支持度；同時出現的交易比例） is not automatically a calibrated（校準；令量測或機率對應實際意義） probability.

C138

Imbalanced data（類別不平衡資料） and augmentation（增強；產生保留所需意義的資料變體）

Class（類別；分類目標） imbalance means some target classes have far fewer examples. A model can achieve high overall accuracy（準確率） while failing the rare class that matters most.

Recognise（辨識；從資料找出物件或模式） this in a question: Very few faults, only two anomalies, rare abnormal event · Rare class, imbalance, augmentation, synthetic samples

Expose the majority-class trap and cost response

Worked study example: Sample Q2(c) has 3000 normal and 2 abnormal sequences（序列；有先後順序的資料）. For illustration call abnormal positive. A weighted training（訓練） objective might give larger importance to each abnormal example, but that does not establish fault diversity（多樣性）.

What this tells us: Weights（權重） can prevent the majority loss（損失函數；衡量預測錯誤） from dominating, but cannot teach an unseen abnormal pattern. Collect diverse faults or consider normal-pattern screening.

Counts refer to the same evaluation set and the same positive-class definition. A zero denominator needs an explicitly stated convention.

  1. All-normal accuracy=3000/3002≈99.933%.
  2. Abnormal recall=0/2=0%.
  3. Duplicating each fault100 times creates200 rows but only2 original cases.
  4. Use class-sensitive evaluation（評估） and collect diverse abnormalities.

Interpret the result: High accuracy alone does not establish a useful fault detector.

Why can a high-accuracy classifier still miss the rare class?

  • Imbalance can make overall accuracy reward（獎勵） ignoring the rare class. Count both the minority proportion and the diversity of its independent cases; many duplicates of two fault examples still describe only two observed fault situations.
  • Class weighting changes the cost of errors during fitting. Resampling（重新取樣；改變取樣率） changes which examples training sees. Threshold（門檻值） adjustment changes the final decision rule. These mechanisms are different and can be combined only with validation.
  • Augmentation must preserve the label（標籤；作比較的正確答案） and physical plausibility. Apply it to training cases after splitting（切分；按條件分開資料） original cases; transformed copies of the same image or sequence are not independent test evidence（證據；已觀察到的資訊）.
Implementation steps and their purpose
  1. Count examples and inspect coverage（涵蓋率；能服務的使用者或項目範圍） per class
  2. Split original cases before augmentation
  3. Apply training-only class weights or resampling
  4. Use label-preserving augmentation where appropriate
  5. Tune decision thresholds using validation costs
  6. Report minority-class metrics

Choose the method from the problem

Use when faults, fraud or some product classes are scarce; limited minority diversity is separate from simple count imbalance.

Common wrong answers and the exact correction
  • Do not augment test data as new independent evidence
  • Class weighting cannot compensate for completely absent fault types.

Implement it and test the outcome

Data, components and application

  • Few abnormal cases → collect diverse faults or model normal behavior → two cases cannot represent all faults
  • Oversampling（過度抽樣；增加少數類樣本） duplicates → validate carefully → repetition does not create new anomaly types
  • Invalid image transformation（變換；把資料轉成另一表示） → restrict augmentation → preserve label meaning

How to evaluate it

Inspect confusion matrix（混淆矩陣）, minority recall/precision（精確率） and per-class F1; include false-alarm burden and uncertainty（不確定性） from tiny samples.

Build the answer in this order

  1. Show why accuracy misleads
  2. Identify count and diversity problems
  3. Propose justified training remedies
  4. Specify rare-case evaluation

An answer you could write

  • “An all-normal classifier obtains 99.933% accuracy but zero abnormal recall, so accuracy is unsuitable alone.”
  • “I address training imbalance while explicitly（明確；直接提供的資訊） collecting more independent abnormal situations.”

ISY5002 Q2(a) — Lean CNN（Convolutional Neural Network；卷積神經網路） redesign, parameter arithmetic, activations and loss

What the question requires

  1. Locate the parameter bottleneck.
  2. Propose a smaller classifier tail（尾實體；關係終點） while preserving required outputs.
  3. Recalculate weights plus biases and total reduction.
  4. Choose activations/loss consistent（一致性） with the classification（分類；預測類別） task.
  5. Validate accuracy, imbalance and lean deployment constraints（約束條件）.

Proposed answer points

  • The original tail is Flatten9408 → Dense256 → Dense128 → Dense918. Its Dense parameter counts（參數數量） are 2,408,704, 32,896 and 118,422; with 18,960 convolution（卷積） parameters（參數） the total is 2,578,982. The first Dense alone accounts for about 93.4%, so the actual bottleneck is the flattened-to-dense connection.
  • A defensible replacement is Flatten9408→Dense64→Dense918. Unchanged convolutions:18,960; Dense64:602,176; output:59,670; total:680,806. Reduction:1,898,176≈73.6%.
  • Use ReLU（Rectified Linear Unit；修正線性；負數歸零） in the hidden layers（隱藏層；中間處理層）, softmax（機率正規化；轉成總和為1的權重） over the 918 mutually exclusive combined classes, and categorical cross-entropy（類別交叉熵；多類分類損失）. Smaller is not automatically better: check held-out（留出資料；未參與該階段訓練） quality.

Avoid: 5,000 unevenly spread images raise overfitting（過度擬合） and class-imbalance concerns; those are related but different problems. The combined 918-way output is one design, not the only possible factorized output architecture（架構）.

ISY5002 Q2(c) — Critique anomaly classification with only two anomalies

What the question requires

  1. Read the imbalance and representation（表徵；資料的表示方式） constraints.
  2. Identify two distinct challenges in the proposed classifier.
  3. Propose a remedy for each and tie it to the supplied features（特徵；描述樣本的屬性）/data.
  4. Explain how anomaly detection（異常偵測） would be assessed.

Proposed answer points

  • Challenge 1:3,000 normal sequences versus two anomalies cannot support（支持度；同時出現的交易比例） reliable supervised anomaly generalization（泛化能力）; an all-normal model already scores 3000/3002≈99.93% accuracy. Consider learning normal behaviour with a one-class or reconstruction-based detector and collect more diverse verified anomalies.
  • Challenge 2:30 concatenated features can be redundant（冗餘；資訊重複）/on different scales; the plotted histogram（直方圖；統計各數值區間的出現次數） may be less discriminative（判別式；著重區分輸入所屬類別） than frequency（頻率） features. Inspect the supplied figure, compare representations on held-out data, scale training-derived features and reduce redundant dimensions if justified.
  • Each sequence has 4×50=200 samples; this is separate from the engineered 10+20=30 feature dimensions. Evaluate false alarms and anomaly recall; two anomalies make estimates highly uncertain.

Avoid: Do not manufacture many reliable abnormal examples by copying two rows. A temporal（時間的） histogram also discards order. The missing QA（Question Answering；問答） answer is newly analysed study guidance, not a past reviewed answer.

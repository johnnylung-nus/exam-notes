Laplace correction（拉普拉斯平滑）

Laplace correction prevents an unseen categorical（類別型；值代表類別） feature（特徵；描述樣本的屬性） value from making an entire Naive Bayes（樸素貝氏法；給定類別後特徵獨立） class（類別；分類目標） score zero. Add one to every possible category count and adjust the denominator consistently.

Recognise（辨識；從資料找出物件或模式） this in a question: Categorical maintenance records, class counts, posterior（後驗機率；看證據之後）, independent（獨立；知道一者不改變另一者機率） features

Add-one categorical likelihood（概似度）

P(x=v|C)=NC,v+1NC+K
N_{C,v}
Training records of class C whose feature has value v.
N_C
Number of training records in class C.
K
Number of possible categories of THIS feature, not number of classes.
+1
Add-one smoothing for each feature category.
  1. Observed Low0,Medium2,High3,total5.
  2. New counts1,3,4,total8.
  3. Probabilities1/8,3/8,4/8 sum to1.
  4. A zero-product class score becomes possible,not automatically likely.

Interpret the result: Do not add one only to the zero numerator.

What this tells us: The previously impossible class now competes with other class scores, but the small count still makes its estimate uncertain.

Why does one zero count erase a Naive Bayes score?

  • A zero count is an estimate from finite data, not necessarily a real impossibility.
  • In a product of categorical likelihoods it can overwhelm every other piece of evidence（證據；已觀察到的資訊）, so smoothing allocates a small amount of probability（機率） to all possible values.
  • Add-one Laplace smoothing adds one to every category count and adds the number of categories to the denominator. Changing only the zero numerator leaves（葉節點；決策樹的最終輸出） probabilities that do not form the intended valid distribution（分布）.
  • The category vocabulary matters: three possible acoustic levels require three added counts, even when one was absent. Smoothing does not fix correlated（相關；數值一同變化的程度） measurements or create evidence for unobserved fault mechanisms.
Implementation steps and their purpose
  1. List all possible categories for the feature
  2. Count each category within the class
  3. Add one to every category count
  4. Add the number of possible categories to that class-feature total
  5. Use the smoothed likelihoods in the class-score product

Data, components and application

  • Only zero numerator changed → correct all counts and denominator → retain a valid probability distribution
  • Many categories with tiny data → consider grouping or more data → avoid estimates dominated by smoothing
  • Unseen category at deployment → define category handling during preparation → keep the model usable

How to evaluate it

Compare held-out（留出資料；未參與該階段訓練） log loss（損失函數；衡量預測錯誤） or classification metrics（分類評估指標）, especially cases containing uncommon categories.

Build the answer in this order

  1. Identify the zero-product problem
  2. State category count
  3. Show corrected numerator and denominator
  4. Continue the class comparison

Common wrong answers and the exact correction
  • Adding one only to the zero count without denominator correction is not standard Laplace smoothing
  • This fixes estimation, not feature dependence.

When would this calculation be useful?

Use when limited training（訓練） data leaves a category unobserved within a class.

Where this is tested in the sample papers

ISY5002 Q2(d) — Naive Bayes from categorical maintenance records

What the question requires

  1. Count class priors（先驗機率；看證據之前） from the nine records.
  2. Count Fair vibration（振動；來回震動的訊號） and Low acoustic within each class.
  3. Multiply prior and likelihoods under the stated conditional-independence assumption（假設；答案依賴但題目未明說的條件）.
  4. Normalize the two scores and select the higher class.

Proposed answer points

  • Carryback（回帶殘料；卸料後仍黏留在輸送帶的物料）: (5/9)×(1/5)×(3/5)=1/15. Mistracking（輸送帶跑偏；未沿正確位置運行）: (4/9)×(2/4)×(2/4)=1/9.
  • Normalize: Carryback=0.375; Mistracking=0.625. Predict Mistracking under the Naive Bayes model.

Avoid: Independence is conditional on cause, not unconditional independence of sensors（感測器）. No zero counts occur in these two likelihoods; smoothing is not required to reproduce this calculation.

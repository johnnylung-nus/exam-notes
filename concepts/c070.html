Vision-language models（視覺語言模型）

A vision-language model (VLM（Vision-Language Model；視覺語言模型）) processes image/video and text together. It can link questions to visual regions and generate descriptions or judgements.

How does language connect to evidence in an image?

  • A VLM combines image and language representations（表徵；資料的表示方式） so a question can guide which visual evidence and relations are relevant（相關性；是否切合問題）.
  • Grounding（依據來源；使輸出有可核對支持） connects words such as “mask” or “person on the left” to particular image regions; reasoning（推理） interprets their relationships under the requested rule.
  • Generation（生成式；學習資料生成或分布） expresses the result, but fluent text can mention details unsupported by the image. Evidence and inference must therefore be separated.
  • A carefully constrained prompt（提示詞） helps specify the task and response structure; it does not turn uncertain visual evidence into certainty.
Implementation steps and their purpose
  1. Provide the image and a precise task prompt.
  2. Ask what is visibly present.
  3. Ground referenced objects in relevant regions.
  4. Apply the required relationships or domain rules.
  5. Separate evidence, inference and uncertainty in the output.

Prepare the data and validate the representation

Data, components and application

  • Hallucinated details → require evidence-grounded output → fluent language can exceed visual evidence.
  • Wrong relation → check object（客體；三元組終點） locations/coverage → detected objects alone do not resolve the question.
  • Unseen setting → test representative cases → broad pretraining does not prove domain reliability.

How to evaluate it

Evaluate objects, grounding, relation/judgement accuracy（準確率） and usefulness of uncertainty to the user.

Build the answer in this order

  1. Question → required visual evidence.
  2. Ground entities（實體；被描述的對象）/relations.
  3. Apply case knowledge.
  4. Evaluate judgement and missing information.

Common wrong answers and the exact correction
  • A plausible caption does not prove correct reasoning.
  • Use a VLM only if it serves the case requirements.

An answer you could write

  • A VLM should ground the question’s objects in image regions and assess the required relation under the domain rule.
  • Separate observable evidence, inference and uncertainty so unsupported visual details are not reported as facts.
  • Evaluate object grounding and the final judgement separately under poor lighting, occlusion and unusual views.

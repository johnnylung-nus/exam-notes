Forward / backward / recursive feature selection（遞迴特徵選擇）

Forward selection adds features（特徵；描述樣本的屬性）; backward selection removes features by testing the resulting subset performance; recursive feature elimination repeatedly removes the least important features according to a fitted estimator.

Recognise（辨識；從資料找出物件或模式） this in a question: Too many variables（變數）, irrelevant inputs, select features, dimensionality（維度；描述資料所需的座標數） harms distance

How do forward, backward and recursive selection traverse feature subsets?

  • Forward selection asks which single addition best improves the current subset; it does not choose the next feature from an unchanging initial ranking（排序）. Two weak standalone features can still interact, which a greedy start may miss.
  • Backward selection tests candidate removals from the current full subset. RFE instead ranks features using the fitted estimator and removes low-ranked ones, refitting afterward because importance can change.
  • Subset size is a development choice. A tiny improvement may not justify（給出理由；用情境與證據支持選擇） more inputs, acquisition cost or instability. Use cross-validated task performance and avoid reporting the searched-on validation score as an unbiased final estimate.
Implementation steps and their purpose
  1. Define a cross-validated task metric
  2. For forward selection start empty and test each possible addition
  3. For backward selection start full and test each possible removal
  4. For RFE fit the estimator and remove lowest-ranked features
  5. Refit after each change
  6. Stop at a validated subset size

Prepare the data and validate the representation（表徵；資料的表示方式）

Data, components and application

  • Greedy decisions miss the best combination → acknowledge search limits → do not claim a global optimum（全域最優解）
  • Selection uses all data → place it inside folds → prevent optimistic results
  • Correlated（相關；數值一同變化的程度） features swap importance → inspect stability → avoid overinterpreting one retained variable

How to evaluate it

Compare selected subsets using the same metric and splitting（切分；按條件分開資料） rules, and measure reduced data-collection or inference（推論；由依據得出結論） cost.

Build the answer in this order

  1. Choose addition/removal direction
  2. State how each candidate is scored
  3. Explain stopping
  4. Validate the final pipeline（處理流程）

Common wrong answers and the exact correction
  • Backward selection and RFE use different removal criteria
  • RFE requires an estimator capable of ranking features.

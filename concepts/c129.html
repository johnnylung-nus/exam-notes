Bagging（裝袋法） and bootstrap sampling（自助抽樣）

Bagging trains models on bootstrap（自助抽樣；從原資料有放回抽樣） samples and aggregates their predictions. A bootstrap sample is drawn with replacement, so some observations（觀測值） repeat and some are left out.

What this tells us: OOB evaluation（評估） is observation-specific; there is not one universal leftover set used by every model.

Expected unique-case fraction

unique fraction = 1 − (1−1/n)ⁿ
n
number of original training observations and draws in a standard bootstrap
  1. An observation is missed by one draw with probability1−1/n.
  2. It is missed by all n draws with probability（機率）(1−1/n)ⁿ.
  3. For large n,this is about36.8%,leaving about63.2% unique in-bag cases.
  4. OOB votes must exclude models trained on that case.

Interpret the result: Draw count is n; unique-case count is smaller because of repeats.

How does bootstrap sampling produce varied training sets?

  • Bootstrap sampling draws with replacement from the training records. A standard bootstrap has as many draws as the original dataset but fewer unique cases; about 63.2% are represented on average, with the remainder available out-of-bag for that tree.
  • Bagged models train independently. Their predictions are combined without the next model explicitly（明確；直接提供的資訊） correcting the previous one; this separates bagging from boosting（提升法） and makes independent（獨立；知道一者不改變另一者機率） fitting possible.
  • For an observation’s out-of-bag prediction, use only models whose bootstrap omitted that observation. Repeatedly optimizing against out-of-bag scores still makes them development evidence（證據；已觀察到的資訊）, so a separate final test remains useful when available.
Implementation steps and their purpose
  1. Draw a same-size sample with replacement from training data
  2. Train one base model
  3. Repeat independently for many models
  4. Vote for classification（分類；預測類別） or average numeric predictions
  5. Use out-of-bag predictions or validation data to estimate quality

Prepare the data and validate the representation（表徵；資料的表示方式）

Data, components and application

  • Base models repeat identical errors → increase meaningful diversity（多樣性） → averaging cannot cancel shared bias（偏置／偏差；須看語境）
  • Correlated（相關；數值一同變化的程度） observations leak across evaluation → split（切分；按條件分開資料） by entity（實體；被描述的對象） first → preserve independence
  • Too few models → add models until validation stabilizes → reduce sampling（取樣） variability

How to evaluate it

Use out-of-bag estimates for development and a final untouched test set（測試集） when available; match metrics to the application.

Common wrong answers and the exact correction
  • Bagging is not sequential mistake reweighting
  • The lecture two-thirds description is an approximation, not the definition of bootstrap sample size.

An answer you could write

  • “I draw training cases with replacement, train independent learners and aggregate their predictions.”
  • “For record B, only the trees whose draws excluded B contribute to its OOB estimate.”

Semantic Networks （語義網路）

Knowledge is shown as nodes and labelled links. The main skill here is identifying what each link means and which direction to read it.

Identify the relationship before drawing the arrow

LabelPlain meaningWhat it connectsLecture example
MemberOf（屬於某類）This individual is a member of this group.One individual → a class/groupMary → MemberOf → Female Persons
John → MemberOf → Male Persons
SubsetOf（子集合）Every member of this smaller group also belongs to the broader group.Group → broader groupFemale Persons → SubsetOf → Persons
Male Persons → SubsetOf → Persons
Persons → SubsetOf → Mammals
HasMother（有母親）The link describes a mother relationship.The source group/individual → its mother category/individualIn this lecture graph: Persons → HasMother → Female Persons. This does not name a particular person’s mother.
SisterOf（是誰的姊妹）The source person is the sister of the destination person.Individual → individualMary → SisterOf → John
Legs（腿數屬性）A property and its value, not membership.Individual/group → valuePersons → Legs → 2
John → Legs → 1

Quick test: one named person belonging to a group → MemberOf. A whole group within another group → SubsetOf. A family connection → the named relation. A number describing a node → an attribute/value link.

Read the lecturer’s network, one link at a time

  1. Mary MemberOf Female Persons: Mary is an individual; Female Persons is the group.
  2. Female Persons SubsetOf Persons: all female persons are persons. Therefore Mary is a person.
  3. Persons SubsetOf Mammals: persons belong to the mammal group. Therefore Mary is also a mammal.
  4. Mary SisterOf John: Mary is John’s sister. It does not say John is Mary’s sister.
  5. Persons HasMother Female Persons: the relationship points to the mother category. Do not invent a mother’s name or conclude Mary is John’s mother.
  6. Persons Legs 2, but John Legs 1: the slide explicitly gives John a specific value. Keep that value rather than replacing it with the general group value.

If asked to write or draw a semantic network

  1. Underline the individuals, groups and property values in the question.
  2. Make a node for each relevant person/group/value.
  3. Choose the link label from its meaning: MemberOf, SubsetOf, a named relationship, or a property.
  4. Read every arrow as a sentence from source to destination.
  5. Check direction and preserve any specific value or exception.

Common mistakes to avoid

Wrong link / conclusionCorrection
Mary SubsetOf Female PersonsUse MemberOf: Mary is one individual, not a group.
Female Persons MemberOf PersonsUse SubsetOf: the link is between two groups.
Persons SubsetOf Female PersonsThe direction is reversed; not all persons are female.
Mary HasMother JohnNot given by the network. SisterOf is a different relationship.
John must have Legs=2The explicit individual value on the slide is 1.

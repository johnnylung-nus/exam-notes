C088

Fourier transformation（傅立葉轉換）

Fourier transformation expresses a signal（訊號） using sinusoidal components. Coefficients tell how much each frequency（頻率） contributes; the inverse reconstructs it.

Recognise this in a question: Frequency peaks, periodic（週期性） components, filter noise, convolution（卷積）

Four-sample Fourier example

F(k) = Σ from n=0 to3 of x(n) exp(−i2πkn/4)
x(n)
nth input value
k
frequency-bin index0…3
i
imaginary unit; i²=−1
  1. F0=2+3+4+4=13.
  2. F1=2−3i−4+4i=−2+i.
  3. F2=2−3+4−4=−1.
  4. F3=−2−i. Magnitudes are13,√5,1,√5.
  5. Mean=F0/4=3.25; inverse using all coefficients reconstructs the samples.

Interpret the result: Coefficients:[13,−2+i,−1,−2−i].

What this tells us: If asked for the mean, divide 13 by four to obtain 3.25. Do not label 13 as the average. A coefficient index also needs the sample-rate/length relation before it is described in hertz.

How are frequency components calculated from samples?

  • The discrete Fourier transform compares the sampled signal with sinusoidal basis patterns. Each coefficient represents a particular frequency component’s contribution.
  • The zero-frequency coefficient collects the constant/DC contribution. Under the lecture’s unnormalized forward convention it is the sum of samples, not their average.
  • Complex coefficients retain magnitude and phase information. Magnitude-only plots are useful summaries but omit information needed for exact reconstruction（重建）.
  • The inverse combines all weighted components to recover the original samples; frequency selection instead produces an altered or approximate signal.
Implementation steps and their purpose
  1. Prepare the sampled signal and its sampling rate.
  2. Calculate the Fourier coefficients.
  3. Inspect useful frequency components.
  4. Use coefficients or derived features（特徵） for the task.
  5. Apply the inverse if reconstruction is needed.
  6. Check whether time localization is required.

Data, components and application

  • Timing of change hidden → use wavelet/windowed analysis → overall frequencies do not locate events.
  • Frequency bins misread → retain sampling-rate information → bin number alone is not frequency in hertz.
  • Unnecessary complex arithmetic → explain representation first → supports scenario reasoning（推理）.

How to evaluate it

Verify inverse reconstruction and whether chosen frequency features distinguish the required classes/events.

Build the answer in this order

  1. Why frequency analysis?
  2. Transform signal.
  3. Interpret useful components.
  4. State localization limit and evaluate.

Common wrong answers and the exact correction
  • FFT is an efficient way to compute the discrete transform.
  • Do not discard phase and expect exact reconstruction.

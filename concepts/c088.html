C088

Fourier transformation（傅立葉轉換）

Fourier transformation expresses a signal（訊號） using sinusoidal components. Coefficients tell how much each frequency（頻率） contributes; the inverse reconstructs it.

Recognise（辨識；從資料找出物件或模式） this in a question: Frequency peaks, periodic（週期性） components, filter noise（雜訊；干擾有效訊息的成分）, convolution（卷積）

Four-sample Fourier example

Xk=∑n=0N−1xnexp(−i2πkn/N)
x_n
Input sample at index n.
N
Number of samples in the transform.
k
Frequency-bin index, from 0 to N−1.
i
Imaginary unit, i²=−1 (often written j in engineering).
X_k
Complex coefficient for frequency bin k.
exp
Complex exponential; this form uses the unnormalized forward-transform convention.

The worked example has N=4. The division kn/N is inside the exponential; the inverse transform uses the opposite sign and the appropriate normalization.

  1. F0=2+3+4+4=13.
  2. F1=2−3i−4+4i=−2+i.
  3. F2=2−3+4−4=−1.
  4. F3=−2−i. Magnitudes are13,√5,1,√5.
  5. Mean（均值；平均數）=F0/4=3.25; inverse using all coefficients reconstructs the samples.

Interpret the result: Coefficients:[13,−2+i,−1,−2−i].

What this tells us: If asked for the mean, divide 13 by four to obtain 3.25. Do not label（標籤；作比較的正確答案） 13 as the average. A coefficient index also needs the sample-rate/length relation（關係；對象間的連結） before it is described in hertz.

How are frequency components calculated from samples?

  • The discrete Fourier transform compares the sampled signal with sinusoidal basis patterns. Each coefficient represents a particular frequency component’s contribution.
  • The zero-frequency coefficient collects the constant/DC contribution. Under the lecture’s unnormalized forward convention it is the sum of samples, not their average.
  • Complex coefficients retain magnitude and phase（相位；週期中的相對位置） information. Magnitude-only plots are useful summaries but omit information needed for exact reconstruction（重建）.
  • The inverse combines all weighted components to recover the original samples; frequency selection instead produces an altered or approximate signal.
Implementation steps and their purpose
  1. Prepare the sampled signal and its sampling rate（取樣率；每秒取樣次數）.
  2. Calculate the Fourier coefficients.
  3. Inspect useful frequency components.
  4. Use coefficients or derived features（特徵；描述樣本的屬性） for the task.
  5. Apply the inverse if reconstruction is needed.
  6. Check whether time localization is required.

Use the result and check it

Data, components and application

  • Timing of change hidden → use wavelet/windowed analysis → overall frequencies do not locate events.
  • Frequency bins（分箱；直方圖的數值區間，本題也可指分類收集箱） misread → retain sampling-rate information → bin number alone is not frequency in hertz.
  • Unnecessary complex arithmetic → explain representation（表徵；資料的表示方式） first → supports scenario reasoning（推理）.

How to evaluate it

Verify inverse reconstruction and whether chosen frequency features distinguish the required classes（類別；分類目標）/events.

  4. State localization limit and evaluate.

Common wrong answers and the exact correction
  • FFT（Fast Fourier Transform；快速傅立葉轉換） is an efficient way to compute the discrete（離散；取分開的數值或時點） transform.
  • Do not discard phase and expect exact reconstruction.

When would this calculation be useful?

Use to identify frequency content and create features for sensor（感測器） classification（分類；預測類別） or analysis.

  • I retain phase when exact reconstruction is needed and evaluate the selected frequency features on the target task.

C117

RNN（循環神經網路） sequence（序列；有先後順序的資料） representation（表徵；資料的表示方式）

An RNN processes an ordered sequence while carrying a hidden state（隱藏狀態；序列模型保留的內部資訊） from one step to the next. The same recurrent weights（權重） are reused, so the current representation depends on earlier observations（觀測值）.

Recognise（辨識；從資料找出物件或模式） this in a question: History matters, sequential purchases, time steps, long dependencies

What information does the recurrent state carry through time?

  • An RNN updates a hidden state from the current event and previous state. Reusing the update across time supports variable-length sequences without learning separate weights for every position.
  • Order changes the state trajectory（軌跡；物件隨時間移動的路徑）. Aggregate counts cannot distinguish product→help from help→product, even though those patterns may have different purchase implications. Sequence models are justified by this extra information, not merely by the existence of timestamps.
  • Define the prediction（預測） time before constructing examples. Later checkout events cannot be used to predict an earlier purchase decision; padding（填充） must also be distinguished from genuine zero-valued events so it does not become artificial history.
Implementation steps and their purpose
  1. Define what one sequence and one time step（時間步；序列中的一個位置） mean（均值；平均數）
  2. Sort events in time
  3. Encode step features（特徵；描述樣本的屬性） and scale numeric（數值型；以數量表示） measurements
  4. Pad（補齊；把不同長度輸入補至所需長度） and mask（遮罩；標示哪些位置應使用或忽略） unequal lengths when batching
  5. Feed the sequence to recurrent units
  6. Choose sequence-level or per-step output

Choose the method from the problem

Use when order matters, such as browsing events, speech, text or a sensor（感測器） time series.

Common wrong answers and the exact correction
  • A list of aggregate counts does not preserve event order
  • CNN（卷積神經網路） and RNN suitability depends on the information structure, not a universal power ranking（排序）.

Implement it and test the outcome

Data, components and application

  • Randomly shuffled steps → restore temporal（時間的） order → preserve the pattern
  • Future events in inputs → restrict to prediction-time information → prevent leakage
  • Long dependencies → consider LSTM → improve memory handling

How to evaluate it

Split（切分；按條件分開資料） by session（工作階段；一次連續造訪的記錄）/user or time as required; assess held-out task metrics rather than isolated time-step accuracy（準確率） alone.

Build the answer in this order

  1. Define sequence
  2. Describe preprocessing（前處理）
  3. Explain hidden-state memory
  4. Match output and loss（損失函數；衡量預測錯誤） to target

An answer you could write

  • “One case is one ordered session; a time step contains the current page and duration.”
  • “I preserve order, mask padding and exclude future events, then evaluate at the same prediction point.”

Where this is tested in the sample papers

ISY5002 Q1(d) — Sequence model, input construction and combination

What the question requires

  1. Choose LSTM for ordered session events.
  2. Represent each session as an ordered sequence with a purchase label（標籤；作比較的正確答案）.
  3. Encode page/source, scale duration, pad/mask and split without future leakage.
  4. Combine outputs with earlier models without training-score leakage.

Proposed answer points

  • Clickstream（點擊軌跡；依次瀏覽與操作的記錄） sequence → LSTM → Dense sigmoid（S形函數） → purchase score; use binary cross-entropy（二元交叉熵；二分類損失） for the binary label.
  • For stacking（堆疊集成；用另一模型整合各模型預測）, generate LSTM training scores out of sample, add them to the earlier model’s inputs, and compare against that model on validation data.

Avoid: Do not use post-purchase/future events when predicting an earlier intervention. In-sample base-model scores can leak into a stacked learner.

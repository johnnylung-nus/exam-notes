SGD / ALS training

SGD and ALS are two ways to learn MF user/item factors. SGD adjusts them from rating errors; ALS alternates which side is fixed while solving the other.

Recognise this in a question: Missing ratings, latent factors, large sparse rating matrix

What this tells us: This one-step improvement does not guarantee lower global or validation error. Real training includes regularisation and many coupled examples; too large a learning rate can overshoot.

What do SGD and ALS update during factor learning?

  • SGD updates the factors involved in a single observed rating using the direction of its error. If prediction is below the actual value, the update should increase the compatibility for that pair while regularisation restrains factor growth. Other pairs sharing that user/item are indirectly affected, explaining how training couples observations.
  • ALS turns the joint problem into alternating conditional problems. With user factors fixed, item factors can be fitted by least squares; with items fixed, users can be fitted. The overall task remains iterative because improving one side changes the best choice for the other.
  • Both procedures require the same clearly defined target and evidence policy. Explicit-rating missingness and implicit preference confidence produce different losses, so “use ALS” alone is not a complete data design. A stable training-error decrease is also insufficient: tune on validation and stop before overfitting or budget limits.

Common wrong answers and the exact correction
  • ALS does not update both matrices independently at the same instant.
  • A normalisation instruction is not permission to turn blanks into measured ratings.

Apply the distinction

Data, components and application

  • SGD unstable → tune learning rate → huge steps can overshoot.
  • Long training/overfit → monitor validation and regularise → lower training error alone is insufficient.

How to evaluate it

Compare validation loss, runtime and stability across initialisations. Specify observed-data objective or implicit confidence weighting correctly.

Build the answer in this order

  1. State objective.
  2. Explain update schedule.
  3. Describe stopping.
  4. Justify settings and evaluation.

An answer you could write

  • “SGD updates the user and item factors from each observed rating error; the illustrated pair’s prediction improves from 1 to 2.86.”
  • “ALS instead fixes one matrix while fitting the other, alternates, and is assessed using the correctly defined loss plus held-out quality.”

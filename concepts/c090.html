C090

Signal（訊號） distributions（分布） and statistics

A distribution describes likely readings; statistics summarize observed data. A class-specific distribution can support（支持度；同時出現的交易比例） probabilistic sensor（感測器） classification（分類；預測類別）.

Recognise（辨識；從資料找出物件或模式） this in a question: Hidden state（隱藏狀態；序列模型保留的內部資訊）, observations（觀測值）, transition, emission, classify a weekly sequence（序列；有先後順序的資料） · Several overlapping populations, soft membership（隸屬度）, Gaussian（高斯分布；常見鐘形分布） components

Bayesian cause classification

sk=P(Ck)∏j=1dP(xj|Ck)P(Ck|x)=sk∑sl
C_k
Candidate class/cause k.
x_j
Observed value of feature j.
P(C_k)
Class prior: class count divided by all training cases.
P(x_j | C_k)
Feature likelihood: within-class count for that value divided by class count (with smoothing if specified).
s_k
Unnormalized score; multiply the prior by ALL feature likelihoods.
∑ s_l
Sum of scores over all candidate classes; divide by this only when a posterior is required.
d
Number of observed features.

Assumption: features are conditionally independent GIVEN the class. To choose a class, compare scores; to report a probability, normalize them.

  1. Carryback（回帶殘料；卸料後仍黏留在輸送帶的物料） has5 records;1 Fair and3 Low:5/9×1/5×3/5=1/15.
  2. Mistracking（輸送帶跑偏；未沿正確位置運行） has4 records;2 Fair and2 Low:4/9×2/4×2/4=1/9.
  3. Sum scores=1/15+1/9=8/45.
  4. Carryback:(1/15)/(8/45)=.375; Mistracking=.625.

Interpret the result: Predict Mistracking under this model.

What this tells us: Predict Mistracking because its normalized probability（機率） is larger. The cause with the larger prior does not win automatically; feature（特徵；描述樣本的屬性） evidence（證據；已觀察到的資訊） can outweigh its starting frequency.

Which statistical description matches the observed measurements?

  • Bayesian classification compares how well each cause explains the observed readings, adjusted by how common that cause is in the training（訓練） data.
  • The prior is the class（類別；分類目標） proportion; a likelihood is the feature probability within that class. Reversing these conditional probabilities changes the calculation.
  • Naive Bayes multiplies feature likelihoods conditional on the class. Its simplifying independence（獨立；知道一者不改變另一者機率） assumption is not the claim that vibration and acoustic are always unrelated.
  • Unnormalized scores are sufficient to rank（秩；矩陣獨立資訊的維度數） classes, but probabilities require division by the sum of competing scores under the stated model.
Implementation steps and their purpose
  1. Prepare relevant（相關性；是否切合問題） features and reliable class labels（標籤；作比較的正確答案）.
  2. Estimate class priors from training counts.
  3. Estimate each feature’s likelihood within each class.
  4. For Naive Bayes, state conditional independence（條件獨立；已知條件後互不提供額外資訊） given class.
  5. Multiply prior by feature likelihoods.
  6. Normalize scores if probabilities are requested and choose the larger.

Use the result and check it

Data, components and application

  • Class imbalance → include priors → avoids treating unequal class frequencies as equal.
  • Correlated（相關；數值一同變化的程度） features → question the independence assumption → duplicated evidence can distort scores.
  • Poor distribution fit → inspect data and choose suitable model → one Gaussian may not fit multiple groups.

How to evaluate it

Check held-out（留出資料；未參與該階段訓練） predictions, class-specific errors and whether probabilities reflect actual outcomes.

Build the answer in this order

  1. Given readings and classes.
  2. Prior and likelihood counts.
  3. Score/normalize.
  4. Prediction（預測）, assumption and validation.

Common wrong answers and the exact correction
  • Likelihood P(reading given class) is not posterior P(class given reading).
  • Use the same denominator for score normalization（正規化；此處縮放至固定範圍）.

When would this calculation be useful?

Use when deciding which class best explains measured features, such as vibration and acoustic categories.

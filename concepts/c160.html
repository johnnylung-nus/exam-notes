Recognition, detection（偵測）, and segmentation（分割） applications

Image classification（分類；預測類別） says what is present; detection adds object（客體；三元組終點） locations, usually boxes; segmentation assigns pixel-level regions. Select the output resolution needed by the downstream（後續階段；使用前一步結果的模型或流程） action.

Recognise（辨識；從資料找出物件或模式） this in a question: Image label（標籤；作比較的正確答案）, object location, bounding boxes（邊界框；框出物件位置）, pixel area, segmentation

Choose from the scenario

Use for product sorting, surveillance or inspection where a single whole-image label may be insufficient.

Scenario cueSuitable choiceWhy it fits
Robot must grasp a particular object among severalProvide detection/segmentation plus relevant（相關性；是否切合問題） pose/location informationKnowing the object identity alone cannot determine where the gripper（夾爪；機器人抓取物件的部件） should move.

Judge localization rather than only the class（類別；分類目標） label

Worked study example: Illustrative target mask（遮罩；標示哪些位置應使用或忽略） contains100 pixels. Predicted mask contains120 pixels, with80 pixels overlapping the true target. Intersection-over-union measures overlap quality.

QuantityCalculationMeaning
Intersection80 pixelsCorrectly shared target region
Union100+120−80=140Pixels in either true or predicted region

What this tells us: The overlap measure is an illustrative evaluation（評估） extension. A robot additionally needs coordinate mapping, obstacle information and motion/safety checks.

What output representation（表徵；資料的表示方式） does the vision application actually need?

  • Classification answers which category is present; detection adds where objects are; segmentation assigns individual pixels to regions. The required downstream action determines whether a label, bounding box or detailed mask is needed.
  • A whole-image class can be confused by several objects and cannot directly supply a grasp location. Detection separates targets spatially; segmentation can provide shape boundaries when a box includes too much background or overlapping material.
  • Training（訓練） labels and evaluation must match the output. Pixel masks require different annotation from image labels, and a good image classifier does not establish tracking, localization or safe robotic success.

Diagnose: Recognition accuracy is high but sorting fails

What you observeWhy it happensWhat to changeWhy that helps
Recognition accuracy is high but sorting failsLocalization or action stages fail downstreamEvaluate each stage and end-to-end（端到端） correct safe sortingComponent labels can be correct while the physical action still targets the wrong location.
Common wrong answers and the exact correction
  • A class probability（機率） does not provide a grasp location
  • Detection and segmentation require different labels.

Apply the distinction

Data, components and application

  • Background objects confuse a classifier → localize targets → separate their evidence（證據；已觀察到的資訊）
  • Occlusion or new lighting → collect representative cases → improve robustness
  • Detection errors propagate to control → evaluate end-to-end success → component accuracy can hide task failure

How to evaluate it

Use class errors for recognition, localization quality for boxes/masks, and real task success; account for latency.

Build the answer in this order

  1. State required output detail
  2. Explain why a label alone is insufficient
  3. Draw perception-to-action flow
  4. Evaluate errors at the right level

An answer you could write

  • “I use localization as well as recognition because the robot needs the target position, not just its class.”
  • “I measure localization quality and final correct-sort, safety and timing performance.”

LSTM（Long Short-Term Memory；長短期記憶網路） and stacked recurrent networks

LSTM is a recurrent model with a memory cell and gates controlling what is kept, added and exposed. This helps learn longer dependencies than a plain RNN（Recurrent Neural Network；循環神經網路）. Stacked recurrent layers learn successive sequence（序列；有先後順序的資料） representations（表徵；資料的表示方式）.

Recognise（辨識；從資料找出物件或模式） this in a question: History matters, sequential purchases, time steps, long dependencies

What must the system deliver?

Use for ordered data when earlier events can influence a later decision, such as a purchase at the end of browsing.

Scenario cueSuitable choiceWhy it fits
Earlier events influence a late purchase outcomeUse LSTM with a binary purchase head（頭實體；關係起點） as a candidateGates can preserve relevant（相關性；是否切合問題） earlier evidence（證據；已觀察到的資訊） across intermediate events.

How do LSTM gates control remembered information?

  • LSTM uses a memory cell with an additive update. The forget gate（遺忘閘；決定丟棄多少舊記憶） controls retained old memory, the input gate（輸入閘；決定寫入多少新資訊） controls writing candidate information, and the output gate（輸出閘；決定輸出多少記憶資訊） controls how memory is exposed as hidden state（隱藏狀態；序列模型保留的內部資訊）.
  • Gate values are learned responses between zero and one, not fixed verbal rules. Selective memory helps longer dependencies but does not preserve every event unchanged or remove every optimization difficulty.
  • A stacked recurrent layer usually needs the earlier layer’s sequence of states, not only one final vector. For a session-level target, the final layer may provide one summary to a sigmoid（S形函數） output. Stacking（堆疊集成；用另一模型整合各模型預測） predictions into another model requires a separate leakage-safe training（訓練） design.
Implementation steps and their purpose
  1. Build one correctly ordered sequence per case
  2. Encode categories, scale numeric（數值型；以數量表示） features（特徵；描述樣本的屬性） and pad（補齊；把不同長度輸入補至所需長度）/mask（遮罩；標示哪些位置應使用或忽略）
  3. Use LSTM units to summarize relevant history
  4. Pass sequence outputs onward when stacking recurrent layers
  5. Attach a target-appropriate final head
  6. Train with validation monitoring

What this tells us: Most old evidence remains and only a little new information is added. The hidden state exposes a bounded, gated view rather than simply returning the whole memory.

Data, implementation and validation

Data, components and application

  • Too many recurrent units → reduce width and stop early → control overfitting（過度擬合）
  • Long irrelevant histories → choose a prediction（預測） window → reduce noise（雜訊；干擾有效訊息的成分）
  • Leakage in stacking → generate scores from held-out（留出資料；未參與該階段訓練） folds → avoid training on memorized predictions

How to evaluate it

Compare against a simple aggregate-feature baseline（基準；供比較的簡單方法） using recall（召回率）, precision（精確率） and business costs.

Common wrong answers and the exact correction
  • LSTM does not eliminate every gradient（梯度） or data problem
  • The slide gate description contains a wording inconsistency: input gates add information, forget gates control retained memory.

An answer you could write

  • “Forget, input and output gates respectively retain, write and expose information.”
  • “I combine LSTM scores with earlier features using out-of-fold training predictions and compare held-out performance.”

Where this is tested in the sample papers

ISY5002 Q1(d) — Sequence model, input construction and combination

What the question requires

  1. Choose LSTM for ordered session events.
  2. Represent each session as an ordered sequence with a purchase label.
  3. Encode page/source, scale duration, pad/mask and split（切分；按條件分開資料） without future leakage.
  4. Combine outputs with earlier models without training-score leakage.

Proposed answer points

  • Clickstream（點擊軌跡；依次瀏覽與操作的記錄） sequence → LSTM → Dense sigmoid → purchase score; use binary cross-entropy（二元交叉熵；二分類損失） for the binary label.
  • For stacking, generate LSTM training scores out of sample, add them to the earlier model’s inputs, and compare against that model on validation data.

Avoid: Do not use post-purchase/future events when predicting an earlier intervention. In-sample base-model scores can leak into a stacked learner.

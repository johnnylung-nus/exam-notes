Classification and Regression（分類與迴歸）

Both predict an output from input features. The type of output decides the task.

What are you predicting?

Question in the scenarioTask / outputHow to judge it
Is this email spam? Which iris species?Classification: a class/category（類別）Confusion matrix; precision, recall, F1
What is the house price? How much time until equipment fails?Regression: a numeric quantity（數值）How far the prediction is from the actual value; MSE
  • Features / predictors（特徵／預測輸入）: information available when making the prediction.
  • Target / response（目標／輸出）: the answer learned from labelled training examples.
  • Numbers can still be class labels: iris species 0, 1, 2 represent categories, not quantities. Predicting species is classification.

KNN: same neighbours, different output

KNN (K-nearest neighbours；K近鄰) finds the k training examples closest to the new input.

TaskTeaching calculation: k = 3Prediction
ClassificationNeighbour labels: spam, spam, not spam → majority voteSpam
RegressionNeighbour values: 10, 12, 20 → average = (10 + 12 + 20) / 314
  • Small k: sensitive to individual examples/noise → high variance, risk of overfitting.
  • Large k: averages over more neighbours → smoother, but may miss local patterns (high bias).
  • Choose k using validation / cross-validation, not the final test set. Odd k avoids a two-class voting tie; it does not prevent every multiclass tie.
  • Prepare distances: put differently scaled numeric features on comparable scales; fit scaling using training data only.

Linear regression: calculate a numeric prediction

Learn coefficients（係數） so a weighted sum of features fits the observed outputs.

y^=β0+β1x1+⋯+βpxp
  • ŷ: predicted output; x₁…xₚ: p input features.
  • β₀: intercept（截距）; β₁…βₚ: learned feature weights.
  • The lecture’s observed-value equation also has ε: noise/unexplained part. Prediction does not add an unknown noise value.

Teaching example: predicted repair time = 2 + 3 × usage. With usage = 4, prediction = 14 hours. If actual time is 16, error = 16 − 14 = 2 hours.

Mean Squared Error (MSE；均方誤差)

MSE=1n∑i=1n(yi−y^i)2

n: number of evaluated examples; yᵢ: actual value; ŷᵢ: predicted value.

Actual [16, 10], predicted [14, 11] → errors [2, −1] → MSE = (2² + (−1)²) / 2 = 2.5 hours². Lower is better on the same evaluation data and target scale.

  • Training: find coefficients that reduce fitting error.
  • Evaluation: compute error on unseen data. Low training error alone does not show generalization（泛化）.

Formula scope: MR Day 4 PDF pp.35–36. Values above are teaching examples.

If the relationship curves: polynomial regression

  • Add polynomial features（多項式特徵）, such as x₁², x₂² and x₁x₂, to represent curved relationships.
  • It remains linear in the learned coefficients; the input features can contain squares/products.
  • More flexibility can overfit: compare polynomial degrees on validation data. Do not select a degree only because training error falls.

Pros and Cons: which method fits the problem?

MethodWhy use it?What can go wrong?
KNNSimple; local neighbours can capture nonlinear patterns; supports both tasks.Distance depends on scale/relevant features; prediction requires neighbour search; k changes the bias/variance tradeoff.
Linear regressionSimple numeric baseline; coefficients make the fitted relationship easy to inspect.A straight-line relationship can miss curved structure; extreme observations can strongly affect squared error.
Polynomial regressionAllows curved patterns through transformed features.Too many/high-degree terms can fit noise and generalize poorly.
Random forestCombines many trees: vote for classification, average for regression.More computation and harder to explain than one tree; still requires unseen-data evaluation.

Used Cases:

  • Iris species: sepal/petal measurements → species label. Classification.
  • Spam filtering: email features → spam/not spam. Examine precision and recall; a high overall accuracy can hide missed spam.
  • Equipment: usage and environmental conditions → time to failure. Regression.
  • Customer activity / travel expenditure: demographic and historical inputs → predicted numeric activity or spending.
  • Retail workshop: no explicit target supplied → first define what to predict and justify the label. Discovering customer groups without labels is clustering, not classification.

Exam answer flow

  1. State the target: category or quantity? Identify input features available at prediction time.
  2. Select a model and explain why: nearest examples, simple numeric relationship, curved relationship, or ensemble.
  3. Prepare data: handle missing/invalid values; prevent target leakage（答案洩漏）; scale inputs when using distances.
  4. Train and tune: separate training/validation/test; select k or polynomial degree on validation data.
  5. Evaluate the right output: classification metrics for classes; prediction error for numeric outputs. Explain the consequence in the scenario.

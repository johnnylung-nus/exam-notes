Transfer learning（遷移學習） and fine tuning（微調）

Transfer learning reuses a model trained on another dataset. A frozen feature（特徵；描述樣本的屬性） extractor learns only a new task head; fine tuning also updates selected pretrained layers on the new data.

Choose from the scenario

Useful when the new labeled dataset is small and the earlier task provides relevant representations.

Scenario cueSuitable choiceWhy it fits
Small image dataset with a related source representationCompare a frozen encoder（編碼器） plus new head before extensive tuningIt limits learned degrees of freedom while testing whether earlier features support the target.

Separate frozen-head training from fine tuning

Worked study example: Illustrative pretrained encoder has 1,000,000 parameters（參數） and produces 128 features. A new five-class head uses 128×5+5 = 645 parameters.

All steps shown
StageTrainable parametersPurpose
Freeze encoder; train new head645Adapt output to five target labels（標籤；作比較的正確答案）
Unfreeze upper 100,000 encoder parameters100,645Adjust task-relevant feature representation
Update all encoder layers1,000,645Most flexibility and greatest small-data risk
Stored model sizeStill includes frozen encoder parametersFreezing reduces updates, not storage

What this tells us: The frozen encoder remains part of prediction（預測）. Training fewer values does not mean those frozen weights（權重） disappear from the deployed model.

Which pretrained features can transfer to the new task?

  • Transfer learning reuses features learned on another dataset. Freezing the base means its weights do not change while the new head learns; fine tuning means updating selected base weights as well.
  • The earlier representation helps only if it retains information useful for the new task. Similar image structures may transfer, but major changes in sensors（感測器）, objects or conditions can make an apparently powerful pretrained model unsuitable.
  • First adapt the output head to the actual labels, then consider limited fine tuning with a small learning rate（學習率）. Input normalization（正規化；此處縮放至固定範圍） must match the selected model. Source-task accuracy（準確率） does not establish performance on the new target distribution（分布）.

Apply the distinction

Data, components and application

  • Source domain differs → validate carefully → reused features may not transfer
  • Too much fine tuning with little data → freeze more layers → reduce overfitting（過度擬合）
  • Excessive learning rate → lower it → preserve useful features

How to evaluate it

Compare held-out performance, training cost and class-level errors with training from scratch.

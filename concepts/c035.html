C035

Association-rule（關聯規則；哪些項目常一起出現） support（支持度；同時出現的交易比例）

Support is the proportion of all baskets containing every item in the whole rule: both the condition and the consequent（後件；THEN結果）. It measures how common that combination is.

Recognise（辨識；從資料找出物件或模式） this in a question: Products bought together, baskets, support, confidence（信賴度；前件出現時後件也出現的比例）, diagnostic associations

What this tells us: The condition occurs 20 times, but 12/20 is confidence, not support. The reverse rule B→A still has 12% support because exactly the same 12 baskets contain both.

How is an itemset（項目集；一組共同考察的項目）'s support counted?

  • Support answers how widely the entire rule combination occurs, not how reliable the rule is when triggered. Its denominator is all eligible transactions（交易；關聯分析的一筆共同出現記錄） under the chosen basket definition. Therefore changing from consultation baskets to patient baskets changes support even when some item labels（標籤；作比較的正確答案） remain the same.
  • Both sides must appear together in a supporting basket. A rule with a frequent condition but an uncommon joint outcome can have low support. Reversing the rule does not change this joint count, so support is symmetric（對稱；交換方向仍相同） even though confidence is usually directional.
  • Minimum support reduces search and removes fragile rare combinations, but high support is not a universal quality criterion. An important rare event may be excluded, while common uninformative combinations survive. The threshold（門檻值） should follow supplied exam requirements or be chosen/validated for the task, not declared as a standard percentage for every domain.
Implementation steps and their purpose
  1. Count all eligible baskets.
  2. Count baskets containing the complete condition and consequent.
  3. Divide complete-rule count by total basket count.
  4. Compare with the supplied support threshold.
  5. Keep basket unit/count consistent（一致性） across calculations.

Use the result and check it

Data, components and application

  • Rare but important rule → justify（給出理由；用情境與證據支持選擇） threshold/domain review → a high threshold may discard useful rare cases.
  • Duplicated transactions → deduplicate at the defined unit → inflated counts distort evidence（證據；已觀察到的資訊）.

How to evaluate it

Recalculate counts and check denominator. Report percentage or count exactly as requested; minimum count 3 is different from 3%.

Build the answer in this order

  1. Define basket unit.
  2. Identify whole itemset.
  3. Count and divide by all baskets.
  4. Apply threshold and explain coverage（涵蓋率；能服務的使用者或項目範圍）.

Common wrong answers and the exact correction
  • Support denominator is not just condition baskets.
  • High support alone does not make a rule predictive.

When would this calculation be useful?

Use to reject extremely rare associations or calculate whether a rule meets the supplied minimum support.

An answer you could write

  • “Twelve of 100 baskets contain both sides, so support is 12%; it passes the stated 10% minimum.”
  • “Reversing the rule leaves（葉節點；決策樹的最終輸出） support unchanged, although confidence will change because its condition count changes.”

Where this is tested in the sample papers

ISY5001 Q3(b)(i) — Temporal（時間的） association baskets and preprocessing（前處理）

What the question requires

  1. Choose the basket unit.
  2. Join patient records and order by date.
  3. Encode earlier diagnosis/treatment, time gap and current diagnosis with distinct roles.
  4. State basket count and assumptions（假設；答案依賴但題目未明說的條件）.

Proposed answer points

  • One consultation per basket: prior（先驗機率；看證據之前） diagnoses + prior treatments + time since each treatment + current doctor diagnosis.
  • Assuming the original 5,000 consultation records and visit date as a treatment-date proxy, create about 5,000 baskets. New trial consultations are not quantified.

Avoid: Patient count does not determine consultation-basket count. Time since treatment differs from duration of treatment. IDs join records; they are not normally mined items.

ISY5001 Q3(b)(ii) — Filter mined rules for the diagnostic task

What the question requires

  1. Keep a current-diagnosis consequent.
  2. Use antecedents（前件；IF條件） available before diagnosis.
  3. Apply justified support/confidence thresholds.
  4. Check temporal meaning and clinical plausibility.

Proposed answer points

  • Role-labelled items let a filter reject treatment-only consequents from a diagnosis ruleset（規則集；一組可使用的規則）.
  • Case-derived illustration: prior lens replacement + elapsed time（已經過的時間；本次與過往事件的時間差） at least six months → current PCO（Posterior Capsule Opacification；後囊混濁） diagnosis association. This is not a clinical rule to apply without validation.
  • With 100 baskets, 20 containing the antecedent and 12 containing both: support=12%; confidence=60%. Pass/fail depends on chosen minima.

Avoid: Ordinary baskets have no time order: encode roles/time. Association does not prove causation（因果；一者造成另一者變化） or safe treatment.

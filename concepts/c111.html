Self-organizing maps（自組織映射；相近輸入映到相近位置）

A self-organizing map maps high-dimensional inputs onto a small organized grid. The winning unit and its neighbors move toward each input, so similar observations（觀測值） tend to occupy nearby map positions.

Recognise（辨識；從資料找出物件或模式） this in a question: Map similar customers to nearby grid cells, topology, winning neuron

One observation updates winner and map neighbor

Worked study example: Illustrative one-dimensional feature（特徵；描述樣本的屬性） with input value 6. A winning prototype is 4, an adjacent map prototype is 2, and a distant unit is 9. Learning rate（學習率） is 0.5; neighborhood weights（權重） are 1,0.5,0 respectively.

All steps shown
UnitUpdate: old + rate × neighborhood × (input−old)New prototype
Winner4 + 0.5×1×(6−4)5
Adjacent map unit2 + 0.5×0.5×(6−2)3
Distant map unit9 + 0.5×0×(6−9)9

What this tells us: The winner moves most, its map neighbor also learns, and the distant unit does not move in this step. This creates organized neighboring representations（表徵；資料的表示方式）.

Update a prototype

wnew=wold+ηh(x−wold)
x
Current input vector.
w
Unit’s prototype vector.
η
Learning rate.
h
Neighbourhood weight relative to the winning unit; often depends on distance and time.
  1. Winner old4,h=1: new=4+0.5×1×(6−4)=5.
  2. Neighbor old2,h=0.5: new=2+0.5×0.5×(6−2)=3.
  3. Distant unit h=0: unchanged.

Interpret the result: The neighborhood updates make the map organized, not just a set of independent（獨立；知道一者不改變另一者機率） winners.

How do a winner and its neighbours learn a SOM（Self-Organizing Map） map?

  • SOM units have both a prototype in original feature space（特徵空間；以特徵作座標的空間） and a fixed position on the map grid. Competition uses feature-space distance; neighborhood learning uses grid proximity. These are different roles, not two interchangeable distances.
  • For each input, first find the best-matching prototype. Move it and nearby grid units toward the observation, with smaller adjustments for farther map neighbors. This encourages a smooth map rather than unrelated cluster representatives.
  • Shrinking the neighborhood over training（訓練） first organizes the map broadly, then refines local details. No known target classes（類別；分類目標） are required; names for map regions come afterward from their original-feature profiles.
Implementation steps and their purpose
  1. Scale features and choose grid size
  2. Initialize unit prototype vectors
  3. Find the prototype closest to the input
  4. Move the winner and its grid neighbors toward that input
  5. Gradually reduce learning rate and neighborhood size
  6. Inspect and profile the resulting map

Prepare the data and validate the representation

Data, components and application

  • One large-scale feature dominates → standardize → balance distances
  • Oversized grid with little data → validate a smaller grid → avoid many unsupported map units

How to evaluate it

Check representation error, neighborhood preservation and whether the discovered profiles are meaningful for the task.

Build the answer in this order

  1. State that training is unsupervised
  2. Explain winner selection
  3. Explain neighborhood updates
  4. Interpret the map without inventing known labels（標籤；作比較的正確答案）

Common wrong answers and the exact correction
  • SOM grid positions are not the original feature values
  • Unlike plain winner-only competition, neighbors also learn.

An answer you could write

  • “The closest prototype wins, but nearby grid units also move toward the input.”
  • “I interpret the resulting map using the original feature profiles; its unit numbers are not known classes.”

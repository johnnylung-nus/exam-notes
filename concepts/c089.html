Filtering（濾波） and convolution（卷積）

Filtering emphasizes or removes selected signal（訊號） components. Convolution applies a local filter across the signal; low-pass（低通；保留低頻） filtering smooths while high-pass（高通；保留高頻） filtering emphasizes changes.

Recognise（辨識；從資料找出物件或模式） this in a question: Frequency（頻率） peaks, periodic（週期性） components, filter noise（雜訊；干擾有效訊息的成分）, convolution

How does a sliding filter change a signal?

  • A filter combines neighbouring samples with specified weights（權重）. Repeated across positions, it emphasizes patterns matching those weights and suppresses others.
  • A low-pass operation smooths local variation; a high-pass operation measures differences. Neither knows automatically which variation is noise.
  • Wavelet decomposition uses low/high-pass branches with downsampling to separate approximation and detail at several scales.
  • Denoising（去雜訊） modifies selected coefficients and reconstructs the signal. The amount removed must be justified by retained useful features（特徵；描述樣本的屬性）, not visual smoothness alone.
Implementation steps and their purpose
  1. Identify the unwanted variation and useful event detail.
  2. Choose a suitable low-pass/high-pass filter.
  3. Apply the filter consistently across the signal.
  4. For wavelets, split approximation/detail and downsample.
  5. Retain or modify useful coefficients.
  6. Reconstruct when a cleaned signal is required.

Use the result and check it

Data, components and application

  • Useful fast event smoothed away → choose filtering strength using the task → noise removal must preserve evidence（證據；已觀察到的資訊）.
  • Boundary artifacts → state extension method → edge values depend on it.
  • Denoising judged only visually → check downstream（後續階段；使用前一步結果的模型或流程） accuracy（準確率） → smooth does not always mean（均值；平均數） correct.

How to evaluate it

Compare original/cleaned signals, retained event details and task performance; check edge and transient behaviour.

Build the answer in this order

  1. Noise versus useful component.
  2. Filter/decomposition choice.
  3. Retained detail and reconstruction.
  4. Evaluate task impact.

Common wrong answers and the exact correction
  • High-frequency content is not always noise.
  • Hand-crafted filters and learned convolution kernels have different parameter origins.

An answer you could write

  • I separate approximation and detail using low/high-pass operations.
  • I remove only coefficients judged unwanted under the task assumptions（假設；答案依賴但題目未明說的條件）, then reconstruct.
  • I verify that the denoised output retains the event and improves held-out（留出資料；未參與該階段訓練） task performance.

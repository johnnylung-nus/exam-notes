Distances and standardization（標準化；減均值再除標準差） for clustering（分群）

A clustering distance expresses what similar means. Numeric Euclidean（歐氏） distance is sensitive to feature（特徵；描述樣本的屬性） scale; ordinal and nominal categories require a representation that respects their meaning.

Recognise this in a question: Find segments without labels（標籤；作比較的正確答案）, centroids, hierarchical groups, choose K

Watch a nearest neighbor reverse after scaling

Worked study example: Illustrative query customer is age40,income50,000. Candidate A is age41,income60,000; B is age60,income50,100. Training（訓練） standard deviations are age10,income10,000.

What this tells us: Scaling reverses the neighbor decision in this example. Different justified feature weighting could still prefer one candidate for the actual business purpose.

How does scaling change which points appear close?

  • Distance is a modeling assumption about similarity（相似度）, not a neutral preprocessing（前處理） detail. Euclidean distance squares numeric coordinate differences, so a feature with large numerical units can dominate the result even when another feature matters more.
  • Standardization expresses differences relative to a feature’s spread. It is useful when raw units should not define importance, but it does not establish equal business relevance. Select features and weights（權重） for the grouping goal.
  • Ordinal values have order, but nominal job or browser codes do not have meaningful arithmetic gaps. An encoding such as lawyer1,doctor2,teacher3 falsely suggests teacher is twice as far from lawyer as doctor is unless that relation is explicitly justified.

Diagnose: Clusters mainly reflect arbitrary category codes

What you observeWhy it happensWhat to changeWhy that helps
Clusters mainly reflect arbitrary category codesNominal labels were treated as numeric magnitudesUse matching-based categorical distance or suitable encodingGroup similarity should not depend on whether a database assigned a category code2 or200.
Common wrong answers and the exact correction
  • Standardization is not proof that every feature deserves equal weight
  • Category numbers do not create meaningful arithmetic automatically.

Apply the distinction

Data, components and application

  • Nominal job codes treated as ordered numbers → use matching-based representation → avoid invented distance ordering
  • Extreme outliers（離群值） dominate → investigate or use robust preparation → protect the grouping
  • Scale estimated from future data → fit on development data → preserve deployment validity（推論有效性）

How to evaluate it

Check whether groups remain sensible across reasonable preparation choices; evaluate compactness and business profiles together.

Build the answer in this order

  1. Define desired similarity
  2. Identify scale/type mismatch
  3. Propose preparation and distance
  4. Explain the effect on groups

An answer you could write

  • “Raw income units dominate this distance, so I standardize using training statistics.”
  • “I still check the chosen features and profiles; equal numerical scaling does not prove equal substantive importance.”

C108

Activation-function choices

Hidden activations provide nonlinearity. Output activation（激活函數；轉換神經元輸出） expresses the required prediction（預測）: sigmoid（S形函數） for one binary probability（機率）, softmax（機率正規化；轉成總和為1的權重） for mutually exclusive classes（類別；分類目標）, and linear（線性；此處加權組合加偏置） output for unrestricted numeric（數值型；以數量表示） regression（迴歸；預測連續數值）.

Recognise（辨識；從資料找出物件或模式） this in a question: Nonlinear（非線性；不能只用線性關係表示） prediction, hidden layer（隱藏層；中間處理層）, weights（權重）, bias（偏置／偏差；須看語境）, backpropagation（反向傳播；計算各參數梯度）

Confident wrong classifications cost more

Binary loss for positive target = −ln(p)
p

ln

  1. Correct-positive probability0.8 gives −ln(0.8)≈0.223.
  2. Probability0.1 for the same true positive（真正例；正類判對） gives −ln(0.1)≈2.303.
  3. For918 mutually exclusive classes, use918 softmax outputs and categorical cross-entropy.

Interpret the result: The final activation expresses the target; the loss judges its prediction.

Which activation fits this hidden layer or output?

  • A hidden activation must do more than rescale a linear expression. Without nonlinearity, several stacked Dense layers still collapse into one linear mapping, so extra layers do not create the intended curved decision regions.
  • Choose the output from the label meaning. Softmax is appropriate when exactly one class is correct; separate sigmoids are appropriate when several labels can independently be true. A numeric target need not be bounded between zero and one.
  • Loss assesses whether the prediction matches the label. Cross-entropy strongly penalizes confident wrong class predictions, while squared error is natural for a continuous（連續；可在範圍內連續變化） quantity. The activation is a transformation（變換；把資料轉成另一表示）, not the training（訓練） objective.
Implementation steps and their purpose
  1. Identify binary, multiclass（多類別）, multilabel or numeric output
  2. Use ReLU as a practical hidden-layer choice
  3. Choose output activation consistent（一致性） with the labels
  4. Pair it with an appropriate loss
  5. Inspect gradient（梯度） and validation behavior

Diagnose: Deep sigmoid hidden layers learn very slowly

What you observeWhy it happensWhat to changeWhy that helps
Deep sigmoid hidden layers learn very slowlyLarge totals push sigmoid into saturationUse suitable initialization（初始化） and consider ReLU hidden layersSaturated sigmoid derivatives（導數；輸入微變時輸出改變多少） are small, weakening gradients sent to earlier layers.
Common wrong answers and the exact correction
  • Softmax classes compete and sum to one
  • ReLU is not a probability output.

Implement it and test the outcome

Data, components and application

  • Sigmoid hidden units saturate → consider ReLU and suitable initialization → reduce vanishing gradients（梯度消失）
  • Mutually nonexclusive labels → use separate sigmoid outputs → several labels may be true

How to evaluate it

Check probabilities, loss and per-class errors on held-out（留出資料；未參與該階段訓練） data; matching activation to task is necessary but does not guarantee accuracy（準確率）.

Build the answer in this order

  1. State target type
  2. Choose hidden activation
  3. Choose output activation
  4. Explain why the loss matches the output

An answer you could write

  • “These classes are mutually exclusive, so I use softmax with categorical cross-entropy.”
  • “ReLU belongs in the hidden layers here; it is not a normalized class-probability output.”

Where this is tested in the sample papers

ISY5002 Q2(a) — Lean CNN（Convolutional Neural Network；卷積神經網路） redesign, parameter arithmetic, activations and loss

What the question requires

  1. Locate the parameter bottleneck.
  2. Propose a smaller classifier tail（尾實體；關係終點） while preserving required outputs.
  3. Recalculate weights plus biases and total reduction.
  4. Choose activations/loss consistent with the classification（分類；預測類別） task.
  5. Validate accuracy, imbalance and lean deployment constraints（約束條件）.

Proposed answer points

  • The original tail is Flatten9408 → Dense256 → Dense128 → Dense918. Its Dense parameter counts（參數數量） are 2,408,704, 32,896 and 118,422; with 18,960 convolution（卷積） parameters（參數） the total is 2,578,982. The first Dense alone accounts for about 93.4%, so the actual bottleneck is the flattened-to-dense connection.
  • A defensible replacement is Flatten9408→Dense64→Dense918. Unchanged convolutions:18,960; Dense64:602,176; output:59,670; total:680,806. Reduction:1,898,176≈73.6%.
  • Use ReLU in the hidden layers, softmax over the 918 mutually exclusive combined classes, and categorical cross-entropy. Smaller is not automatically better: check held-out quality.

Avoid: 5,000 unevenly spread images raise overfitting（過度擬合） and class-imbalance concerns; those are related but different problems. The combined 918-way output is one design, not the only possible factorized output architecture（架構）.

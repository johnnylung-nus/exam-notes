C154

Clustering（分群） vs classification（分類；預測類別）

Classification learns known target categories from labeled cases. Clustering discovers groups from similarity（相似度） without known category labels（標籤；作比較的正確答案）; the groups need interpretation after fitting.

Choose from the scenario

Choose classification when purchase, fault or class（類別；分類目標） labels are available; choose clustering when exploring unknown customer or operating groups.

Scenario cueSuitable choiceWhy it fits
Known purchase/no-purchase labels are suppliedUse supervised classificationThe objective is to predict an established outcome, not discover arbitrary customer groups.

See why a cluster number is not a fault diagnosis（診斷；判斷可能的疾病或故障原因）

What this tells us: Renaming Cluster2 “fault” before checking it would create a diagnosis from an arbitrary group. The needed evidence（證據；已觀察到的資訊） is external meaning, not a visually separate cluster alone.

Are the groups supplied as labels or discovered from the inputs?

  • Classification uses known category labels to learn boundaries that separate those meanings. Clustering uses a chosen similarity definition to discover groups; its numbered outputs have no inherent class, severity or business interpretation.
  • The same observations can produce different legitimate clusters under different features（特徵；描述樣本的屬性） or scaling. Customer age groups and purchase-behavior groups answer different questions, so define the grouping objective before choosing distance.
  • A small remote group might represent a fault, a rare legitimate operating mode or measurement error. Clustering alone cannot decide which. Link the groups back to original features and obtain appropriate expert or labeled validation.

Diagnose: Every distant observation is automatically called abnormal

What you observeWhy it happensWhat to changeWhy that helps
Every distant observation is automatically called abnormalDistance from a dominant cluster was mistaken for ground truthCheck operating conditions and obtain confirmed anomaly examplesRare legitimate regimes can be far apart while remaining normal.
Common wrong answers and the exact correction
  • Cluster numbers are arbitrary labels, not a ranked severity scale
  • Clusters need not match real class boundaries.

Apply the distinction

Data, components and application

  • A cluster is assumed to mean（均值；平均數） abnormal → inspect and validate → similarity does not establish a fault label
  • Labels too scarce → consider anomaly detection（異常偵測） with normal data → do not invent a fully supervised dataset
  • Arbitrary scaling → prepare features → prevent unit-driven groups

How to evaluate it

Classification uses held-out（留出資料；未參與該階段訓練） target errors; clustering uses compactness/separation, stability and meaningful profiles.

Build the answer in this order

  1. Identify available supervision
  2. Choose prediction（預測） or discovery
  3. Explain output meaning
  4. State the right evaluation（評估）

An answer you could write

  • “The cluster IDs only describe similarity groups; I profile them before assigning business meaning.”
  • “For labeled purchase outcomes I train a classifier; for only two known faults I consider normal-pattern screening and collect diagnostic evidence.”

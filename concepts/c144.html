Naive Bayes and conditional independence

Naive Bayes scores each class using its prior probability and the likelihood of the observed feature values. It assumes features are conditionally independent given the class, not independent in the whole dataset.

How do priors and feature likelihoods produce a class score?

  • Bayes classification reverses the question from “how likely is this sensor reading under a cause?” to “how likely is the cause after this reading?” The prior captures cause frequency before the new evidence; likelihood captures evidence frequency within each cause.
  • Naive Bayes multiplies feature likelihoods under conditional independence given the cause. It does not claim vibration and sound are independent across the full dataset; both can vary together because they share a cause.
  • For ranking classes, the evidence denominator is common and can be omitted. To report actual posterior percentages, normalize the class scores; unnormalized scores such as1/9 are not already the final class probabilities.
Implementation steps and their purpose
  1. Count each class to obtain priors
  2. Estimate feature likelihoods within each class
  3. Multiply prior by the relevant likelihoods
  4. Compare class scores
  5. Normalize by the sum of scores if actual posterior probabilities are requested

Use the result and check it

Data, components and application

  • Zero count kills a product → apply consistent Laplace smoothing → permit unseen values
  • Strongly dependent measurements → inspect performance or compare alternatives → avoid double-counting evidence
  • Different class frequencies → retain priors → do not compare likelihoods alone

How to evaluate it

Check class errors and probability quality on held-out data; assumptions need not be perfectly true for useful classification.

Common wrong answers and the exact correction
  • The common evidence denominator cancels only for class ranking
  • Likelihood and posterior have opposite conditioning directions.

Useful as a simple probabilistic classifier and for short count-based exam calculations.

ISY5002 Q2(d) — Naive Bayes from categorical maintenance records

What the question requires

  1. Count class priors from the nine records.
  2. Count Fair vibration and Low acoustic within each class.
  3. Multiply prior and likelihoods under the stated conditional-independence assumption.
  4. Normalize the two scores and select the higher class.

Proposed answer points

  • Carryback: (5/9)×(1/5)×(3/5)=1/15. Mistracking: (4/9)×(2/4)×(2/4)=1/9.
  • Normalize: Carryback=0.375; Mistracking=0.625. Predict Mistracking under the Naive Bayes model.

Avoid: Independence is conditional on cause, not unconditional independence of sensors. No zero counts occur in these two likelihoods; smoothing is not required to reproduce this calculation.

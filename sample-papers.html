Intent and slots

Natural language understandingIntent classificationSlot detection and information extraction

Answer flow

  1. List the supported user goals.
  2. For each goal, identify the fields needed to fulfil it.
  3. Give an appropriate value example; separate user context from intent.
Proposed answer points & exam traps
  • Intent = what the user wants; slot = a required detail; slot value = the actual detail.

Watch: Do not use a job role or every symptom as a separate intent.

Answer flow

5001 Q1(d) · 4 marks

HMM states, observations and sequence classification

HMM: weekly query patternsSignal distributions and statistics

Answer flow

  1. Define hidden states and the observed daily query records.
  2. Specify initial, transition and emission probabilities conceptually.
  3. Explain how probabilities would be learned or supplied.
  4. Score the week’s sequence and choose the supported work-pattern class.
Proposed answer points & exam traps
  • One defensible design trains an HMM per job/work-pattern class. Hidden states represent daily activity modes; observations are daily query categories/counts.
  • Compute each class model’s sequence likelihood, combine with class priors if used, and choose the highest supported class. Activity labels and model structure are design assumptions.

Watch: Do not confuse an observed count with a hidden state or invent transition/emission numbers from an incomplete table. Job role and changing daily activity are not automatically the same variable.

5001 Q2(g) · 2 marks

Check formula scale, sign and threshold

Normalization and preprocessingSignals, sensors, and sensing pipeline

Answer flow

  1. Keep relative size as pupil pixels / iris pixels.
  2. Check the fractional scale against the threshold.
  3. Apply absolute value to the whole left–right difference.
  4. State the percentage interpretation and strictness.
Proposed answer points & exam traps
  • Under a 30-percentage-point interpretation: abs(left_mean − right_mean) > 0.30. This is equivalent to abs(left_mean − right_mean)/0.30 > 1.
  • For 0.20 versus 0.60, absolute difference = 0.40; dividing by 0.30 gives about 1.33.

Watch: The case’s “30%” is ambiguous: a relative-percent definition requires a reference denominator. Do not present the percentage-point interpretation as a universal clinical formula. abs(L)−abs(R) does not fix sign.

5002 Q2(a) · 8 marks

Lean CNN redesign, parameter arithmetic, activations and loss

CNN convolution, padding, strideCNN dimensions and parameter countsActivation-function choicesL1 / L2 regularizationImbalanced data and augmentationCNN application design

Answer flow

  1. Locate the parameter bottleneck.
  2. Propose a smaller classifier tail while preserving required outputs.
  3. Recalculate weights plus biases and total reduction.
  4. Choose activations/loss consistent with the classification task.
  5. Validate accuracy, imbalance and lean deployment constraints.
Proposed answer points & exam traps
  • Original Flatten9408→Dense256 uses 9408×256+256=2,408,704 parameters, about 93.4% of the 2,578,982 total.
  • A defensible replacement is Flatten9408→Dense64→Dense918. Unchanged convolutions:18,960; Dense64:602,176; output:59,670; total:680,806. Reduction:1,898,176≈73.6%.
  • Use ReLU in the hidden layers, softmax over the 918 mutually exclusive combined classes, and categorical cross-entropy. Smaller is not automatically better: check held-out quality.

Watch: 5,000 unevenly spread images raise overfitting and class-imbalance concerns; those are related but different problems. The combined 918-way output is one design, not the only possible factorized output architecture.

5002 Q2(b) · 4 marks

Deep-RL sorting architecture, reward and safe learning

Deep-learning decision / control applicationsSupervised / unsupervised / reinforcement learningMultimodal representation and fusionEnd-to-end sense-making design

Answer flow

  1. Define observations/state, actions and task success.
  2. Choose reward terms for correct sorting, safety and time.
  3. Draw hardware, perception, decision and control loops.
  4. Explain simulation-first training and controlled transfer.
Proposed answer points & exam traps
  • RGB-D + robot sensors → identification/tracking → state → deep-RL policy → safety/motion checks → arm/gripper action → new observations and reward. Include target objects, obstacles, other robots and people in the environment.
  • Reward correct placement; penalize collisions and unnecessary time. Enforce joint/gripper constraints in control rather than hoping a learned reward guarantees safety.
  • Train in a physics-based simulator, then validate in controlled low-risk real tests with safety constraints active.

Watch: A reward penalty is not a hard safety guarantee. Classification of the object and control of the robot are separate responsibilities.

Naive Bayes from categorical maintenance records

Answer flow

  1. Count class priors from the nine records.
  2. Count Fair vibration and Low acoustic within each class.
  3. Multiply prior and likelihoods under the stated conditional-independence assumption.
  4. Normalize the two scores and select the higher class.
Proposed answer points & exam traps
  • Carryback: (5/9)×(1/5)×(3/5)=1/15. Mistracking: (4/9)×(2/4)×(2/4)=1/9.

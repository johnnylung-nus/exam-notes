Naive Bayes and conditional independence

Naive Bayes scores each class using its prior probability and the likelihood of the observed feature values. It assumes features are conditionally independent given the class, not independent in the whole dataset.

CalculationDiagramHow it worksWorked exampleChoose & designProblems & fixesExam answer

Normalize the two class scores

score(cause)=P(cause)×P(Fair|cause)×P(Low|cause)
P(cause)
prior class frequency
P(reading|cause)
likelihood estimated within that cause
posterior
normalized score after observing readings
  1. Carryback=(5/9)×(1/5)×(3/5)=1/15.
  2. Mistracking=(4/9)×(2/4)×(2/4)=1/9.
  3. Score sum=1/15+1/9=8/45.
  4. Posteriors:Carryback0.375;Mistracking0.625.

Interpret the result: Predict Mistracking under conditional independence given the cause.

Compute both fault posteriors

Worked study example: Sample Q2(d): five Carryback cases and four Mistracking cases. For Fair vibration and Low acoustic, the supplied within-class counts give likelihoods1/5 and3/5 for Carryback,2/4 and2/4 for Mistracking.

Carryback(5/9)×(1/5)×(3/5)=1/15(1/15)/(1/15+1/9)=0.375

What this tells us: The more common cause before observation was Carryback, but the observed combination favors Mistracking strongly enough to reverse that prior preference.

Why the calculation works

  • Bayes classification reverses the question from “how likely is this sensor reading under a cause?” to “how likely is the cause after this reading?” The prior captures cause frequency before the new evidence; likelihood captures evidence frequency within each cause.
  • Naive Bayes multiplies feature likelihoods under conditional independence given the cause. It does not claim vibration and sound are independent across the full dataset; both can vary together because they share a cause.
  • For ranking classes, the evidence denominator is common and can be omitted. To report actual posterior percentages, normalize the class scores; unnormalized scores such as1/9 are not already the final class probabilities.
Implementation steps and their purpose
  1. Count each class to obtain priors
  2. Estimate feature likelihoods within each class
  3. Multiply prior by the relevant likelihoods
  4. Compare class scores
  5. Normalize by the sum of scores if actual posterior probabilities are requested

Use the result and check it

Data, components and application

  • Zero count kills a product → apply consistent Laplace smoothing → permit unseen values
  • Strongly dependent measurements → inspect performance or compare alternatives → avoid double-counting evidence
  • Different class frequencies → retain priors → do not compare likelihoods alone

How to evaluate it

Check class errors and probability quality on held-out data; assumptions need not be perfectly true for useful classification.

Build the answer in this order

  1. State conditional independence
  2. Calculate priors and likelihoods
  3. Show both scores

Laplace correction

Laplace correction prevents an unseen categorical feature value from making an entire Naive Bayes class score zero. Add one to every possible category count and adjust the denominator consistently.

CalculationDiagramHow it worksWorked exampleChoose & designProblems & fixesExam answer

Add-one categorical likelihood

P(category|class)=(count+1)/(class count+number of categories)
count
observed count for this category within the class
number of categories
all three defined levels,including absent ones
  1. Observed Low0,Medium2,High3,total5.
  2. New counts1,3,4,total8.
  3. Probabilities1/8,3/8,4/8 sum to1.
  4. A zero-product class score becomes possible,not automatically likely.

Interpret the result: Do not add one only to the zero numerator.

Smooth a missing acoustic category correctly

Worked study example: Illustrative class contains five cases with acoustic counts Low0,Medium2,High3. There are three defined categories. Compare the original and add-one estimates.

All steps shown
CategoryRaw estimateSmoothed estimate
Low0/5=0(0+1)/(5+3)=1/8
Medium2/5=0.4(2+1)/8=3/8
High3/5=0.6(3+1)/8=4/8
Total11/8+3/8+4/8=1
Prior0.4, other likelihood0.5, Low observedRaw class score0Smoothed score0.4×0.5×0.125=0.025

What this tells us: The previously impossible class now competes with other class scores, but the small count still makes its estimate uncertain.

Why the calculation works

  • A zero count is an estimate from finite data, not necessarily a real impossibility. In a product of categorical likelihoods it can overwhelm every other piece of evidence, so smoothing allocates a small amount of probability to all possible values.
  • Add-one Laplace smoothing adds one to every category count and adds the number of categories to the denominator. Changing only the zero numerator leaves probabilities that do not form the intended valid distribution.
  • The category vocabulary matters: three possible acoustic levels require three added counts, even when one was absent. Smoothing does not fix correlated measurements or create evidence for unobserved fault mechanisms.
Implementation steps and their purpose
  1. List all possible categories for the feature
  2. Count each category within the class
  3. Add one to every category count
  4. Add the number of possible categories to that class-feature total
  5. Use the smoothed likelihoods in the class-score product

Use the result and check it

Data, components and application

  • Only zero numerator changed → correct all counts and denominator → retain a valid probability distribution
  • Many categories with tiny data → consider grouping or more data → avoid estimates dominated by smoothing
  • Unseen category at deployment → define category handling during preparation → keep the model usable

How to evaluate it

Compare held-out log loss or classification metrics, especially cases containing uncommon categories.

Build the answer in this order

  1. Identify the zero-product problem
  2. State category count
  3. Show corrected numerator and denominator
  4. Continue the class comparison

What you observeWhy it happensWhat to changeWhy that helps
Smoothed category probabilities sum above oneOnly the absent category was adjustedRecompute every numerator and the full denominatorSmoothing adds a consistent set of pseudo-counts, not an isolated exception to probability arithmetic.
Common wrong answers and the exact correction
  • Adding one only to the zero count without denominator correction is not standard Laplace smoothing
  • This fixes estimation, not feature dependence.

When would this calculation be useful?

Use when limited training data leaves a category unobserved within a class.

Scenario cueSuitable choiceWhy it fits
A categorical likelihood is zero because no such value was observedUse the same smoothing rule across that feature’s categoriesThis avoids a single sampling gap setting the whole class score to zero.

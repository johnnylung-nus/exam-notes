A* search: which waiting node next?

  • g = actual accumulated cost from start; h = estimated cost to goal; f = g + h = estimated total through that node.
  • Frontier / open list = all discovered nodes still waiting to be explored. Select the smallest f across that list.
  • “Go back” means switch to a waiting branch, not retrace the route to a fixed splitting point.

C138

Imbalanced data and augmentation

Class imbalance means some target classes have far fewer examples. A model can achieve high overall accuracy while failing the rare class that matters most.

CalculationDiagramHow it worksWorked exampleChoose & designProblems & fixesExam answer

Expose the majority-class trap and cost response

Worked study example: Sample Q2(c) has 3000 normal and 2 abnormal sequences. For illustration call abnormal positive. A weighted training objective might give larger importance to each abnormal example, but that does not establish fault diversity.

What this tells us: Weights can prevent the majority loss from dominating, but cannot teach an unseen abnormal pattern. Collect diverse faults or consider normal-pattern screening.

Read the relationships and follow the choices

  • Imbalance can make overall accuracy reward ignoring the rare class. Count both the minority proportion and the diversity of its independent cases; many duplicates of two fault examples still describe only two observed fault situations.
  • Class weighting changes the cost of errors during fitting. Resampling changes which examples training sees. Threshold adjustment changes the final decision rule. These mechanisms are different and can be combined only with validation.
  • Augmentation must preserve the label and physical plausibility. Apply it to training cases after splitting original cases; transformed copies of the same image or sequence are not independent test evidence.
Implementation steps and their purpose
  1. Count examples and inspect coverage per class
  2. Split original cases before augmentation
  3. Apply training-only class weights or resampling
  4. Use label-preserving augmentation where appropriate
  5. Tune decision thresholds using validation costs
  6. Report minority-class metrics

Choose the method from the problem

Use when faults, fraud or some product classes are scarce; limited minority diversity is separate from simple count imbalance.

Scenario cueSuitable choiceWhy it fits
Fault misses are costlyUse class-sensitive loss/thresholds and report rare-class recallOverall accuracy suppresses the exact failure the business cares about.

Implement it and test the outcome

Data, components and application

  • Few abnormal cases → collect diverse faults or model normal behavior → two cases cannot represent all faults
  • Oversampling duplicates → validate carefully → repetition does not create new anomaly types
  • Invalid image transformation → restrict augmentation → preserve label meaning

How to evaluate it

Inspect confusion matrix, minority recall/precision and per-class F1; include false-alarm burden and uncertainty from tiny samples.

What the question requires

  2. Propose a smaller classifier tail while preserving required outputs.
  3. Recalculate weights plus biases and total reduction.
  4. Choose activations/loss consistent with the classification task.

Proposed answer points

  • The original tail is Flatten9408 → Dense256 → Dense128 → Dense918. Its Dense parameter counts are 2,408,704, 32,896 and 118,422; with 18,960 convolution parameters the total is 2,578,982. The first Dense alone accounts for about 93.4%, so the actual bottleneck is the flattened-to-dense connection.
  • A defensible replacement is Flatten9408→Dense64→Dense918. Unchanged convolutions:18,960; Dense64:602,176; output:59,670; total:680,806. Reduction:1,898,176≈73.6%.
  • Use ReLU in the hidden layers, softmax over the 918 mutually exclusive combined classes, and categorical cross-entropy. Smaller is not automatically better: check held-out quality.

Avoid: 5,000 unevenly spread images raise overfitting and class-imbalance concerns; those are related but different problems. The combined 918-way output is one design, not the only possible factorized output architecture.

C139

Confusion matrix and classification metrics

A confusion matrix separates correct positives, missed positives, false alarms and correct negatives. Choose metrics from the consequence of each error, not whichever number is largest.

CalculationDiagramHow it worksWorked exampleChoose & designProblems & fixesExam answer

Calculate positive-class metrics

Recall=TP/(TP+FN); Precision=TP/(TP+FP); F1=2TP/(2TP+FP+FN)
TP
correctly predicted purchasers
FN
missed purchasers
FP
nonpurchasers predicted as purchasers
TN
correctly rejected nonpurchasers
  1. Recall=80/100=0.80.
  2. Precision=80/120≈0.667.
  3. F1=160/220≈0.727.
  4. Accuracy=(80+860)/1000=0.94.

Interpret the result: Choose using error consequences,not the largest isolated metric.

Compute and interpret one confusion matrix

Worked study example: Illustrative held-out set: 80 true positives,20 false negatives,40 false positives,860 true negatives. Positive means purchaser.

All steps shown
MetricCalculationInterpretation
Accuracy(80+860)/1000 = 0.9494% of all cases correct
Recall80/(80+20) = 0.80Found 80% of actual purchasers
Precision80/(80+40) ≈ 0.667One third of predicted purchasers are false positives
F12×80/(2×80+40+20) ≈ 0.727Combined positive-class measure
Specificity860/(860+40) ≈ 0.956Correctly rejects most nonpurchasers

What this tells us: The same matrix supports different conclusions depending on error costs; 94% accuracy alone hides 20 missed purchasers.

Why the calculation works

  • Define positive before doing arithmetic. Recall divides correct positives by all actual positives, measuring misses; precision divides correct positives by all predicted positives, measuring false-alarm burden.
  • A threshold changes which scores become positive, so a model can trade recall for precision. Metric choice follows the consequence of errors: missing a purchaser differs from giving a cheap unused coupon.
  • F1 combines precision and recall but omits true negatives and does not encode the actual monetary ratio between false negatives and false positives. A similar F1 or accuracy cannot replace a business-cost argument.
Implementation steps and their purpose
  1. Define the positive class explicitly
  2. Count true positives, false negatives, false positives and true negatives
  3. Calculate recall as found positives divided by all actual positives
  4. Calculate precision as correct positives divided by all predicted positives
  5. Compare error costs and choose a threshold

Use the result and check it

Data, components and application

  • Accuracy hides missed purchasers → inspect recall → measure how many opportunities are missed
  • Too many coupon false alarms → inspect precision and coupon cost → judge operational burden
  • Class labels unclear → confirm matrix orientation → prevent reversed conclusions

How to evaluate it

Sample discussion favors SVM recall 0.9771 over NN 0.9616 when missing purchasers costs more than unused coupons; this is a cost-based choice.

Build the answer in this order

  1. State positive class
  2. Compare missed positives and false alarms
  3. Relate differences to business cost
  4. Justify the chosen model

C140

ROC and gain/lift charts

ROC compares true-positive rate against false-positive rate as the threshold changes. Gain and lift ask whether targeting the highest-scored cases finds more positives than random targeting.

CalculationDiagramHow it worksWorked exampleChoose & designProblems & fixes

Choose from the scenario

Useful for choosing operating thresholds or prioritizing a limited marketing capacity.

Scenario cueSuitable choiceWhy it fits
Only 200 customers can be contactedCompare gain/lift at top200, not just global AUCThe relevant question is which ranking gives the best usable group within the capacity constraint.

Calculate gain and lift at a coupon budget

Worked study example: Illustrative held-out population has 1000 customers,100 purchasers. The model ranks customers; the top200 contain50 purchasers.

All steps shown

Gain50/100 = 50%Finds half of all purchasers
Precision in target group50/200 = 25%One in four targeted customers purchases
Random baseline precision100/1000 = 10%Baseline purchaser rate
Lift25%/10% = 2.52.5 times random concentration
Same lift from gain50%/20% = 2.5Equivalent calculation

What this tells us: A 2.5 lift indicates useful concentration, but issuing 200 coupons is only worthwhile if the expected benefit exceeds campaign cost.

The distinction that changes the answer

  • ROC evaluates ranking across thresholds by comparing true-positive rate with false-positive rate. AUC summarizes discrimination, not the probability calibration or the profit at a particular threshold.
  • Gain asks what fraction of all positives is captured by targeting the highest-scored fraction of the population. Lift compares that capture with random targeting, so it directly relates to a limited outreach budget.
  • A ranking can have good AUC yet produce too many false positives at the selected operating point, especially with rare positives. Inspect the actual selected group and base rate rather than treating one summary score as a deployment decision.

EXTRA-SVM

Support vector machine: margin, scaling and business choice

A linear SVM learns a separating boundary with a large margin. The closest influential training cases are support vectors. A soft margin permits violations to balance fitting errors against a wider boundary.

CalculationDiagramHow it worksWorked exampleChoose & designProblems & fixesExam answer

Choose from the scenario

Use as a supervised classification baseline when a linear boundary is plausible; compare against an NN using operational costs rather than assuming the more complex model wins.

Scenario cueSuitable choiceWhy it fits
Missing purchasers is costly while unused coupons are cheapPrefer the given SVM conditionallyIts higher reported recall buys fewer missed opportunities at an acceptable extra false-positive cost.

Turn the given model comparison into a cost decision

Worked study example: Use the sample discussion’s reported missed-purchaser and false-positive counts, keeping its original matrix/prevalence inconsistency visible. Hypothetical cost per missed purchase is 10 units; unused coupon cost is 1 unit.

Trade-offSVM avoids 49 misses but adds 51 false positivesBenefit 490 minus extra cost 51 = 439
Break-even49×miss cost > 51×false-alarm costSVM favored when cost ratio exceeds 51/49

What this tells us: Accuracy is nearly equal, but the preferred model depends on relative error cost. Reverse the cost assumptions and the NN may become preferable.

The distinction that changes the answer

  • A linear SVM chooses a separating boundary with a large margin. Support vectors are the closest influential training cases; they define the difficult boundary region rather than every case contributing identically to its position.
  • Soft margin allows violations so noisy or overlapping data need not be perfectly separated. Larger penalty C emphasizes avoiding training violations; smaller C allows more tolerance. Tune this balance on prepared training/validation data.
  • A kernel can provide nonlinear boundaries, but the sample explicitly compares a linear SVM with an NN. Do not claim that the given SVM already performs arbitrary nonlinear reasoning; choose between them using observed costs and metrics.

What would make the choice wrong?

Common wrong answers and the exact correction

  • The penalty strength is not a learned feature weight

Apply the distinction

Data, components and application

  • Large feature scales distort the margin → standardize → make geometry meaningful
  • Penalty too strong fits difficult/noisy cases → tune a lower penalty → allow more tolerance
  • Nonlinear structure remains → compare a kernel model if justified → permit curved boundaries

How to evaluate it

Check held-out business value, class metrics and inference cost; revisit the decision if false-positive costs are high.

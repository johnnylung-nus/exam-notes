C154

Clustering vs classification

Classification learns known target categories from labeled cases. Clustering discovers groups from similarity without known category labels; the groups need interpretation after fitting.

How it worksWorked exampleChoose & designProblems & fixes

1. What problem does it solve?

Choose classification when purchase, fault or class labels are available; choose clustering when exploring unknown customer or operating groups.

Scenario cueSuitable choiceWhy it fits
Known purchase/no-purchase labels are suppliedUse supervised classificationThe objective is to predict an established outcome, not discover arbitrary customer groups.

2. How it works — what happens and why

  • Classification uses known category labels to learn boundaries that separate those meanings. Clustering uses a chosen similarity definition to discover groups; its numbered outputs have no inherent class, severity or business interpretation.
  • The same observations can produce different legitimate clusters under different features or scaling. Customer age groups and purchase-behavior groups answer different questions, so define the grouping objective before choosing distance.
  • A small remote group might represent a fault, a rare legitimate operating mode or measurement error. Clustering alone cannot decide which. Link the groups back to original features and obtain appropriate expert or labeled validation.
Implementation steps and their purpose
  1. State whether target labels exist
  2. Define the input observations and similarity
  3. For classification train against known labels
  4. For clustering fit a grouping method without pretending to know classes
  5. Profile discovered groups and connect them to an action

3. See why a cluster number is not a fault diagnosis

4. Design the solution and check the result

Data, components and application

  • A cluster is assumed to mean abnormal → inspect and validate → similarity does not establish a fault label
  • Labels too scarce → consider anomaly detection with normal data → do not invent a fully supervised dataset
  • Arbitrary scaling → prepare features → prevent unit-driven groups

How to evaluate it

Classification uses held-out target errors; clustering uses compactness/separation, stability and meaningful profiles.

Build the answer in this order

  1. Identify available supervision
  2. Choose prediction or discovery
  3. Explain output meaning
  4. State the right evaluation

  • Cluster numbers are arbitrary labels, not a ranked severity scale
  • Clusters need not match real class boundaries.

6. Turn understanding into an exam answer

  • “The cluster IDs only describe similarity groups; I profile them before assigning business meaning.”
  • “For labeled purchase outcomes I train a classifier; for only two known faults I consider normal-pattern screening and collect diagnostic evidence.”

C155

Distances and standardization for clustering

A clustering distance expresses what similar means. Numeric Euclidean distance is sensitive to feature scale; ordinal and nominal categories require a representation that respects their meaning.

How it worksWorked exampleChoose & designProblems & fixes

1. What problem does it solve?

Use before K-means or hierarchical clustering, because the distance determines which cases form groups.

Scenario cueSuitable choiceWhy it fits
Cluster countries using rates measured on different scalesStandardize meaningful numeric inputs before Euclidean clusteringOtherwise the largest numerical range drives the grouping more than the intended joint profile.

2. How it works — what happens and why

  • Distance is a modeling assumption about similarity, not a neutral preprocessing detail. Euclidean distance squares numeric coordinate differences, so a feature with large numerical units can dominate the result even when another feature matters more.
  • Standardization expresses differences relative to a feature’s spread. It is useful when raw units should not define importance, but it does not establish equal business relevance. Select features and weights for the grouping goal.
  • Ordinal values have order, but nominal job or browser codes do not have meaningful arithmetic gaps. An encoding such as lawyer1,doctor2,teacher3 falsely suggests teacher is twice as far from lawyer as doctor is unless that relation is explicitly justified.
Implementation steps and their purpose
  1. Identify numeric, ordinal and nominal inputs
  2. Choose features relevant to the grouping goal
  3. Standardize numeric features when unequal units should not dominate
  4. Choose appropriate categorical encoding/distance
  5. Inspect nearest and farthest examples for plausibility
  6. Fit and profile clusters

3. Watch a nearest neighbor reverse after scaling

Data, components and application

  • Nominal job codes treated as ordered numbers → use matching-based representation → avoid invented distance ordering
  • Extreme outliers dominate → investigate or use robust preparation → protect the grouping
  • Scale estimated from future data → fit on development data → preserve deployment validity

How to evaluate it

Check whether groups remain sensible across reasonable preparation choices; evaluate compactness and business profiles together.

Build the answer in this order

  1. Define desired similarity
  2. Identify scale/type mismatch
  3. Propose preparation and distance
  4. Explain the effect on groups

5. Diagnose the proposed model — change and justify

Common wrong answers and the exact correction
  • Standardization is not proof that every feature deserves equal weight
  • Category numbers do not create meaningful arithmetic automatically.

6. Turn understanding into an exam answer

  • “Raw income units dominate this distance, so I standardize using training statistics.”
  • “I still check the chosen features and profiles; equal numerical scaling does not prove equal substantive importance.”

C156

K-means and centroid updates

K-means forms K groups by repeatedly assigning each point to its nearest centroid and recomputing each centroid as the mean of its assigned points. Here K is the number of clusters.

How it worksWorked exampleChoose & designProblems & fixes

1. What problem does it solve?

Useful for numeric data when compact groups around representative means make sense.

Scenario cueSuitable choiceWhy it fits
Numeric observations form compact groupsUse scaled K-means with several startsNearest-centroid assignment and means provide an efficient representative grouping.

2. How it works — what happens and why

  • K-means alternates two operations under a squared-distance objective. With fixed centroids, nearest assignment minimizes each point’s contribution; with fixed membership, the arithmetic mean minimizes that cluster’s squared error.
  • These alternating improvements do not guarantee a global solution. Initial seeds and data geometry matter, and K must be specified. Outliers can pull a mean, while elongated or unequal-density groups may not match the compact-centroid assumption.
  • Track assignments and means separately when doing exam arithmetic. Recomputing means without reassignment is not a full iteration; evaluating a final clustering using stale centers yields the wrong error.
Implementation steps and their purpose
  1. Prepare numeric features and choose K
  2. Initialize K centroids
  3. Assign each point to its nearest centroid
  4. Replace each centroid with the mean of its assigned points
  5. Repeat until assignments or centroids stabilize
  6. Compare multiple initializations

3. Trace two K-means iterations

  • Different scales → standardize → prevent one feature dominating
  • Outliers or noncompact shapes → inspect or choose a better grouping method → means may misrepresent the data

How to evaluate it

Compare within-cluster squared error, silhouette, stability and business profiles over plausible K values.

Build the answer in this order

  • It reaches a local solution, not a guaranteed global optimum.

C157

K-means++ initialization

K-means++ selects initial centroids that tend to be spread out, then runs ordinary K-means. It reduces the risk that several starting centers occupy the same small region.

How it worksWorked exampleChoose & designProblems & fixes

1. What problem does it solve?

Use when standard random initialization produces unstable or poor cluster solutions.

Scenario cueSuitable choiceWhy it fits
Random starts repeatedly place centers in one regionTry K-means++ and compare several runsSpread-out seeds reduce that particular bad-start pattern without claiming a guaranteed best partition.

2. How it works — what happens and why

  • K-means++ changes initialization, not the later objective or centroid update. It tries to spread initial seeds so that several centers do not waste their starts in one dense local region.
  • After one random seed, each observation’s chance of becoming the next seed is proportional to its squared distance from its nearest existing seed. This is probabilistic; it does not deterministically choose the farthest point.
  • More spread-out starts often improve convergence and solution quality, but distant outliers also obtain high sampling weight. Scaling and outlier investigation remain important, and K is still supplied rather than discovered by this initialization.
Implementation steps and their purpose
  1. Prepare feature scales and choose K
  2. Select the first center randomly
  3. Find each point’s squared distance to its nearest chosen center
  4. Sample another center with probability proportional to that squared distance
  5. Repeat until K centers exist
  6. Run normal assignment-and-mean-update iterations

Compare final squared error and stability across starts, along with silhouette and meaningful profiles.

C158

Hierarchical clustering and linkage

Hierarchical clustering creates nested groups displayed in a dendrogram. Agglomerative clustering starts with one cluster per observation and repeatedly merges the closest pair. Linkage defines distance between clusters.

How it worksWorked exampleChoose & designProblems & fixes

1. What problem does it solve?

Useful for exploring grouping at several levels without selecting the final number of groups before constructing the hierarchy.

Scenario cueSuitable choiceWhy it fits
Need to inspect nested country or customer groupingsUse hierarchical clustering with a stated linkageThe hierarchy allows several defensible cut levels instead of only one flat partition.

2. How it works — what happens and why

  • Agglomerative clustering starts with individual observations and merges the nearest pair of current clusters. Because a merge is generally not undone, early distance and linkage choices shape the whole hierarchy.
  • Linkage answers what close clusters means: single uses nearest cross-pair, complete uses farthest cross-pair, average uses average cross-pairs, and Ward uses the increase in within-group squared error. These are different grouping preferences.
  • A dendrogram records merge order and height. Cutting it produces a chosen group count or distance level; large merge gaps can suggest a useful cut but need substantive profile and stability checks.
Implementation steps and their purpose
  1. Prepare features and choose observation distance
  2. Start with individual clusters
  3. Calculate inter-cluster distances under the chosen linkage
  4. Merge the closest pair
  5. Repeat and record merge heights
  6. Cut the dendrogram at a justified level and profile groups

3. Calculate three linkage distances on the same groups

Data, components and application

  • Single-link chains connect distinct groups → compare complete/average linkage → alter the grouping criterion
  • Outliers dominate merges → investigate → avoid interpreting noise as a segment
  • Many observations → consider cost → pairwise calculations can be expensive

How to evaluate it

Inspect dendrogram stability, separation and substantive group profiles; compare plausible linkage choices.

Build the answer in this order

  1. Explain merge sequence
  2. State linkage meaning
  3. Choose a defensible cut
  4. Interpret groups and limitations

5. Diagnose the proposed model — change and justify

  • Hierarchical merging usually cannot undo a bad earlier merge.

C159

Cluster evaluation and number of clusters

Cluster evaluation checks compactness, separation, stability and usefulness. Choosing K is a modeling decision; lower within-cluster error alone cannot determine the best count because that error normally falls as K grows.

How it worksWorked exampleChoose & designProblems & fixes

1. What problem does it solve?

Use when asked how many groups to keep or whether discovered segments are valid.

Scenario cueSuitable choiceWhy it fits
Asked how many clusters to retainCompare plausible K values with elbow, validity scores and profilesThis balances compactness, separation and usable complexity instead of maximizing a single training statistic.

2. How it works — what happens and why

  • Within-cluster squared error normally falls as K increases, eventually becoming zero with one centroid per observation. Therefore choosing the smallest error alone would produce an unhelpful answer; inspect diminishing returns and meaningful groups.
  • Silhouette compares a point’s average distance to its own group with its average distance to the nearest alternative group. Positive values indicate better cohesion than separation; near zero means boundary overlap, and negative values suggest a questionable assignment.
  • Other indices emphasize compactness and separation differently. Higher Calinski–Harabasz and lower Davies–Bouldin are favorable, but no technical score establishes that segments are stable or actionable. Profile groups and repeat reasonable starts/samples.
Implementation steps and their purpose
  1. Fit a plausible range of cluster counts
  2. Plot within-cluster squared error and inspect diminishing returns
  3. Compare silhouette and other validity indices
  4. Check stability across starts or samples
  5. Profile each group using original features
  6. Choose a useful interpretable solution

3. Combine elbow and silhouette evidence

4. Design the solution and check the result

Data, components and application

  • Choose largest K because error is smallest → use elbow plus validation → avoid trivial tiny groups
  • Nice statistics but no usable segments → inspect profiles → clusters must support the objective
  • Small unstable cluster → inspect rare real pattern versus noise → avoid automatic deletion

How to evaluate it

Higher silhouette/Calinski–Harabasz and lower Davies–Bouldin are favorable; no single score proves the true grouping.

Build the answer in this order

  1. State evaluation criteria
  2. Compare several K choices
  3. Explain technical and business evidence
  4. Defend a practical count

5. Diagnose the proposed model — change and justify

  • Silhouette near zero indicates overlapping/boundary cases, not perfect grouping.

  • “Error reductions fall from45 and15 to only3 and2, making K3 a plausible elbow.”
  • “I confirm with silhouette, stability and interpretable profiles before choosing that count.”

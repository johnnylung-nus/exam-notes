Steps on the lecture road map

Hill Climbing, selected by h: Arad (366) → Sibiu (253) → Fagaras (176) → Bucharest (0). Actual cost = 140 + 99 + 211 = 450.

Dijkstra, selected by g: Arad (0) → Zerind (75) → Timisoara (118) → Sibiu (140) → Oradea (146) → Rimnicu Vilcea (220) → Lugoj (229) → Fagaras (239) → Mehadia (299) → Pitesti (317) → Craiova (366) → Dobreta (374) → Bucharest (418).

Dijkstra's crucial update: Fagaras first proposes Bucharest at 239 + 211 = 450. Later Pitesti proposes 317 + 101 = 418. Replace its cost and parent; finish only when Bucharest is the smallest waiting g.

A*, selected by g+h: Arad (366) → Sibiu (393) → Rimnicu (413) → Fagaras (415) → Pitesti (417) → Bucharest (418). The selection order is not the final route.

Exam wording: Search = Reasoning Engine

In this lecture, search is the reasoning engine that explores possible states and actions to reach a goal, guided by an evaluation function.

State space + Actions + Goal + Evaluation → Search / Reasoning Engine. Recognise this wording when a scenario asks how the system chooses its next action or finds a solution.

Day 1: PDF p.71 / slide 76. This is the framing in the search chapter; reasoning can also use other methods.

Keep these distinctions

  • Selection order ≠ final travel route. Dijkstra considers Zerind and Timisoara, but the final route does not travel through them.
  • Hill Climbing's 0 is h at the goal, not a zero-cost journey. The actual journey costs 450.
  • Dijkstra is A* with h = 0. With equal edge costs, Dijkstra selects in breadth-first order.

Lecture wording: “Hill Climbing (Greedy Best First Search)” is the deck's label. This trace follows its best-child rule (earlier alternatives discarded). General greedy best-first search can instead keep a global waiting list; these are not identical algorithms.

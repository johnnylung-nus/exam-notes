RBF networks

An RBF network describes an input by its closeness to hidden-unit centers. Nearby inputs activate a Gaussian basis function strongly; the output combines these responses.

Two local basis responses become one prediction

Worked study example: Illustrative one-dimensional RBF network has centers 0 and 2, width 1 for both. Use Gaussian response exp(−distance²/2). Input is 0.5; output weights are 10 and 20, with zero output bias.

Read the relationships and follow the choices

  • An RBF unit asks how close the input is to a center, not on which side of a global straight boundary it lies. Its Gaussian response is strongest at the center and declines as distance grows.
  • The width determines a unit’s area of influence. Small widths create many narrow local bumps; large widths combine evidence over broad regions. The right choice depends on the data density and target smoothness.
  • Two-stage training separates representation from target fitting: cluster the prepared inputs to obtain centers and widths, then use labeled examples to learn the output combination. Center selection can therefore use unlabeled training inputs, but evaluation still needs held-out targets.
Implementation steps and their purpose
  1. Scale inputs before calculating distances
  2. Choose hidden centers, often using clustering
  3. Set a width for each center
  4. Calculate radial responses for each training input
  5. Learn supervised output weights

Choose the method from the problem

Useful for nonlinear mapping when local regions in feature space provide a meaningful representation.

Implement it and test the outcome

Data, components and application

  • Widths too narrow → validate wider widths → avoid memorizing isolated training cases
  • Widths too broad → reduce widths or add centers → distinguish meaningful regions
  • Many centers → reduce them with clustering → control model size

How to evaluate it

Tune center count and widths using validation classification or regression error; compare against a simple baseline.

General regression neural networks

GRNN predicts a numeric value by combining stored training targets, giving greater influence to examples closer to the new input. Its output divides a similarity-weighted target sum by the similarity sum.

  1. Targets10 and20 have similarities0.8 and0.2.
  2. Numerator=0.8×10+0.2×20=12.
  3. Denominator=0.8+0.2=1.
  4. Prediction=12/1=12.

Interpret the result: Normalize similarity weights; do not confuse this with an unrestricted RBF output.

A local average changes when support changes

Worked study example: Illustrative targets are 10,20,40. Similarities are already computed from distances using a selected Gaussian width; the two queries have different proximity patterns.

All steps shown
QuerySimilarity-weighted numerator / denominatorPrediction
Near first example(0.8×10 + 0.2×20 + 0.0×40)/(0.8+0.2+0)12
Between second and third(0.1×10 + 0.4×20 + 0.5×40)/(0.1+0.4+0.5)29
All patterns equally similar(1×10 + 1×20 + 1×40)/(1+1+1)23.33

What this tells us: The prediction follows nearby target evidence rather than a single fitted global straight line. A distant query still needs a low-support warning even if a numeric result is produced.

Why the calculation works

  • GRNN forms a normalized similarity-weighted estimate of stored targets. Nearby training patterns contribute strongly; remote patterns contribute weakly. The denominator makes the effective target weights sum to one.
  • Its smoothing width controls a bias–variance trade-off: narrow kernels approach a near-neighbor estimate and can follow noise; broad kernels average over dissimilar cases and can erase local structure.
  • The pattern layer represents training examples, so model size and prediction work can grow with the stored dataset. Fast fitting does not automatically mean cheap inference. Explain memory and support as well as error when recommending it.
Implementation steps and their purpose
  1. Scale and clean numeric inputs
  2. Store representative training inputs and targets in pattern units
  3. Calculate Gaussian similarity to the new input
  4. Sum similarity-weighted targets
  5. Divide by the sum of similarities

Use the result and check it

Data, components and application

  • Small smoothing width → increase after validation → reduce sensitivity to noise
  • Large training memory → reduce representative patterns → improve inference cost
  • Distant query → flag weak support → local averaging may be unreliable

How to evaluate it

Tune smoothing width using held-out MAE or RMSE; inspect errors in sparsely sampled regions.

Build the answer in this order

  1. Identify numeric target
  2. Explain similarity weighting
  3. Show numerator and denominator
  4. Justify smoothing and validation

When would this calculation be useful?

Use for nonlinear regression where local similarity predicts the target and storing representative examples is feasible.

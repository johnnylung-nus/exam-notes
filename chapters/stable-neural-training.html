C119

Vanishing / exploding gradients

Backpropagation repeatedly multiplies local derivatives. Very small products make early-layer gradients vanish; very large products make them explode, causing unstable updates.

Read the relationships and follow the choices

  • Early-weight gradients pass through chains of local derivatives. Repeated small factors produce vanishing signals; repeated large factors produce exploding signals. This is an optimization failure, distinct from fitting the training set too closely.
  • Saturated sigmoid activations have tiny derivatives when their totals are extreme. Initialization and input scaling influence whether a deep model starts there; simply training longer may not recover a practically absent learning signal.
  • Exploding gradients require controlled updates, such as clipping and a suitable learning rate. Residual paths or LSTM address different propagation structures. Dropout is a regularizer, not a universal cure for missing or enormous gradients.
Implementation steps and their purpose
  1. Inspect training loss and gradient magnitudes
  2. Check saturation, depth and initialization
  3. Choose activation-compatible initialization
  4. Use residual connections for deep feedforward networks or LSTM for long sequences
  5. Reduce excessive learning rates and clip exploding gradients when needed

Choose the method from the problem

Diagnose deep networks or long recurrent chains that learn very slowly, stop improving, or produce unstable losses.

C120

Xavier / He initialization

Initialization sets starting weights before learning. Random weights break symmetry; their scale should avoid making activations or gradients disappear or grow excessively through the network.

n
incoming connections per neuron
  1. For n=100,He variance=0.02.
  2. He standard deviation=√0.02≈0.141.
  3. The stated lecture Xavier uniform bounds are±0.1.
  4. Use the stated initializer convention; other Xavier variants use fan-in and fan-out.

Interpret the result: Random weights break symmetry; suitable variance preserves signal scale.

Read the relationships and follow the choices

  • Identical zero connecting weights leave hidden units symmetric: identical inputs generate identical responses and matching gradients. Random connecting weights allow units to develop different useful features; zero biases do not create the same problem when weights differ.
  • Weight scale controls activation and gradient propagation. Excessively large sigmoid totals saturate; excessively small values attenuate signals across depth. The appropriate distribution depends on the number of incoming connections and chosen activation.
  • He initialization accounts for ReLU suppressing negative responses. Xavier-style methods balance signal propagation for sigmoid/tanh-type networks. Several Xavier conventions exist, so use the lecture’s or implementation’s stated formula instead of mixing fan-in and fan-out definitions.
Implementation steps and their purpose
  1. Identify hidden activation type
  2. Choose Xavier-style initialization for sigmoid/tanh networks
  3. Choose He initialization for ReLU networks
  4. Start biases at zero when appropriate
  5. Train and inspect activation, gradient and loss behavior

Choose the method from the problem

Use when designing or debugging a deep network, especially if training fails from the beginning.

Scenario cueSuitable choiceWhy it fits
Deep network uses ReLU hidden unitsStart with a compatible He initializerIt targets the variance change caused by ReLU rather than assuming any tiny random numbers are equivalent.

Where the graph or reasoning can fail

What you observeWhy it happensWhat to changeWhy that helps
Sigmoid hidden outputs start almost all at zero or oneInitial totals are too extremeReduce scale and check prepared input magnitudesAvoiding saturation preserves useful derivatives so earlier weights receive learning signals.
Common wrong answers and the exact correction
  • Xavier formulas have multiple conventions
  • use the lecture or stated implementation convention in a calculation
  • Biases can be zero even though all connecting weights should not be identical.

Implement it and test the outcome

Data, components and application

  • All weights identical → randomize → neurons can learn different features
  • Huge initial weights saturate sigmoid → reduce scale → maintain useful derivatives
  • Tiny initial weights → choose suitable variance → preserve signals across depth

How to evaluate it

Check stable convergence and validation performance across reasonable random seeds; initialization is one part of the training setup.

Build the answer in this order

  1. Name the activation
  2. Choose a compatible initializer
  3. Explain symmetry and scale
  4. Distinguish initialization from regularization

An answer you could write

  • “The initializer matches the activation and incoming connection count.”
  • “Randomization breaks symmetry; variance controls signal scale, rather than penalizing the final learned weights.”

C123

Batch normalization

Batch normalization standardizes intermediate activations using batch statistics during training, then learns scale and shift. It often makes optimization more stable; any regularization effect is secondary.

  3. Scaleγ=2,shiftβ=0.5 gives[−1.5,2.5].
  4. At inference,use stored statistics rather than the current test batch.

Interpret the result: Batch normalization differs from input scaling, dropout and weight penalties.

Normalize and then learn a useful scale

Worked study example: Illustrative batch for one feature is [1,3], mean 2 and variance 1. Ignore the tiny stability constant for arithmetic. Learned scale is 2 and learned shift is 0.5.

What this tells us: The transformed training pair has mean 0.5, demonstrating why learned shift breaks the simplistic permanent-zero-mean interpretation.

Why the calculation works

  • Batch normalization normalizes intermediate features with batch mean and variance during training, then applies learned scale and shift. Those learned terms can restore a useful distribution; normalized does not mean permanently mean zero and variance one.
  • Running statistics accumulated during training are used at inference. This avoids making one deployed prediction depend on whatever unrelated observations happen to share its test batch.
  • It often improves optimization and introduces batch-related noise, but does not explicitly shrink weights like L2 or randomly drop units like dropout. Input scaling fitted once on training features is also different from normalization of intermediate activations.
Implementation steps and their purpose
  1. Insert batch normalization at an appropriate layer position
  2. Estimate batch mean and variance during training
  3. Normalize activations and apply learned scale and shift
  4. Maintain running statistics
  5. Use stored statistics in inference mode

Use the result and check it

Data, components and application

  • Very small batches produce noisy estimates → reconsider batch size or normalization choice → stabilize statistics
  • Training/evaluation mode mismatch → use inference mode for testing → avoid batch-dependent errors

How to evaluate it

Compare convergence speed, stable loss and held-out quality; do not claim it guarantees absence of overfitting.

Build the answer in this order

  1. Identify optimization difficulty
  2. Explain normalization and learned rescaling
  3. State training/inference distinction
  4. Compare with weight penalties and dropout

C124

Residual connections

A residual connection adds a block’s input to its learned transformation. The block can learn a correction to the input rather than having to rebuild the entire desired mapping.

CalculationDiagramHow it worksWorked exampleChoose & designProblems & fixes

What must the system deliver?

Use to train deeper networks more effectively when adding layers makes optimization difficult.

Scenario cueSuitable choiceWhy it fits
Adding depth worsens training even with sufficient capacityUse a shape-compatible residual blockThe network can learn small refinements and retain a direct path instead of relearning the entire representation at every block.

What each component receives and produces

  • A residual block adds its input to a learned transformation. Instead of reconstructing the whole desired output, the learned path can concentrate on the correction that needs to be made.
  • If no correction helps, a near-zero learned path approximately preserves the input. This makes additional depth easier to optimize than forcing every extra layer to learn an identity transformation indirectly.
  • Addition requires equal shapes. If spatial dimensions or channel counts change, the shortcut needs a compatible projection or downsampling. A residual route improves information and gradient flow, but does not automatically solve overfitting caused by limited labels.
Implementation steps and their purpose
  1. Group layers into a residual block
  2. Compute the block transformation
  3. Pass the original input through a shortcut
  4. Add shortcut and block output
  5. Match shapes with a projection when necessary
  6. Train and compare against a plain network

Compare learning the output with learning a correction

Data, components and application

  • Input/output dimensions differ → use a projection shortcut → addition requires compatible shapes
  • Deep plain network degrades → residual paths → improve information and gradient flow
  • Overfitting persists → use appropriate regularization → easier optimization is not enough

How to evaluate it

Assess both successful optimization and validation performance at comparable model sizes.

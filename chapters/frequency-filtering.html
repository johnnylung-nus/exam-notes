C087

Time and frequency representation

Time representation shows how readings change; frequency representation shows which rates of variation contribute. Choose according to the question.

How it worksWorked exampleChoose & designProblems & fixes

1. What problem does it solve?

Use when a repeated pattern is hard to see in raw readings or when the timing of a change matters.

Scenario cueSuitable choiceWhy it fits
Steady repeated component soughtFrequency featuresDirectly exposes periodic content.
Short change or sequence order soughtTime-frequency/localized featuresRetains where the component occurs.

2. How it works — what happens and why

  • Time-domain samples preserve order and change locations. Frequency coefficients expose repeated rates of variation that may be hard to see directly.
  • The transformation is a representation change, not automatically information reduction; loss occurs when coefficients or timing detail are discarded/aggregated.
  • A global frequency description is unsuitable when the order of components defines the event. Localized transforms retain more temporal structure.
  • Feature choice should follow the recognition question: steady vibration frequency and brief transient detection need different evidence.
Implementation steps and their purpose
  1. Identify whether the task needs event timing, frequency content or both.
  2. Inspect the time signal.
  3. Use Fourier analysis for overall frequency components.
  4. If timing matters, use a localized representation such as the lecture’s wavelet approach.
  5. Extract relevant coefficients/statistics and evaluate the task.

4. Design the solution and check the result

Data, components and application

  • Time information lost → use localized analysis → preserves event timing.
  • Raw waveform too complex → transform to relevant frequency features → exposes repeated structure.
  • Transform chosen for appearance → test target task → a clear plot is not proof of useful evidence.

How to evaluate it

Check retained frequency/time information and downstream recognition on unseen sequences.

Build the answer in this order

  3. Explain information gained/lost.
  4. Evaluate downstream usefulness.

6. Turn understanding into an exam answer

  • I need both the frequency and its occurrence time, so a global spectrum alone is insufficient.
  • I extract localized coefficients and compare them across windows.
  • The final test checks whether reversed or shifted events remain distinguishable.

C088

Fourier transformation

Fourier transformation expresses a signal using sinusoidal components. Coefficients tell how much each frequency contributes; the inverse reconstructs it.

How it worksWorked exampleChoose & designProblems & fixes

1. What problem does it solve?

Use to identify frequency content and create features for sensor classification or analysis.

Scenario cueSuitable choiceWhy it fits
Need fast computation of discrete transformFFT algorithmComputes the transform efficiently rather than defining a different physical feature.
Need reconstruct original exactlyRetain required complex coefficientsMagnitude alone generally loses phase information.

2. How it works — what happens and why

  • The discrete Fourier transform compares the sampled signal with sinusoidal basis patterns. Each coefficient represents a particular frequency component’s contribution.
  • The zero-frequency coefficient collects the constant/DC contribution. Under the lecture’s unnormalized forward convention it is the sum of samples, not their average.
  • Complex coefficients retain magnitude and phase information. Magnitude-only plots are useful summaries but omit information needed for exact reconstruction.
  • The inverse combines all weighted components to recover the original samples; frequency selection instead produces an altered or approximate signal.
Implementation steps and their purpose
  1. Prepare the sampled signal and its sampling rate.
  2. Calculate the Fourier coefficients.
  3. Inspect useful frequency components.
  4. Use coefficients or derived features for the task.
  5. Apply the inverse if reconstruction is needed.
  6. Check whether time localization is required.

3. Use the lecture’s four-sample Fourier result

Worked study example: Lecture input [2,3,4,4]; i denotes the imaginary unit. No derivation beyond the taught example is required.

4. Design the solution and check the result

Data, components and application

  • Timing of change hidden → use wavelet/windowed analysis → overall frequencies do not locate events.
  • Frequency bins misread → retain sampling-rate information → bin number alone is not frequency in hertz.
  • Unnecessary complex arithmetic → explain representation first → supports scenario reasoning.

How to evaluate it

Verify inverse reconstruction and whether chosen frequency features distinguish the required classes/events.

Build the answer in this order

  1. Why frequency analysis?
  2. Transform signal.
  3. Interpret useful components.
  4. State localization limit and evaluate.

5. Diagnose the proposed model — change and justify

Common wrong answers and the exact correction

  • Do not discard phase and expect exact reconstruction.

6. Turn understanding into an exam answer

  • The transform represents the signal as weighted sinusoidal components.
  • For [2,3,4,4], the zero-frequency coefficient is 13 and the mean is 3.25 under this convention.
  • I retain phase when exact reconstruction is needed and evaluate the selected frequency features on the target task.

C089

Filtering and convolution

Filtering emphasizes or removes selected signal components. Convolution applies a local filter across the signal; low-pass filtering smooths while high-pass filtering emphasizes changes.

How it worksWorked exampleChoose & designProblems & fixes

1. What problem does it solve?

Use for noise reduction, feature extraction and the lecture’s wavelet decomposition/reconstruction.

Scenario cueSuitable choiceWhy it fits
Slow trend needed, high-frequency noise irrelevantSmoothing/low-passRetains the slow component more strongly.
Abrupt edge/fault transient mattersRetain high-pass detailThat rapid change may be the useful signal.

2. How it works — what happens and why

  • A filter combines neighbouring samples with specified weights. Repeated across positions, it emphasizes patterns matching those weights and suppresses others.
  • A low-pass operation smooths local variation; a high-pass operation measures differences. Neither knows automatically which variation is noise.
  • Wavelet decomposition uses low/high-pass branches with downsampling to separate approximation and detail at several scales.
  • Denoising modifies selected coefficients and reconstructs the signal. The amount removed must be justified by retained useful features, not visual smoothness alone.
Implementation steps and their purpose
  1. Identify the unwanted variation and useful event detail.
  2. Choose a suitable low-pass/high-pass filter.
  3. Apply the filter consistently across the signal.
  4. For wavelets, split approximation/detail and downsample.
  5. Retain or modify useful coefficients.
  6. Reconstruct when a cleaned signal is required.

4. Design the solution and check the result

Data, components and application

  • Useful fast event smoothed away → choose filtering strength using the task → noise removal must preserve evidence.
  • Boundary artifacts → state extension method → edge values depend on it.
  • Denoising judged only visually → check downstream accuracy → smooth does not always mean correct.

How to evaluate it

Compare original/cleaned signals, retained event details and task performance; check edge and transient behaviour.

Build the answer in this order

  1. Noise versus useful component.
  2. Filter/decomposition choice.
  3. Retained detail and reconstruction.
  4. Evaluate task impact.

5. Diagnose the proposed model — change and justify

What you observeWhy it happensWhat to changeWhy that helps
Fault vanishes after cleaningAggressive filtering removes transientReduce removal and test task evidenceNoise and faults can occupy similar frequencies.
Boundary values distortedExtension/padding convention ignoredState and test boundary handlingNeighbourhood operations need values beyond edges.
Common wrong answers and the exact correction
  • High-frequency content is not always noise.
  • Hand-crafted filters and learned convolution kernels have different parameter origins.

6. Turn understanding into an exam answer

  • I separate approximation and detail using low/high-pass operations.
  • I remove only coefficients judged unwanted under the task assumptions, then reconstruct.
  • I verify that the denoised output retains the event and improves held-out task performance.

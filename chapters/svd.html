SVD & principal components

What is decomposed, where PC directions come from, and which quantities mean variance.

Sources and specific lecture caveats are shown beside each detailed concept below.

What SVD does

  • Singular value decomposition (SVD): factor a real matrix X into U, Σ, and Vᵀ.
  • U and V contain orthonormal directions. Σ contains non-negative singular values, ordered largest first.
  • Keeping the largest k singular values and matching vectors gives a rank-at-most-k approximation.
X=UΣVTXk=UkΣkVkT

X: n rows × d features. Truncated shapes: Uₖ is n × k, Σₖ is k × k, Vₖᵀ is k × d.

Reference: NumPy: SVD definition and shapes.

How SVD finds principal components

  • Original features: the input columns. PC directions: learned directions formed from those features.
  • For PCA, centre the feature columns first. Standardize if differences in units or scale should not dominate.
  • For centred X, the columns of V are PC directions. Projected coordinates (PC scores) are XV = UΣ.
  • SVD works on X directly. Alternatively, eigendecompose its feature covariance matrix. The resulting PC directions agree, up to sign and rotations within tied eigenspaces.
C=XTXn−1λj=σj2n−1

n observations, n > 1. λⱼ is the variance along PC j; σⱼ is the corresponding singular value.

Variance, covariance, and standard deviation

  • Variance: spread of one feature around its mean, measured using squared deviations.
  • Standard deviation: square root of variance. “Mean ± standard deviation” is an interval description, not the variance.
  • Covariance: how two features vary together. Its sign shows whether their centred values tend to move together or oppositely.
  • The covariance matrix has feature variances on its diagonal and pairwise covariances off the diagonal.

Corrections from the available discussion

  • “Large-scale features make the model stop learning” — Incorrect. For PCA, they can dominate the variance and therefore the PC directions.
  • “Calculate each feature’s variance to find the PCs” — Incomplete. Relationships between features also matter. Use covariance eigendecomposition or SVD of centred data.
  • “Features and PCs are the same” — Incorrect. Features are the original variables; PCs use new directions built from them.
  • “Both methods use n dimensions” — Ambiguous. State n observations and d features. Feature covariance has shape d × d; the data matrix has shape n × d.

What to examine in a scenario

  • Separate target and identifiers from the feature matrix when learning unsupervised PCA directions.
  • Fit centring, scaling, and PCA on training data only; reuse those fitted transformations on held-out data.
  • Choose k by the retained variance and the actual task. Greater retained variance does not guarantee better prediction.
  • SVD does not automatically discard components; truncation is the reduction step.
  • A reconstruction objective measures how closely Xₖ approximates X. That is not automatically a downstream classifier’s loss.

Reference: scikit-learn: PCA, centring, and variance.

PCA, variance, and principal directions

PCA replaces correlated numeric features with new uncorrelated directions, ordered by how much data variation they capture. It solves representation and dimensionality reduction, not collaborative recommendation.

Read the relationships and follow the choices

  • PCA rotates prepared numeric data to directions with maximum variance, then retains only some directions. It does not use the prediction target to seek the most discriminative directions, so high retained variance need not imply high purchase accuracy.
  • A component direction is a set of coefficients; a component score is one observation’s coordinate along that direction. Large absolute loadings help name the pattern, but a component sign can be reversed without changing the represented axis.
  • Fit centering, scaling and directions on training predictors only. Revenue must not be included when predicting Revenue. PCs are uncorrelated in the fitted covariance sense, not generally independent; ordinary scores need not have unit variance unless standardized/whitened.
Implementation steps and their purpose
  1. Exclude the prediction target and future information
  2. Split before fitting PCA
  3. Center training features and standardize when units require it
  4. Fit principal directions using training inputs
  5. Choose component count using variance and validation
  6. Transform validation/test inputs using the fitted preparation and directions

Choose the method from the problem

Useful for compressing related features or reducing multicollinearity, while accepting some loss of original-feature interpretability.

ISY5002 Q1(e)(i) — Select a PCA component count with a stated criterion

What the question requires

  1. Read the explained-variance percentages.
  2. State a criterion rather than inventing a required cutoff.
  3. Accumulate the percentages.
  4. Choose the smallest count meeting the criterion.

Proposed answer points

  • With a stated 90% cumulative-variance criterion, retain ten components: the first nine sum to 86.8%, the first ten to 92.2%.
  • Other justified criteria can produce different counts; the question does not mandate 90%.

Avoid: Ten is not a universal PCA rule. Do not confuse number of original features with number of retained components.

Eigenvalues / eigenvectors and SVD

For PCA, eigenvectors specify principal directions and eigenvalues tell how much variance each direction captures. SVD is another way to obtain those directions from the centered data matrix.

What information this representation preserves

  • A covariance eigenvector tells a direction that the covariance transformation scales without rotating; its eigenvalue is the variance along that principal direction. The words direction and amount prevent treating eigenvalues as feature coefficients.
  • SVD decomposes the centered data matrix directly. Its right singular vectors give the same PCA directions, and squared singular values divided by sample count minus one give covariance eigenvalues under the sample-covariance convention.
  • For explained-variance ratios the common sample-size denominator cancels, but squaring does not. Summing singular values instead of their squares answers the wrong question. Components, loadings and observation scores are related quantities with different roles, not interchangeable tables.
Implementation steps and their purpose
  1. Prepare and center the feature matrix
  2. Obtain directions from covariance eigenvectors or from SVD of centered inputs
  3. Sort directions by eigenvalue or singular value
  4. Select component count using cumulative explained variance
  5. Project prepared observations onto the retained directions

Prepare the data and validate the representation

Data, components and application

  • Sum raw singular values for variance → square them first → variance depends on squared singular values
  • Forget centering → center using training means → obtain PCA directions around the mean
  • Interpret loadings as observations → distinguish directions from scores → avoid category mistakes

How to evaluate it

Check retained variance, reconstruction usefulness and downstream held-out performance; retain more components only when justified.

Build the answer in this order

  1. Explain direction versus amount
  2. Show retention arithmetic
  3. Distinguish eigenvectors/loadings from scores
  4. Apply the same fitted transform to new cases

Choose the representation from the task

Use to connect the geometric PCA explanation with variance-retention calculations without treating symbols as a separate formula table.

Artificial neuron, weights, bias, activation

A neuron combines inputs using learned weights, adds a bias, then applies an activation. Weights control input influence; bias shifts the point at which the neuron responds.

Follow one neuron from evidence to output

Worked study example: Illustrative binary neuron: page engagement input 2, exit-rate input 0.5; their weights are 0.8 and −1.2; bias is −0.4. The numbers illustrate arithmetic, not a fitted bookstore model.

All steps shown
OperationCalculationMeaning
Engagement contribution2 × 0.8 = 1.6Supports the positive output
Exit contribution0.5 × (−1.2) = −0.6Opposes the positive output
Add bias1.6 − 0.6 − 0.4 = 0.6Pre-activation total
Apply sigmoid1 / (1 + exp(−0.6)) ≈ 0.646One bounded prediction score

What this tells us: At decision threshold 0.5 this predicts the positive class. Raising the decision threshold to 0.7 changes the decision without changing the learned weights.

Why the calculation works

  • Think of each weight as a learned sensitivity: increasing an input by one changes the pre-activation total by that input’s weight, while the other inputs stay fixed. A negative weight contributes evidence in the opposite direction.
  • The bias moves the boundary without requiring any measured input to change. Treat it as an adjustable constant, not as a new property measured from the visitor or image.
  • The activation acts after the weighted sum. A hard threshold turns the total into a class; sigmoid turns it into a bounded score; a hidden nonlinear activation allows combinations that a single linear equation cannot express.
Implementation steps and their purpose
  1. Encode each input numerically
  2. Multiply inputs by their weights and add the bias
  3. Apply the chosen activation
  4. Compare output with the training target and update weights

Use the result and check it

Data, components and application

  • Different input scales distort learning → scale using training statistics → inputs become comparable
  • Only linear layers → add nonlinear hidden activations → stacked layers can represent nonlinear patterns

How to evaluate it

Choose classification metrics or regression error to match the target; training output alone does not establish generalization.

Build the answer in this order

C105

Perceptron and linear separability

A single perceptron makes a binary decision using one straight separating boundary. It can learn a solution only when the training classes are linearly separable.

CalculationDiagramHow it worksWorked exampleChoose & designProblems & fixes

One wrong positive updates a perceptron

Worked study example: Illustrative current weights are 0.2 and −0.1, bias −0.4; input is (1,2), target class 1; output is 1 when the total is positive. Learning rate is 0.1.

All steps shown

Pre-activation0.2×1 − 0.1×2 − 0.4 = −0.4Prediction 0, target 1

Bias−0.4 + 0.1×(1−0)−0.3
Recheck same case0.3×1 + 0.1×2 − 0.30.2: now predicts 1

What this tells us: Fixing one case can change other decisions, so repeat across the training set. If no separating line exists, repeated updates cannot create one.

Interpret the result: A wrong positive example increases its active-input weights.

Read the relationships and follow the choices

  • A perceptron’s threshold cuts feature space into two sides. With two inputs the boundary is a line; adding input dimensions changes it to a hyperplane, but does not make it nonlinear.
  • Its learning signal comes from a wrong class decision. A correctly classified training case makes no update even if it is very close to the boundary; a wrong case moves the boundary toward classifying it correctly.
  • An update is proportional to the input: a feature equal to zero gets no weight update from that case. The bias can still change because its fixed input is one. This is why tracing the bias matters.
Implementation steps and their purpose
  1. Initialize weights and bias
  2. Calculate weighted input and hard-threshold output
  3. Find target minus predicted output
  4. Adjust each weight by learning rate × error × its input
  5. Repeat over examples

Choose the method from the problem

Useful as a simple binary baseline; unsuitable when the classes require curved or disconnected decision regions.

Scenario cueSuitable choiceWhy it fits
XOR labels on the four binary cornersUse hidden nonlinear units instead of one perceptronNo single line separates the two positive corners from the two negative corners.

Where the graph or reasoning can fail

What you observeWhy it happensWhat to changeWhy that helps
Updates continue without eliminating mistakesThe classes overlap or are not linearly separableChange the representation or use an MLPThe limitation is the available decision-boundary shape, not merely insufficient iterations.
Common wrong answers and the exact correction
  • Training longer cannot make one perceptron solve XOR
  • A threshold output is not a calibrated probability.

Implement it and test the outcome

Data, components and application

  • Nonseparable classes → use nonlinear hidden layers → combine several boundaries
  • Large learning steps oscillate → reduce learning rate → updates become controlled

How to evaluate it

Check errors on unseen cases and whether a linear decision boundary is plausible; failure to converge may reflect the model limitation.

Build the answer in this order

  1. Inspect the class arrangement
  2. Decide whether a straight boundary suffices
  3. Show one update if asked
  4. Justify an MLP when it does not

An answer you could write

  • “A single perceptron is unsuitable because one linear boundary cannot separate the classes shown.”
  • “I would add nonlinear hidden units so several learned boundaries can be combined, then compare unseen-case errors.”

ADALINE and delta rule

ADALINE learns from the continuous weighted sum before thresholding. The delta rule changes weights to reduce squared prediction error, rather than using only the final class decision.

  3. New w=0.32,b=0.06; y=0.70.

Worked study example: Illustrative one-input ADALINE has weight 0.2, bias 0, input 2 and target 1. Use half-squared error and learning rate 0.1.

All steps shown

What this tells us: This step reduces the continuous prediction error. Applying the final bipolar threshold is a separate output decision, not the number inserted into the delta rule.

Why the calculation works

  • ADALINE trains against the continuous weighted sum, so the size of a mistake matters even before the threshold is applied. A small error produces a small update rather than the same correction as any other wrong binary output.
  • Squared-error loss is smooth in the weights of a linear unit. Moving against its gradient gives the delta rule: learning rate × target-minus-linear-output × input. State whether the half-squared-error convention is used if doing derivative arithmetic.
  • The final threshold may provide a class label, but it is outside the differentiable training signal. Confusing the linear output with the thresholded output erases the core distinction from a perceptron.
Implementation steps and their purpose
  1. Calculate the continuous weighted sum
  2. Subtract it from the target
  3. Multiply error by input and learning rate to obtain the weight adjustment
  4. Update weights and repeat
  5. Apply a threshold if a final binary class is required

Use the result and check it

Data, components and application

  • Unscaled inputs cause unstable updates → standardize → gradients are better balanced
  • Nonlinear target → add nonlinear hidden structure → a single linear unit cannot express it

How to evaluate it

Track mean squared error on training and validation data, and classification performance if a threshold is applied.

Build the answer in this order

  1. State which output supplies the error
  2. Calculate the error
  3. Show the update
  4. Explain the limitation of one linear unit

Common calculation and modelling mistakes

What you observeWhy it happensWhat to changeWhy that helps
Loss jumps or oscillates after each updateLarge inputs or learning rate make corrections excessiveScale inputs and reduce the learning rateThe weight update contains the input value, so large magnitudes amplify every correction.
Common wrong answers and the exact correction
  • Do not compute ADALINE learning error from the thresholded class
  • ADALINE is not automatically a multilayer nonlinear model.

When would this calculation be useful?

Use to explain gradient-based learning and contrast ADALINE with the perceptron.

  • “The adjustment is positive here because the current output is too low; its size depends on both the input and learning rate.”

C107

MLP and backpropagation

An MLP passes inputs through hidden layers to predict a target. Backpropagation calculates how each weight contributed to the loss, allowing a gradient-based optimizer to update it.

CalculationDiagramHow it worksWorked exampleChoose & designProblems & fixesExam answer

What must the system deliver?

Use for supervised nonlinear relationships, especially prepared tabular features; choose architecture complexity to fit available data.

Scenario cueSuitable choiceWhy it fits
Unordered prepared customer features predict purchaseStart with a small MLP and binary headThe hidden layers model interactions while one sigmoid output matches a binary target.

What each component receives and produces

  • An MLP learns intermediate features whose targets are not directly labeled. Backpropagation assigns credit or blame to each hidden unit by following how that unit influences the final loss through later weights.
  • Forward propagation computes the prediction and loss. Backward propagation computes derivatives; the optimizer then changes parameters. Calling all three backpropagation hides the actual sequence required in an architecture answer.
  • For a hidden unit, the downstream error is multiplied by its outgoing weight and its activation derivative. If either is tiny, little learning reaches that unit; this explains why activation and initialization choices affect early layers.
Implementation steps and their purpose
  1. Prepare inputs and training labels
  2. Run a forward pass through hidden and output layers
  3. Calculate task-appropriate loss
  4. Propagate loss gradients backward using the chain rule
  5. Update weights and monitor validation performance

Data, components and application

  • Poor gradients → inspect activation and initialization → restore useful learning signals

How to evaluate it

Assess held-out precision, recall and loss for classification, or regression error for numeric targets.

C108

Activation-function choices

Hidden activations provide nonlinearity. Output activation expresses the required prediction: sigmoid for one binary probability, softmax for mutually exclusive classes, and linear output for unrestricted numeric regression.

CalculationDiagramHow it worksWorked exampleChoose & designProblems & fixesExam answer

Match outputs to the actual task

Worked study example: Illustrative predictions compare three target structures; natural logarithms are used for cross-entropy values below.

All steps shown
TaskOutput/targetLoss or decision
Purchase yes/noSigmoid probability 0.8; target purchase 1Binary cross-entropy −ln(0.8) ≈ 0.223
Confident missed purchaseSigmoid probability 0.1; target purchase 1−ln(0.1) ≈ 2.303: much larger penalty
Exactly one of three classesSoftmax [0.1,0.7,0.2]; correct class secondCategorical cross-entropy −ln(0.7) ≈ 0.357
Two attributes may both applySeparate sigmoid scores [0.8,0.9]Both can be positive; no sum-to-one requirement

What this tells us: For the sample’s 918 exclusive product combinations, 918 softmax outputs preserve that specified task. Changing to separate attribute heads requires a justified label redesign.

Confident wrong classifications cost more

Binary loss for positive target = −ln(p)
p
predicted probability of the positive class
ln
natural logarithm
  1. Correct-positive probability0.8 gives −ln(0.8)≈0.223.
  2. Probability0.1 for the same true positive gives −ln(0.1)≈2.303.
  3. For918 mutually exclusive classes, use918 softmax outputs and categorical cross-entropy.

Interpret the result: The final activation expresses the target; the loss judges its prediction.

Read the relationships and follow the choices

  • A hidden activation must do more than rescale a linear expression. Without nonlinearity, several stacked Dense layers still collapse into one linear mapping, so extra layers do not create the intended curved decision regions.
  • Choose the output from the label meaning. Softmax is appropriate when exactly one class is correct; separate sigmoids are appropriate when several labels can independently be true. A numeric target need not be bounded between zero and one.
  • Loss assesses whether the prediction matches the label. Cross-entropy strongly penalizes confident wrong class predictions, while squared error is natural for a continuous quantity. The activation is a transformation, not the training objective.
Implementation steps and their purpose
  1. Identify binary, multiclass, multilabel or numeric output
  2. Use ReLU as a practical hidden-layer choice
  3. Choose output activation consistent with the labels
  4. Pair it with an appropriate loss
  5. Inspect gradient and validation behavior

Choose the method from the problem

Choose activations from the target meaning and gradient behavior, rather than using the same function everywhere.

Scenario cueSuitable choiceWhy it fits
Predict an unrestricted physical quantityUse a linear output and regression lossA sigmoid would artificially restrict the range unless the target had first been appropriately transformed.

Where the graph or reasoning can fail

What you observeWhy it happensWhat to changeWhy that helps
Deep sigmoid hidden layers learn very slowlyLarge totals push sigmoid into saturationUse suitable initialization and consider ReLU hidden layersSaturated sigmoid derivatives are small, weakening gradients sent to earlier layers.
Common wrong answers and the exact correction
  • Softmax classes compete and sum to one
  • ReLU is not a probability output.

Implement it and test the outcome

Data, components and application

  • Sigmoid hidden units saturate → consider ReLU and suitable initialization → reduce vanishing gradients
  • Mutually nonexclusive labels → use separate sigmoid outputs → several labels may be true

How to evaluate it

Check probabilities, loss and per-class errors on held-out data; matching activation to task is necessary but does not guarantee accuracy.

Build the answer in this order

  1. State target type
  2. Choose hidden activation
  3. Choose output activation
  4. Explain why the loss matches the output

An answer you could write

  • “These classes are mutually exclusive, so I use softmax with categorical cross-entropy.”
  • “ReLU belongs in the hidden layers here; it is not a normalized class-probability output.”

Where this is tested in the sample papers

ISY5002 Q2(a) — Lean CNN redesign, parameter arithmetic, activations and loss

What the question requires

  1. Locate the parameter bottleneck.
  2. Propose a smaller classifier tail while preserving required outputs.
  3. Recalculate weights plus biases and total reduction.
  4. Choose activations/loss consistent with the classification task.
  5. Validate accuracy, imbalance and lean deployment constraints.

Proposed answer points

  • The original tail is Flatten9408 → Dense256 → Dense128 → Dense918. Its Dense parameter counts are 2,408,704, 32,896 and 118,422; with 18,960 convolution parameters the total is 2,578,982. The first Dense alone accounts for about 93.4%, so the actual bottleneck is the flattened-to-dense connection.
  • A defensible replacement is Flatten9408→Dense64→Dense918. Unchanged convolutions:18,960; Dense64:602,176; output:59,670; total:680,806. Reduction:1,898,176≈73.6%.
  • Use ReLU in the hidden layers, softmax over the 918 mutually exclusive combined classes, and categorical cross-entropy. Smaller is not automatically better: check held-out quality.

Avoid: 5,000 unevenly spread images raise overfitting and class-imbalance concerns; those are related but different problems. The combined 918-way output is one design, not the only possible factorized output architecture.
